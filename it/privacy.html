🔍 1. Panoramica

NODUS è un'estensione browser con approccio local-first. Tutto ciò che acquisisci — idee, note, evidenziazioni, tag, catene e progetti — viene memorizzato esclusivamente nell'archiviazione locale del tuo browser (chrome.storage.local) e non viene mai caricato su alcun server.

NODUS effettua due tipi di connessioni esterne, entrambe chiaramente descritte in questo documento:

opt-in Telemetria anonima

Disabilitata per impostazione predefinita. Se scegli di attivarla, vengono inviate solo statistiche di utilizzo aggregate — mai i tuoi contenuti.

PRO only Validazione licenza

Solo per abbonati PRO a pagamento. Invia un'impronta digitale del dispositivo con hash e la tua email per verificare la licenza. Il contenuto delle conversazioni non viene mai incluso.

💾 2. Dati memorizzati localmente sul tuo dispositivo

Tutti i seguenti dati sono memorizzati in chrome.storage.local — il che significa che risiedono solo sul tuo computer e non vengono mai inviati da nessuna parte, a meno che tu non li esporti esplicitamente.

  • Idee, note ed evidenziazioni acquisite
  • Tag e assegnazioni alla coda
  • Catene e modelli di catene
  • Progetti e metadati dei progetti
  • Preferenze del layout del dashboard
  • Impostazioni di lingua e animazione
  • Coda eventi di telemetria (se attivata)
  • ID anonimo — un hash SHA-256 generato localmente con salt casuale, mai collegato alla tua identità

NODUS non dispone di un sistema di account utente. Non esiste sincronizzazione cloud, nessun profilo lato server e nessun modo per noi di identificarti dai dati memorizzati localmente.

🌐 3. Endpoint esterni spiegati

NODUS si connette a URL esterni in tre scenari: telemetria (opt-in), validazione della licenza (solo PRO) e lettura di file che hai già caricato su piattaforme AI. Di seguito sono riportati tutti gli endpoint utilizzati e cosa viene inviato esattamente.

3a. Infrastruttura NODUS

https://nodus-worker.mmcarvalho-dev.workers.dev/telemetry/batch opt-in only

Riceve statistiche di utilizzo aggregate anonime. Viene chiamato solo se hai abilitato la telemetria nelle Impostazioni. Vedi Sezione 4 per i dettagli completi.

Dati inviati: ID anonimo (hash SHA-256) · conteggi dei tipi di evento · conteggi delle piattaforme · nessun contenuto delle conversazioni · nessun URL · nessun testo

https://nodus-worker.mmcarvalho-dev.workers.dev/auth/status PRO only

Convalida la tua licenza PRO all'avvio. Viene chiamato solo se hai inserito un token di licenza. Vedi Sezione 5 per i dettagli completi.

Dati inviati: indirizzo email · impronta digitale del dispositivo con hash · nessun contenuto delle conversazioni

3b. Accesso ai file sulle piattaforme AI

A questi endpoint si accede in modalità read-only quando attivi la funzione Acquisizione Chat Completa o gli allegati file. NODUS legge il contenuto del file per visualizzarlo o salvarlo localmente. Nulla viene caricato sui server NODUS.

https://files.oaiusercontent.com/*  ·  https://*.oaiusercontent.com/*  ·  https://cdn.openai.com/* read-only

File e immagini caricati dall'utente nelle conversazioni ChatGPT (immagini, PDF, allegati). NODUS legge questi file localmente per includerli nell'Acquisizione Chat Completa.

https://*.anthropic.com/* read-only

File, artefatti e allegati caricati dall'utente nelle conversazioni Claude.ai. Accessibili localmente per supportare l'Acquisizione Chat Completa.

https://storage.googleapis.com/* read-only

File caricati dall'utente nelle conversazioni Gemini. Accessibili localmente per supportare l'Acquisizione Chat Completa.

https://*.blob.core.windows.net/* read-only

File caricati dall'utente nelle conversazioni Microsoft Copilot. Accessibili localmente per supportare l'Acquisizione Chat Completa.

📊 4. Telemetria anonima opzionale

La telemetria è disabilitata per impostazione predefinita. Devi attivarla esplicitamente in Impostazioni → Telemetria. Puoi disabilitarla in qualsiasi momento e tutti i dati in coda localmente vengono eliminati immediatamente.

Cosa raccoglie la telemetria (quando abilitata)

  • Conteggi dei tipi di evento (ad es. "3 salvataggi, 1 iniezione") — nessun contenuto, nessun testo
  • Conteggi delle piattaforme (ad es. "usato su ChatGPT 2 volte") — nessun URL
  • ID anonimo — un hash SHA-256 generato localmente, non collegato alla tua identità
  • Conteggi aggregati delle sessioni al giorno (raggruppamento temporale)

Cosa non raccoglie mai la telemetria

  • Contenuto delle conversazioni, prompt o risposte AI
  • URL visitati o titoli delle pagine
  • Il tuo nome, email o qualsiasi informazione identificativa
  • Indirizzo IP (non memorizzato dal nostro worker)
  • Specifiche del dispositivo o impronta digitale del browser

Come i dati vengono elaborati prima dell'invio

Gli eventi vengono aggregati localmente prima della trasmissione. Invece di inviare eventi grezzi, NODUS invia contatori aggregati (ad es. quanti salvataggi sono avvenuti, da quale piattaforma) con rumore a protezione della privacy applicato (offset casuale ±2 per contatore). Gli eventi grezzi non lasciano mai il tuo dispositivo.

Conservazione dei dati

I dati di telemetria aggregati vengono conservati sui nostri server per un massimo di 12 mesi, dopodiché vengono eliminati. I log degli eventi locali vengono conservati per 90 giorni nell'archiviazione del browser, poi eliminati automaticamente.

🔑 5. Validazione licenza PRO

Se acquisti NODUS PRO, l'estensione convalida la tua licenza con il nostro server all'avvio. Questo è il minimo necessario per verificare un abbonamento a pagamento.

Cosa viene inviato durante la validazione della licenza

  • Il tuo indirizzo email (come inserito durante l'attivazione)
  • Un'impronta digitale del dispositivo con hash (identificatore generato dal browser, non il numero seriale del tuo hardware)

Cosa non viene mai inviato

  • Contenuto delle conversazioni o qualsiasi cosa tu abbia acquisito
  • Il tuo indirizzo IP (non memorizzato, utilizzato solo per il routing da Cloudflare)
  • Dati di telemetria (questi sono sistemi separati)

I dati della licenza sono memorizzati in un database Cloudflare D1 (regione Brasile/Sud America). Vengono utilizzati esclusivamente per verificare se il tuo abbonamento è attivo. Non vengono mai venduti o condivisi con terze parti.

La versione GRATUITA di NODUS funziona completamente offline e non contatta mai il nostro server delle licenze.

📎 6. Accesso ai file sulle piattaforme AI

Quando utilizzi l'Acquisizione Chat Completa o le funzioni di allegato file, NODUS può recuperare file che hai già caricato su una piattaforma AI (ChatGPT, Claude, Gemini, Copilot) per includerli nell'acquisizione locale.

Questo accesso è read-only e locale. NODUS legge il contenuto del file direttamente dalla CDN della piattaforma AI nella memoria del tuo browser e lo salva nell'archiviazione locale (chrome.storage.local). Il file non viene mai ricaricato su alcun server NODUS.

I permessi del browser necessari per questo (*.oaiusercontent.com, *.anthropic.com, storage.googleapis.com, *.blob.core.windows.net) consentono a NODUS di leggere quei file. Non consentono a NODUS di scrivere, modificare o trasmettere i tuoi dati su quelle piattaforme.

🚫 7. Cosa non facciamo mai

  • Vendere i tuoi dati a terze parti
  • Leggere, memorizzare o trasmettere il contenuto delle tue conversazioni
  • Tracciare i siti web che visiti al di fuori delle piattaforme AI
  • Utilizzare SDK pubblicitari o analisi di terze parti
  • Iniettare annunci o link di affiliazione nelle piattaforme AI
  • Accedere al microfono, alla fotocamera o agli appunti senza un'azione
  • Sincronizzare i dati acquisiti su qualsiasi cloud senza il tuo esplicito export

⚖️ 8. I tuoi diritti (LGPD / GDPR)

NODUS è conforme alla Lei Geral de Proteção de Dados brasiliana (LGPD) e al Regolamento Generale sulla Protezione dei Dati dell'UE (GDPR), ed è compatibile con il CCPA.

I tuoi diritti

  • Accesso — Tutti i dati memorizzati localmente sono visibili ed esportabili dal dashboard NODUS in qualsiasi momento
  • Cancellazione — Puoi eliminare tutti i dati locali da Impostazioni → Cancella tutti i dati. La disinstallazione dell'estensione rimuove anche tutti i dati locali
  • Portabilità — Esporta tutte le tue idee come JSON, Markdown o DOCX in qualsiasi momento
  • Opt-out — Disabilita la telemetria in qualsiasi momento in Impostazioni → Telemetria
  • Cancellazione dati licenza — Contattaci per richiedere la cancellazione della tua email dal nostro database delle licenze

Base giuridica del trattamento

La telemetria viene trattata sulla base del consenso (opt-in). La validazione della licenza viene trattata sulla base dell'esecuzione del contratto (verifica di un abbonamento a pagamento). Non avviene nessun altro trattamento.
