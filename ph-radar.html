How it works

Open the side panel. See everything.

PH Radar runs silently. Snapshots the daily race in the background, tracks the hunters you pin, and alerts you when products cross watch rules you set.

1

Install the extension

Add NODUS PH Radar to Chrome. Free, no account. Just paste a Product Hunt Developer Token once.

2

Open the side panel

See today's race ranked live. Pin products. Pin hunters. Set watch rules with custom thresholds.

3

Get alerts that matter

When a product crosses your rule (votes, velocity, rank), the bell lights up. Built for makers who want to know when something is breaking out.

Features

Everything you need to read the Product Hunt daily race

🏁

Daily Race

Live ranking of today's launches. Snapshot loop with 3 cadence profiles (eco/standard/hi-fi) to balance freshness vs API quota.

⚡

Velocity

Votes per hour computed between snapshots. Catches products accelerating before they hit the top.

🔔

Watch Rules

Define conditions (votes, comments, velocity, rank). When a product matches all, the bell fires. Each rule is independent.

🎯

Hunters Tab

Track publishers you care about. Pin favorite hunters, get notes per hunter, see all launches grouped by who hunted them.

🗓️

Launch Calendar

Upcoming launches submitted by makers via Spotlight. See who's launching tomorrow, next week. Curated by the NODUS community.

🌐

16 Languages

Native interface in 16 languages. Auto-translate taglines and comments via Chrome's offline translator. No data leaves your machine.
