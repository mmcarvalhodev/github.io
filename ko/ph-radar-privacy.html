🔍 1. 개요

NODUS PH Radar는 로컬 우선 브라우저 확장 프로그램입니다(Chrome). Product Hunt에 대한 역사적 깊이 — 일일 레이스 추적, 속도 분석, 워치 규칙, hunter 탭, 출시 캘린더 — 를 모두 사이드패널에서 제공합니다. 설정, 캐시, 핀, 메모, 워치 규칙은 귀하의 브라우저에 남아 있습니다. 사용자 계정도, 로그인도, 핵심 기능을 위한 클라우드 동기화도 없습니다.

이것은 메인 NODUS 확장 프로그램(AI 대화 캡처) 및 NODUS YT Radar와는 별개의 제품입니다. 해당 방침을 찾고 계신다면 NODUS 개인정보 처리방침 또는 YT Radar 개인정보 처리방침을 참조하세요.

PH Radar는 다음 세 가지 목적으로만 외부 연결을 하며, 각각은 아래에 문서화되어 있습니다.

필수 Product Hunt API v2 (공개)

귀하가 추적하는 제품의 공개 제품 데이터(일일 레이스, 투표 수, hunter 정보)를 가져오는 데 사용됩니다. 읽기 전용, 공개 데이터만 사용하며, 귀하의 PH 계정 자격 증명에는 절대 접근하지 않습니다.

필수 Community Spotlight

당사의 worker로부터 지역에 맞게 큐레이션된 제품 프로모션을 가져옵니다. 귀하의 국가 코드만 전송하며, 신원 정보, 검색 기록, Product Hunt 계정 정보는 일절 전송하지 않습니다.

클릭 시 프로모션 클릭 수

Spotlight 제품을 클릭하면 maker가 자신의 게시물 성과를 알 수 있도록 익명 클릭 이벤트가 기록됩니다. 프로모션 ID만 전송됩니다.

💾 2. 사용자 기기에 로컬로 저장되는 데이터

다음의 모든 항목은 chrome.storage.local 또는 로컬 IndexedDB에 저장되며, 이는 귀하의 컴퓨터에만 존재하고, 제3장에 명시적으로 설명된 경우를 제외하고는 어떠한 NODUS 서버로도 전송되지 않습니다.

settings
귀하의 환경설정: UI 언어, 선호 지역, overlay 모드, 새로고침 간격, 사이드바 레이아웃 선택.
ph_token
귀하의 Product Hunt 개인 API 토큰(선택 사항). 공개 리더보드 데이터를 가져오는 데에만 사용되며, NODUS 서버로는 절대 전송되지 않고 Product Hunt 자체 API로만 전송됩니다. 확장 프로그램 설정에서 언제든지 지울 수 있습니다.
ph_snapshots_<date> (IndexedDB)
그날의 레이스에 등장한 제품의 공개 지표(투표 수, hunter, tagline)에 대한 일일 스냅샷. 속도 차트와 일일 타임라인을 구성하는 데 사용됩니다. 로컬 IndexedDB에 저장되며, 30일 후 자동으로 정리됩니다.
ph_pins
귀하가 워치하기 위해 핀으로 고정한 제품. 로컬에 저장되며, 당사 서버로는 절대 전송되지 않습니다.
ph_notes_<productId>
귀하가 추적 중인 제품에 대해 작성한 메모. 로컬에 저장되며, 당사 서버로는 절대 전송되지 않습니다.
ph_watch_rules
귀하가 정의한 알림 규칙(예: "투표 수가 > 200이 되면 알림"). 로컬에 저장되며, 트리거는 브라우저 내에서 평가됩니다.
spotlight_token
귀하의 Spotlight 액세스 토큰(제출 시 브라우저 내에서 생성된 UUID). 대시보드에서 귀하 자신의 프로모션을 조회하는 데에만 사용됩니다. 로컬에 저장되며, 당사 서버에는 이 토큰의 SHA-256 해시만 보관합니다. 평문은 최초 제출 이후 절대 전송되지 않습니다.
_cacheVersion
확장 프로그램 업데이트 후 오래된 캐시를 무효화하는 데 사용되는 내부 플래그.

PH Radar에는 사용자 계정 시스템이 없습니다. 귀하의 PH 토큰, 핀, 메모, 워치 규칙, 스냅샷은 확장 프로그램을 제거하거나 브라우저 설정에서 확장 프로그램 데이터를 지우면 모두 자동으로 삭제됩니다.

🌐 3. 외부 엔드포인트 설명

확장 프로그램은 다음 종류의 네트워크 요청을 합니다. 모든 도메인은 확장 프로그램의 host_permissions 매니페스트 필드에 선언되어 있으며, 설치 전에 귀하의 브라우저에서 확인할 수 있습니다.

3a. Product Hunt GraphQL API v2 (공개)

https://api.producthunt.com/v2/api/graphql 필수

공개 일일 레이스 리더보드, 제품 상세 정보(제목, tagline, 썸네일, 투표 수, hunter), hunter 프로필 통계를 가져옵니다. 이는 producthunt.com에서 볼 수 있는 것과 동일한 공개 데이터입니다.

전송되는 데이터: 공개 제품/hunter 데이터에 대한 GraphQL 쿼리 · 귀하의 PH 개인 토큰(Product Hunt 자체 서버로만 — 당사로는 아님) · NODUS가 수집하는 개인 데이터 없음

3b. NODUS PH Radar worker (Community Spotlight)

https://worker-ph-radar.mmcarvalho-dev.workers.dev/spotlight?region=... 필수

사이드패널 스트립을 채울 수 있도록 귀하의 지역에 대한 활성 Spotlight 제품 프로모션을 요청합니다.

전송되는 데이터: 국가 코드 · 신원 정보 없음, PH 계정 정보 없음, Cloudflare의 표준 요청 로그를 넘어 저장되는 IP 없음

https://worker-ph-radar.mmcarvalho-dev.workers.dev/spotlight/click 클릭 시에만

사이드패널에서 Spotlight 제품을 클릭할 때에만 전송됩니다. maker의 보고 대시보드를 위해 집계 클릭 카운터를 증가시킵니다.

전송되는 데이터: 프로모션 ID · 그 외에는 없음

https://worker-ph-radar.mmcarvalho-dev.workers.dev/spotlight/impression 조회 시

Spotlight 카드가 스트립에서 표시될 때 전송됩니다(프로모션당 세션마다 최대 한 번 집계). 집계 노출 보고에 사용됩니다.

전송되는 데이터: 프로모션 ID · 그 외에는 없음

3c. 프로모션 제출 (maker 전용, 선택 사항)

https://worker-ph-radar.mmcarvalho-dev.workers.dev/promotions/submit maker만 · 제출 시

maker가 nodus-ai.app/ph-radar에서 Community Spotlight 제출 양식을 작성할 때에만 호출됩니다. 일반적인 확장 프로그램 사용으로는 트리거되지 않습니다.

전송되는 데이터: Product Hunt 제품 URL · 이메일 주소 · 선택적 tagline, 출시일, 토픽, 지역 · tier · 액세스 토큰(UUID, 클라이언트 측에서 생성)

⭐ 4. Community Spotlight 프로모션

Community Spotlight는 maker가 제출한(무료 또는 유료 tier) 큐레이션된 Product Hunt 제품을 보여주는, PH Radar 사이드패널 하단의 스트립입니다. 인디 maker가 광고 네트워크 없이 발견의 노출을 얻을 수 있도록 존재합니다.

worker가 프로모션에 대해 저장하는 내용

maker가 nodus-ai.app/ph-radar에서 제품을 제출하면, 당사의 Cloudflare D1 데이터베이스에 다음이 저장됩니다: Product Hunt 제품 URL과 slug, 제목, tagline, 썸네일 URL, hunter 사용자명, tier(free / bronze / silver / gold), 대상 지역과 토픽, 선택적 출시일, 제출자의 이메일(거래 알림 전용), 집계 노출/클릭 카운터. 이 정보는 maker가 자발적으로 제공하는 것이며, 확장 프로그램 사용자로부터 수집되는 것이 아닙니다.

액세스 토큰

제출 시점에 귀하의 브라우저는 crypto.randomUUID()를 사용하여 UUID 액세스 토큰을 생성합니다. 이 토큰은 화면에 한 번만 표시되므로 귀하가 복사하여 보관합니다. 당사 서버에는 이 토큰의 SHA-256 해시만 저장합니다. 당사는 이를 검증할 수 있지만 평문 토큰을 되찾기 위해 역변환할 수는 없습니다. 이 토큰을 통해 대시보드에서 귀하 자신의 프로모션을 조회하고 관리할 수 있습니다.

유료 tier — Paddle 결제 처리

유료 tier(Bronze 1달러, Silver 3달러, Gold 7달러)의 결제는 Paddle에 의해 처리됩니다(하위 처리자 세부 정보는 제5장 참조). 귀하의 이메일 주소와 결제 정보는 NODUS가 아니라 Paddle이 수집합니다. 당사는 Paddle의 webhook로부터 결제 확인 이벤트만 받으며, 여기에는 귀하의 플랜을 활성화할 수 있도록 귀하의 이메일과 거래 ID가 포함됩니다.

확장 프로그램 사용자는 어떻습니까?

확장 프로그램 측에서는 귀하를 식별하는 어떠한 것도 저장하지 않습니다. worker는 다음만 받습니다: Spotlight 매칭을 위한 지역 코드, 그리고 — 귀하가 클릭하거나 조회한 경우 — 프로모션 ID. 당사는 귀하가 추적 중인 제품, Cloudflare의 표준 요청 처리를 넘어선 귀하의 IP, 귀하의 브라우저 핑거프린트, 또는 어떠한 계정 식별자도 기록하지 않습니다.

호스팅

worker는 Cloudflare D1 데이터베이스와 함께 Cloudflare Workers에서 실행됩니다. Cloudflare는 표준 네트워크 운영(DDoS 보호, 라우팅)의 일환으로 IP 주소와 요청 메타데이터를 일시적으로 처리할 수 있습니다. 당사는 자체 데이터베이스에 IP 주소를 기록하지 않습니다.

🔗 5. 하위 처리자

당사는 당사를 대신하여 개인 데이터를 처리할 수 있는 다음 제3자 서비스를 이용합니다. 해당되는 경우 각 업체와 데이터 처리 계약을 체결했습니다.

서비스 목적 처리되는 데이터 개인정보 처리방침
Cloudflare Workers + D1 Spotlight 프로모션 저장 및 제공을 위한 서버리스 런타임 및 데이터베이스 프로모션 메타데이터, 이메일(해시된 토큰), 집계 통계. IP 주소는 Cloudflare의 네트워크에 의해 일시적으로 처리되며 D1에 기록되지 않습니다. cloudflare.com/privacypolicy
Paddle 유료 Spotlight tier(Bronze, Silver, Gold)에 대한 결제 처리 이메일 주소, 청구 이름, 결제 카드 세부 정보(전적으로 Paddle이 처리하며 — NODUS는 카드 번호를 절대 보지 않습니다). Paddle은 기록상의 판매자입니다. paddle.com/legal/privacy
Resend 거래 이메일: 제출 확인 및 관리자 검토 알림 제출하는 maker의 이메일 주소와 이메일 내용(제출 세부 정보). 이메일은 제출 이벤트에 의해서만 트리거됩니다. resend.com/legal/privacy-policy
Product Hunt API v2 공개 제품 및 hunter 데이터 가져오기 공개 제품 메타데이터(투표 수, 제목, tagline, hunter). 귀하의 PH 개인 토큰은 Product Hunt로 직접 전송되며, NODUS로는 전송되지 않습니다. producthunt.com/legal/privacy

제3자 분석 없음, 추적 쿠키 없음. PH Radar는 Google Analytics, Mixpanel, Segment, Facebook Pixel, 또는 기타 어떠한 행동 추적이나 광고 SDK도 — 확장 프로그램 내에서도, PH Radar와 관련된 nodus-ai.app 웹사이트 페이지에서도 — 사용하지 않습니다.

🚫 6. 당사가 절대로 하지 않는 것

  • 귀하의 데이터를 제3자에게 판매하는 것
  • 귀하의 Product Hunt 계정 자격 증명, DM, 비공개 프로젝트, 구매 내역을 읽는 것
  • 귀하의 PH 개인 토큰을 NODUS 서버로 전송하는 것 — 그것은 오직 Product Hunt 자체 API로만 전송됩니다
  • 확장 프로그램 사이드패널 외부에서 귀하가 producthunt.com에서 둘러보는 제품을 추적하는 것
  • Product Hunt 외부에서 귀하가 방문하는 웹사이트를 추적하는 것
  • 광고 SDK, 제3자 분석, 또는 행동 추적 쿠키를 사용하는 것
  • 귀하의 마이크, 카메라, 클립보드, 또는 다운로드에 접근하는 것
  • 핀, 메모, 워치 규칙, 또는 투표 스냅샷을 당사 서버로 동기화하는 것 — 그 모든 데이터는 귀하의 기기에 남아 있습니다
  • 확장 프로그램의 핵심 기능을 사용하기 위해 계정, 로그인, 또는 이메일을 요구하는 것
  • maker 제출 데이터(이메일, 제품 URL)를 제5장에 나열된 하위 처리자 이외의 제3자와 공유하는 것

⚖️ 7. 귀하의 권리 (LGPD / GDPR)

PH Radar는 브라질 일반 개인정보 보호법(LGPD) 및 EU 일반 데이터 보호 규정(GDPR)을 준수하며, CCPA와도 호환됩니다.

확장 프로그램 사용자로서 귀하가 가지는 권리

  • 접근 — 모든 로컬 데이터는 chrome://extensions → PH Radar → 뷰 검사 → 애플리케이션 → 저장소 / IndexedDB를 통해 볼 수 있습니다
  • 삭제 — 확장 프로그램을 제거하면 모든 chrome.storage.local 및 IndexedDB 데이터가 자동으로 지워집니다. 브라우저 설정에서 수동으로 지울 수도 있습니다
  • PH 토큰 — 확장 프로그램 설정 페이지에서 언제든지 Product Hunt 토큰을 지울 수 있습니다. 이는 NODUS 서버로 절대 전송되지 않습니다
  • 옵트아웃 — 확장 프로그램 설정에서 Spotlight 스트립을 비활성화할 수 있습니다. 사이드패널을 닫으면 확장 프로그램의 모든 네트워크 활동이 중지됩니다

maker(Spotlight 제출자)로서 귀하가 가지는 권리

  • 접근 및 삭제 — 제출 시 표시된 액세스 토큰을 사용하여 nodus-ai.app/ph-radar#dashboard의 대시보드를 통해 귀하의 프로모션을 조회하거나 삭제할 수 있습니다
  • 토큰 분실 — 제출 시 사용한 이메일로 당사에 연락하시면 본인 확인 후 귀하의 데이터를 삭제해 드립니다
  • 결제 데이터 — 청구 데이터(결제 내역, 청구서)는 paddle.com/legal/privacy에서 Paddle에 직접 문의하시거나 구매 이메일의 구매자 포털 링크를 이용하세요
