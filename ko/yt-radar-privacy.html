🔍 1. 개요

NODUS YT Radar는 로컬 우선 브라우저 확장 프로그램입니다 (Chrome 및 Firefox). 시청 중인 YouTube 동영상이 모든 국가의 Top 50 인기 급상승 동영상 대비 어디에 순위하는지를 바이럴 점수 및 모멘텀 분석과 함께 실시간으로 보여줍니다. 모든 설정, 캐시, 기록 스냅샷은 브라우저 안에 머무릅니다 — 사용자 계정도, 로그인도, 클라우드 동기화도 없습니다.

이는 기본 NODUS 확장 프로그램(AI 대화 캡처)과는 별개의 제품입니다. 해당 방침을 찾고 계신다면 privacy.html을 참조하세요.

YT Radar는 오직 세 가지 목적으로만 외부 연결을 수행하며, 각각은 아래에 문서화되어 있습니다:

필수 YouTube Data API v3

선택한 국가의 공개 Top 50 인기 급상승 목록과 시청 중인 동영상의 세부 정보를 가져오는 데 사용됩니다. 읽기 전용 공개 데이터입니다.

필수 Community Spotlight

우리 워커로부터 큐레이션된 지역 인식 동영상 프로모션을 가져옵니다. 국가 코드와 카테고리 번호만 전송하며 — 신원 정보도, 시청 중인 동영상 정보도 보내지 않습니다.

클릭 시 프로모션 클릭 수

Spotlight 항목을 클릭하면 익명 클릭 이벤트가 기록되어 프로모션 제작자가 자신의 목록 성과를 알 수 있습니다. 프로모션 ID만 전송됩니다.

💾 2. 기기에 로컬로 저장되는 데이터

아래의 모든 항목은 chrome.storage.local에 저장됩니다 — 즉, 귀하의 컴퓨터에만 존재하며 섹션 3에 명시적으로 설명된 경우를 제외하고는 어떠한 NODUS 서버로도 전송되지 않습니다.

settings
귀하의 환경설정: 국가 코드, 오버레이 모드(배지 / 확장 / 티커 / 끔), 캐시 새로 고침 간격(15/30/60분), 카테고리 필터, UI 언어.
ranking_<region>_<category>
YouTube Data API가 반환한 Top 50 목록으로, 팝업을 열 때마다 다시 가져오지 않도록 캐시됩니다. 귀하의 새로 고침 간격 설정에 따라 만료됩니다.
video_<videoId>
팝업에서 연 동영상의 공개 메타데이터(제목, 채널, 조회수, 좋아요 수, 게시일). 10분 후 만료됩니다.
hist_<videoId>
귀하가 분석한 동영상의 공개 카운터(조회수, 좋아요, 댓글)에 대한 시계열 스냅샷으로, 성장 스파크라인을 그리고 급상승을 감지하는 데 사용됩니다. 스냅샷은 최대 5분에 한 번 촬영되며 48시간 후 정리됩니다. 식별 정보는 포함하지 않으며 — 오직 숫자뿐입니다.
_cacheVersion
확장 프로그램 업데이트 후 오래된 캐시를 무효화하는 데 사용되는 내부 플래그.

YT Radar에는 사용자 계정 시스템이 없으며, 로그인도, 확장 프로그램 내부 이메일 수집도, 텔레메트리도 없습니다. 위의 모든 키는 확장 프로그램을 제거하거나 브라우저의 확장 프로그램 설정에서 "모든 데이터 삭제"를 클릭하면 자동으로 삭제됩니다.

🌐 3. 외부 엔드포인트 설명

확장 프로그램은 네 종류의 네트워크 요청을 수행합니다. 연결하는 모든 URL은 확장 프로그램의 host_permissions 매니페스트 필드에 선언되어 있으며 설치 전에 귀하의 브라우저에서 확인할 수 있습니다.

3a. YouTube Data API v3 (공개 Google API)

https://www.googleapis.com/youtube/v3/videos?chart=mostPopular&regionCode=... 필수

선택한 국가의 공개 Top 50 인기 급상승 목록을 가져옵니다. 이는 YouTube의 인기 급상승 탭을 구동하는 것과 동일한 공개 엔드포인트입니다.

전송되는 데이터: 국가 코드(예: BR) · 선택적 카테고리 ID · 우리의 API 키 · 개인 데이터 없음, 시청 중인 동영상 정보 없음

https://www.googleapis.com/youtube/v3/videos?id=<videoId> 필수 (필요 시)

시청 중인 동영상의 공개 세부 정보를 가져오지만, 해당 동영상이 Top 50 목록에 아직 없는 경우에만 가져옵니다. 이것이 바로 바이럴 점수와 성장 지표를 계산할 수 있게 해주는 것입니다.

전송되는 데이터: YouTube 동영상 ID · 우리의 API 키 · 개인 데이터 없음

Google은 자체 개인정보 처리방침에 따라 이러한 요청을 기록할 수 있습니다. 우리는 이와 함께 어떠한 추가 개인 데이터도 전송하지 않습니다.

3b. NODUS YT Radar 워커 (Community Spotlight)

https://worker-yt-radar.mmcarvalho-dev.workers.dev/promotions?region=...&category=... 필수

귀하의 국가/카테고리 조합에 대해 활성화된 프로모션 동영상을 우리 워커에 요청하여 Community Spotlight 카드를 표시할 수 있도록 합니다.

전송되는 데이터: 국가 코드 · 카테고리 ID · 신원 정보 없음, 시청 중인 동영상 정보 없음, Cloudflare의 표준 요청 로그를 넘어서는 IP 저장 없음

https://worker-yt-radar.mmcarvalho-dev.workers.dev/promotions/click 클릭 시에만

Community Spotlight 카드의 "시청" 버튼을 클릭할 때만 전송됩니다. 집계 클릭 카운터를 증가시켜 프로모션 제작자가 자신의 목록 성과를 볼 수 있도록 합니다.

전송되는 데이터: 프로모션 ID · 그 외에는 없음

https://worker-yt-radar.mmcarvalho-dev.workers.dev/player?v=<videoId> iframe

프로모션 미리보기를 재생하기 위해 Community Spotlight 캐러셀 안에 iframe으로 로드됩니다. 워커는 YouTube 플레이어를 임베드하는 작은 HTML 페이지를 반환합니다.

전송되는 데이터: 프로모션 대상 YouTube 동영상 ID · 채널 및 제목(iframe 레이블로만 사용)

⭐ 4. Community Spotlight 프로모션

Community Spotlight는 제작자가 제출한 큐레이션된 YouTube 동영상(무료 또는 유료 등급)을 표시하는 팝업 내부 섹션입니다. 독립 제작자가 광고 네트워크 없이 노출을 얻을 수 있도록 존재합니다.

워커가 프로모션에 대해 저장하는 것

제작자가 nodus-ai.app/yt-radar에서 동영상을 제출하면, 우리의 Cloudflare D1 데이터베이스에 다음이 저장됩니다: YouTube 동영상 ID, 제목, 채널, 썸네일 URL, 등급(무료/브론즈/실버/골드), 대상 지역 및 카테고리, 제출자의 이메일(연락 목적으로만), 그리고 집계 클릭/조회 카운터. 이 정보는 확장 프로그램 사용자로부터 수집되는 것이 아니라 제작자에 의해 제공됩니다.

확장 프로그램 사용자는 어떤가요?

확장 프로그램 측에서는 귀하를 식별하는 어떠한 것도 저장하지 않습니다. 워커는 오직 다음만 봅니다: 귀하가 선택한 국가와 카테고리(적절한 프로모션을 매칭할 수 있도록), 그리고 — 클릭하는 경우 — 프로모션 ID. 우리는 귀하가 어떤 동영상을 시청하고 있었는지, Cloudflare의 표준 요청 처리를 넘어서는 귀하의 IP, 귀하의 브라우저 핑거프린트, 또는 어떠한 계정 식별자도 기록하지 않습니다.

호스팅

워커는 Cloudflare Workers에서 실행됩니다. Cloudflare는 표준 네트워크 운영(DDoS 보호, 라우팅)의 일환으로 IP 주소와 요청 메타데이터를 일시적으로 처리할 수 있습니다. 우리는 IP 주소를 우리 자체 데이터베이스에 기록하지 않습니다.

🚫 5. 우리가 절대 하지 않는 것

  • 귀하의 데이터를 제3자에게 판매하는 것
  • 귀하가 어떤 YouTube 동영상을 시청하는지 추적하는 것 — 오직 활성 동영상 ID만 읽으며, 그것도 순위를 계산하기 위해서만
  • 귀하가 YouTube 외부에서 방문하는 웹사이트를 추적하는 것
  • 귀하의 YouTube 댓글, 검색 기록, 시청 기록 또는 계정 정보를 읽거나 전송하는 것
  • 광고 SDK, 제3자 분석 또는 행동 추적을 사용하는 것
  • 귀하의 마이크, 카메라, 클립보드 또는 다운로드에 접근하는 것
  • YouTube 페이지 자체에 광고를 삽입하는 것 — 오버레이는 귀하가 비활성화할 수 있는 작은 순위 배지만 표시합니다
  • 귀하의 데이터를 우리 서버로 동기화하는 것
  • 확장 프로그램의 핵심 기능을 사용하기 위해 계정, 로그인 또는 이메일을 요구하는 것

⚖️ 6. 귀하의 권리 (LGPD / GDPR)

YT Radar는 브라질 일반 개인정보 보호법(LGPD) 및 EU 일반 개인정보 보호 규정(GDPR)을 준수하며 CCPA와 호환됩니다.

귀하가 가진 권리

  • 접근 — 모든 로컬 데이터는 chrome://extensions → YT Radar → 뷰 검사 → Application → Storage를 통해 확인할 수 있습니다
  • 삭제 — 확장 프로그램을 제거하면 모든 chrome.storage.local 데이터가 자동으로 지워집니다. 브라우저 설정에서 수동으로 지울 수도 있습니다
  • 프로모션 데이터 — Community Spotlight 항목을 제출했다면, 제출 양식의 성공 화면에 표시된 접근 토큰을 사용하여 관리하거나 삭제할 수 있습니다. 토큰을 잃어버리셨나요? 제출 시 사용한 이메일로 문의해 주세요
  • 옵트아웃 — 설정에서 오버레이를 "끔"으로 설정하면 페이지 내 오버레이가 비활성화됩니다. 팝업을 닫으면 모든 확장 프로그램 네트워크 활동이 중지됩니다

처리의 법적 근거

Top 50 가져오기 및 동영상 세부 정보 조회는 정당한 이익(귀하가 확장 프로그램을 연 목적인 기능 제공)에 따라 처리됩니다. Spotlight 프로모션 제출은 제출 제작자와의 계약 이행에 따라 처리됩니다. 그 외의 처리는 발생하지 않습니다.
