Hacker News를 위한 시그널 레이어

같은 Hacker News. 더 적은 시각 피로. 더 많은 시그널. 편안하게 읽고, 태그로 스레드를 고정하고, 실시간으로 진짜 떠오르는 것을 확인하세요.

로컬 우선. 추적 없음. 서버 없음. 당신의 읽기 활동은 브라우저 안에 머뭅니다.

작동 방식

한 번 설치하세요. 평생 더 잘 읽으세요.

설정도, 계정도 필요 없습니다. Hacker News를 열면 확장 프로그램이 거친 부분을 부드럽게 다듬어 줍니다.

1

확장 프로그램 설치

NODUS HN Radar를 Chrome 또는 Firefox에 추가하세요. 280KB. 로컬 전용. Hacker News 외에는 어떤 권한도 요구하지 않습니다.

2

Hacker News 열기

Lens 레이어가 자동으로 활성화됩니다. 다크 모드, 읽기 쉬운 폰트, 게시물 유형별 배지, 방문한 게시물 회색 처리 — 조용히 작동합니다.

3

사이드 패널 열기

확장 프로그램 아이콘을 클릭하세요. 스레드를 고정하고, 태그를 붙이고, Radar가 떠오르는 게시물을 실시간 속도 점수와 함께 부각시키는 것을 지켜보세요.

기능

매일 HN을 읽는 사람이 직접 설계했습니다.

단순한 "모던 테마"가 아닙니다 — HN 특유의 미학을 존중하면서 약점만 제거한 읽기 및 시그널 레이어입니다.

🌓

Lens 읽기 레이어

다크, 라이트, 자동 테마. 조절 가능한 글꼴 크기. 읽기 너비 제어. 방문한 게시물 회색 처리. 컴팩트 모드.

🏷️

유형 배지

제목 옆에 인라인 SHOW / ASK / LAUNCH / TELL / POLL 알약 배지. 유형별 색상 라인. 클릭하면 패널이 열립니다.

📌

고정 및 태그

어떤 게시물이든 고정하세요. 다채로운 색상의 태그를 추가하세요 (색상은 이름에서 파생). 태그는 HN 페이지의 제목 옆에도 전파됩니다.

📡

Radar 대시보드

Top / Show HN / Ask HN / Best — 각 게시물마다 속도 점수(시간당 포인트 + 댓글)를 제공. 폭발하기 전에 떠오르는 것을 포착하세요.

⚡

속도와 델타

각 게시물은 현재 속도와 지난 구간의 변화량을 동시에 표시합니다. 가속 중인지 모멘텀을 잃는지 알 수 있습니다.

👤

활성 OP 배지

게시물 작성자가 스레드에 답변하면 금색 배지가 나타납니다. HN 사용자들이 사랑하는 "창업자가 여기 있어요" 시그널.

🔥

활발한 토론 알림

스레드가 댓글 150개 이상이 되면 은은한 칩이 표시됩니다. 400개 이상이면 🔥 불타오릅니다. 방문할 가치가 있는 스레드.

💬

인라인 미리보기

고정 카드의 "X comments"에 마우스를 올리면 — 상위 5개 댓글이 인라인으로 표시됩니다. 탭을 전환하지 않고 토론을 스캔할 수 있습니다.

🌐

통합 번역

Chrome (138+)의 로컬 Translator API를 사용하여 제목과 댓글 미리보기를 번역. API 키 없음, 클라우드 없음, 비용 없음.

🔕

도메인 음소거

medium.com 게시물에 지치셨나요? x.com은요? 도메인을 음소거 목록에 추가하면 Radar에서 사라집니다.

📐

줄무늬 행

색상과 강도를 사용자 정의할 수 있는 선택적 교차 배경. 메인 페이지를 위한 Excel 스타일 스캔.

🌍

17개 언어

인터페이스가 English, Português, Español, Français, Deutsch, Italiano, 日本語, 한국어, 中文, Русский 등으로 완전히 번역되었습니다.

🔔

워치리스트 알림

Top / Show / Ask / Best 전반에 최대 5개의 임계값 규칙. 스레드가 임계값을 넘으면 패널 내 알림 — 추가 권한 없음, 네이티브 팝업 없음.

설계상 로컬 우선 — 기능으로서가 아니라.

고정하거나, 태그를 붙이거나, 숨긴 모든 것은 브라우저 안에 머뭅니다. 확장 프로그램은 정확히 두 가지 종류의 네트워크 호출만 합니다: news.ycombinator.com (공개 사이트)와 Hacker News의 공개 Firebase API (떠오르는 목록을 가져오기 위함). 그게 전부입니다.

서버 없음. 계정 없음. 텔레메트리 없음. 추적 없음. 광고 SDK 없음. 코드는 .crx 패키지에서 검토할 수 있습니다.
