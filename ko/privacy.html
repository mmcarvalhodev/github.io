🔍 1. 개요

NODUS는 로컬 우선 브라우저 확장 프로그램입니다. 아이디어, 메모, 하이라이트, 태그, 체인, 프로젝트 등 캡처한 모든 내용은 브라우저의 로컬 스토리지(chrome.storage.local)에만 저장되며, 어떠한 서버에도 업로드되지 않습니다.

NODUS는 두 가지 유형의 외부 연결을 수행하며, 이 문서에서 모두 명확히 설명합니다:

opt-in 익명 텔레메트리

기본적으로 비활성화되어 있습니다. 활성화를 선택하신 경우, 집계된 사용 통계만 전송되며 귀하의 콘텐츠는 절대 포함되지 않습니다.

PRO only 라이선스 검증

유료 PRO 구독자에게만 해당됩니다. 라이선스 확인을 위해 해시된 기기 지문과 이메일 주소를 전송합니다. 대화 콘텐츠는 절대 포함되지 않습니다.

💾 2. 기기에 로컬 저장되는 데이터

아래의 모든 데이터는 chrome.storage.local에 저장됩니다. 즉, 귀하의 컴퓨터에만 존재하며, 명시적으로 내보내지 않는 한 어디에도 전송되지 않습니다.

  • 캡처된 아이디어, 메모, 하이라이트
  • 태그 및 큐 할당
  • 체인 및 체인 템플릿
  • 프로젝트 및 프로젝트 메타데이터
  • 대시보드 레이아웃 설정
  • 언어 및 애니메이션 설정
  • 텔레메트리 이벤트 큐 (활성화된 경우)
  • 익명 ID — 무작위 솔트를 사용하여 로컬에서 생성된 SHA-256 해시이며, 귀하의 신원과 연결되지 않습니다

NODUS에는 사용자 계정 시스템이 없습니다. 클라우드 동기화, 서버 측 프로필이 없으며, 로컬에 저장된 데이터로 귀하를 식별할 방법이 없습니다.

🌐 3. 외부 엔드포인트 설명

NODUS는 세 가지 경우에 외부 URL에 연결합니다: 텔레메트리(opt-in), 라이선스 검증(PRO 전용), 그리고 귀하가 AI 플랫폼에 업로드한 파일 읽기. 다음은 사용되는 모든 엔드포인트와 전송되는 데이터의 정확한 내용입니다.

3a. NODUS 인프라

https://nodus-worker.mmcarvalho-dev.workers.dev/telemetry/batch opt-in only

익명화된 집계 사용 통계를 수신합니다. 설정에서 텔레메트리를 활성화한 경우에만 호출됩니다. 자세한 내용은 4섹션을 참조하세요.

전송 데이터: 익명 ID (SHA-256 해시) · 이벤트 유형 횟수 · 플랫폼 횟수 · 대화 콘텐츠 없음 · URL 없음 · 텍스트 없음

https://nodus-worker.mmcarvalho-dev.workers.dev/auth/status PRO only

시작 시 PRO 라이선스를 검증합니다. 라이선스 토큰을 입력한 경우에만 호출됩니다. 자세한 내용은 5섹션을 참조하세요.

전송 데이터: 이메일 주소 · 해시된 기기 지문 · 대화 콘텐츠 없음

3b. AI 플랫폼 파일 접근

이 엔드포인트들은 전체 채팅 캡처 또는 파일 첨부 기능을 사용할 때 읽기 전용으로 접근됩니다. NODUS는 파일 내용을 읽어 로컬에 저장합니다. NODUS 서버에는 아무것도 업로드되지 않습니다.

https://files.oaiusercontent.com/*  ·  https://*.oaiusercontent.com/*  ·  https://cdn.openai.com/* read-only

ChatGPT 대화에서 사용자가 업로드한 파일 및 이미지 (이미지, PDF, 첨부파일). NODUS는 전체 채팅 캡처에 포함하기 위해 이 파일들을 로컬에서 읽습니다.

https://*.anthropic.com/* read-only

Claude.ai 대화에서 사용자가 업로드한 파일, 아티팩트, 첨부파일. 전체 채팅 캡처를 지원하기 위해 로컬에서 접근합니다.

https://storage.googleapis.com/* read-only

Gemini 대화에서 사용자가 업로드한 파일. 전체 채팅 캡처를 지원하기 위해 로컬에서 접근합니다.

https://*.blob.core.windows.net/* read-only

Microsoft Copilot 대화에서 사용자가 업로드한 파일. 전체 채팅 캡처를 지원하기 위해 로컬에서 접근합니다.

📊 4. 선택적 익명 텔레메트리

텔레메트리는 기본적으로 비활성화되어 있습니다. 활성화하려면 설정 → 텔레메트리에서 명시적으로 활성화해야 합니다. 언제든지 비활성화할 수 있으며, 로컬에 대기 중인 모든 데이터는 즉시 삭제됩니다.

텔레메트리가 수집하는 것 (활성화된 경우)

  • 이벤트 유형 횟수 (예: "저장 3회, 삽입 1회") — 콘텐츠 없음, 텍스트 없음
  • 플랫폼 횟수 (예: "ChatGPT 2회 사용") — URL 없음
  • 익명 ID — 로컬에서 생성된 SHA-256 해시이며, 귀하의 신원과 연결되지 않음
  • 일별 집계 세션 횟수 (시간대 구간화)

텔레메트리가 절대 수집하지 않는 것

  • 대화 콘텐츠, 프롬프트 또는 AI 응답
  • 방문한 URL 또는 페이지 제목
  • 이름, 이메일 또는 식별 가능한 정보
  • IP 주소 (워커에서 저장하지 않음)
  • 기기 사양 또는 브라우저 지문

전송 전 데이터 처리 방식

이벤트는 전송 전에 로컬에서 집계됩니다. 원시 이벤트를 전송하는 대신, NODUS는 개인정보 보호 노이즈(카운터당 ±2 무작위 오프셋)가 적용된 집계 카운터(예: 저장 횟수, 플랫폼별)를 전송합니다. 원시 이벤트는 귀하의 기기를 떠나지 않습니다.

데이터 보유

집계된 텔레메트리 데이터는 서버에 최대 12개월간 보유된 후 삭제됩니다. 로컬 이벤트 로그는 브라우저 스토리지에 90일간 보유된 후 자동으로 정리됩니다.

🔑 5. PRO 라이선스 검증

NODUS PRO를 구매하신 경우, 확장 프로그램은 시작 시 서버에서 라이선스를 검증합니다. 이는 유료 구독을 확인하기 위한 최소한의 요구 사항입니다.

라이선스 검증 시 전송되는 데이터

  • 이메일 주소 (활성화 시 입력한 주소)
  • 해시된 기기 지문 (브라우저 생성 식별자, 하드웨어 일련번호 아님)

절대 전송되지 않는 데이터

  • 대화 콘텐츠 또는 캡처한 모든 내용
  • IP 주소 (저장되지 않으며, Cloudflare가 라우팅에만 사용)
  • 텔레메트리 데이터 (별도의 시스템)

라이선스 데이터는 Cloudflare D1 데이터베이스(브라질/남미 지역)에 저장됩니다. 구독 활성 여부를 확인하는 용도로만 사용되며, 제3자에게 판매하거나 공유하지 않습니다.

NODUS 무료 버전은 완전히 오프라인으로 작동하며, 라이선스 서버에 연결하지 않습니다.

📎 6. AI 플랫폼에서의 파일 접근

전체 채팅 캡처 또는 파일 첨부 기능을 사용할 때, NODUS는 로컬 캡처에 포함하기 위해 귀하가 AI 플랫폼(ChatGPT, Claude, Gemini, Copilot)에 이미 업로드한 파일을 가져올 수 있습니다.

이 접근은 읽기 전용이며 로컬에서 이루어집니다. NODUS는 AI 플랫폼의 CDN에서 파일 내용을 브라우저 메모리로 직접 읽어 로컬 스토리지(chrome.storage.local)에 저장합니다. 파일은 절대 NODUS 서버에 재업로드되지 않습니다.

이를 위해 필요한 브라우저 권한(*.oaiusercontent.com, *.anthropic.com, storage.googleapis.com, *.blob.core.windows.net)은 NODUS가 해당 파일을 읽을 수 있도록 허용합니다. 해당 플랫폼에서 귀하의 데이터를 쓰거나 수정하거나 전송하는 것은 허용하지 않습니다.

🚫 7. 절대 하지 않는 것들

  • 제3자에게 귀하의 데이터를 판매
  • 대화 콘텐츠 읽기, 저장 또는 전송
  • AI 플랫폼 외부에서 귀하가 방문한 웹사이트 추적
  • 광고 SDK 또는 제3자 분석 도구 사용
  • AI 플랫폼에 광고 또는 제휴 링크 삽입
  • 귀하의 조작 없이 마이크, 카메라 또는 클립보드에 접근
  • 명시적 내보내기 없이 캡처한 데이터를 클라우드에 동기화

⚖️ 8. 귀하의 권리 (LGPD / GDPR)

NODUS는 브라질 개인정보보호법(LGPD)과 EU 일반 데이터 보호 규정(GDPR)을 준수하며, CCPA와도 호환됩니다.

귀하가 보유한 권리

  • 접근권 — 로컬에 저장된 모든 데이터는 언제든지 NODUS 대시보드에서 확인하고 내보낼 수 있습니다
  • 삭제권 — 설정 → 전체 데이터 삭제에서 모든 로컬 데이터를 삭제할 수 있습니다. 확장 프로그램 제거 시에도 모든 로컬 데이터가 삭제됩니다
  • 이동권 — 언제든지 모든 아이디어를 JSON, Markdown 또는 DOCX로 내보낼 수 있습니다
  • 거부권 — 설정 → 텔레메트리에서 언제든지 텔레메트리를 비활성화할 수 있습니다
  • 라이선스 데이터 삭제 — 라이선스 데이터베이스에서 이메일 삭제를 요청하려면 저희에게 문의하세요

처리의 법적 근거

텔레메트리는 동의(opt-in)를 기반으로 처리됩니다. 라이선스 검증은 계약 이행(유료 구독 확인)을 기반으로 처리됩니다. 그 외 다른 처리는 발생하지 않습니다.
