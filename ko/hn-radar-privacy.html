🔍 1. 개요

NODUS HN Radar는 완전히 로컬 우선 방식의 브라우저 확장 프로그램입니다. news.ycombinator.com에서의 읽기 경험을 향상시키고, Hacker News의 공개 API를 통해 떠오르는 게시물을 부각시킵니다. 서버 없음, 계정 없음, 로그인 없음, 클라우드 동기화 없음, 텔레메트리 없음.

메인 NODUS 확장 프로그램(AI 대화 캡처) 및 NODUS YT Radar의 자매 제품입니다. 각각 고유한 정책을 갖습니다:

  • NODUS 메인 — privacy.html
  • YT Radar — yt-radar-privacy.html
  • HN Radar — 본 문서

HN Radar는 두 개의 엔드포인트에 연결하며, 둘 다 Hacker News 자체에 속합니다:

필수 news.ycombinator.com

귀하가 읽고 있는 사이트. 콘텐츠 스크립트는 귀하가 직접 로드한 페이지를 향상시킵니다 — 능동적인 fetch는 없습니다.

필수 hacker-news.firebaseio.com

Hacker News의 공개 Firebase API. 떠오르는 목록 (Top / Show / Ask / Best)과 Radar 대시보드를 위한 개별 항목 세부 정보를 가져오는 데 사용됩니다.

없음 NODUS 서버

HN Radar는 어떤 NODUS 인프라에도 연결하지 않습니다. YT Radar (Community Spotlight worker)나 NODUS 메인 (PRO 라이선스)과 달리, 이 확장 프로그램은 NODUS 백엔드 의존성이 전혀 없습니다.

💾 2. 로컬에 저장되는 데이터

아래 항목은 모두 chrome.storage.local에 저장되며, 섹션 3에 설명된 경우를 제외하고는 다른 곳으로 전송되지 않습니다.

settings
귀하의 환경설정: 테마, 글꼴 크기, 읽기 너비, 강조 토글, 인터페이스 언어, 번역 설정, 줄무늬 색상/강도 등.
visited
프런트 페이지에서 클릭한 HN 게시물 ID 목록과 타임스탬프. 방문한 게시물을 회색으로 처리하는 데 사용. 30일 TTL과 자동 정리.
pinned
📌로 명시적으로 고정한 게시물: id, 제목, url, 도메인, 점수 스냅샷, 댓글 수, 경과 시간, 태그, 고정 타임스탬프.
collapsedCards
사이드 패널에서 접은 고정 카드의 ID.
recentTags
자동 완성을 위해 최근 사용한 태그 이름 40개 목록.
mutedDomains
음소거한 도메인 목록. 이러한 도메인의 게시물은 Radar에서 숨겨집니다.
radar
시간 경과에 따른 HN 게시물 데이터(점수, 댓글)의 스냅샷. 속도 계산에 사용.
opActiveCache
ID별 "작성자 답변" 감지 캐시. TTL 10분.
comments_<postId>
호버 미리보기 댓글 캐시. TTL 10분.

확장 프로그램을 제거하면 모든 것이 자동으로 삭제됩니다. 사용자 계정 없음, 이메일 수집 없음, NODUS가 귀하를 식별할 수 있는 방법 없음.

🌐 3. 외부 엔드포인트 설명

확장 프로그램은 host_permissions에 선언되고 설치 전에 Chrome에 표시되는 두 도메인에서만 fetch합니다.

3a. Hacker News 사이트

https://news.ycombinator.com/*콘텐츠 스크립트 전용

콘텐츠 스크립트는 귀하가 로드하는 페이지에 CSS와 작은 DOM 개선 사항(고정 버튼, 유형 배지, 번역 버튼)을 주입합니다. 확장 프로그램은 백그라운드에서 HN을 능동적으로 fetch하지 않습니다.

확장 프로그램이 전송하는 데이터: 브라우저가 이미 전송하는 것 외에는 아무것도 없음.

3b. Hacker News 공개 Firebase API

https://hacker-news.firebaseio.com/v0/topstories.json필수

떠오르는 ID 배열을 반환합니다. 공식 HN 프런트 페이지와 동일한 소스.

전송되는 데이터: 식별 정보 없음 — 요청만 전송.

…/v0/{best,show,ask}stories.json활성 탭일 때

Best, Show HN, Ask HN 탭에 대해서도 동일합니다.

…/v0/item/<id>.json게시물당

Radar 또는 미리보기에 표시되는 각 게시물 또는 댓글의 공개 세부 정보를 가져옵니다.

전송되는 데이터: 게시물 ID. 귀하의 식별자는 없음.

Hacker News와 Y Combinator는 자체 정책에 따라 이러한 요청을 기록할 수 있습니다. 확장 프로그램 자체는 헤더, 쿠키 또는 인증을 추가하지 않습니다.

🌐 4. 브라우저 내 번역

번역은 전적으로 귀하의 기기에서 이루어집니다. HN Radar는 Chrome의 내장 Translator API (Chrome 138+)를 사용하며, 이는 처음 사용할 때 작은 언어 모델을 로컬에 다운로드하고 어떤 서버에도 텍스트를 전송하지 않고 번역합니다.

이는 다음을 의미합니다:

  • 번역 시 어떤 텍스트도 브라우저를 떠나지 않습니다.
  • API 키 없음, 비용 없음, 사용량 추적 없음.
  • 모델이 다운로드된 후에는 번역이 오프라인에서도 작동합니다.
  • 번역 캐시는 로컬 전용이며 확장 프로그램과 함께 삭제됩니다.

귀하의 브라우저가 Translator API를 지원하지 않는 경우(Firefox 또는 이전 Chrome), 번역 기능은 아무 작동도 하지 않습니다 — 클라우드 서비스로의 폴백 없음.

🚫 5. 절대 하지 않는 것

  • 귀하의 데이터를 제3자에게 판매
  • NODUS 서버로 무엇이든 전송 (이 확장 프로그램에는 NODUS 백엔드 없음)
  • 귀하가 읽거나, 클릭하거나, 고정한 게시물 추적
  • news.ycombinator.com 외에 방문한 사이트 추적
  • 서드파티 분석 또는 광고 SDK 사용
  • 귀하의 댓글, 답변 또는 HN 계정 데이터 읽기 또는 저장
  • 마이크, 카메라, 클립보드 또는 다운로드에 액세스
  • 광고 또는 제휴 링크 주입
  • 계정, 로그인 또는 이메일 요구
  • 귀하의 태그, 핀 또는 환경설정을 클라우드에 동기화

⚖️ 6. 귀하의 권리 (LGPD / GDPR / CCPA)

HN Radar는 브라질 LGPD, 유럽 GDPR을 준수하며 CCPA와 호환됩니다. 모든 데이터가 로컬에 있고 확장 프로그램이 프로파일링이나 사이트 간 추적을 하지 않으므로 대부분의 권리는 브라우저를 통해 직접 행사할 수 있습니다.

귀하가 가진 권리

  • 접근 — 모든 로컬 데이터는 chrome://extensions → HN Radar → 검사 → Application → Storage에서 확인 가능
  • 삭제 — 확장 프로그램 제거 시 모든 것 삭제
  • 이동성 — 로컬 데이터는 chrome.storage.local에 JSON으로 저장되며 DevTools에서 내보내기 가능
  • 옵트아웃 — 언제든 Lens 마스터 토글을 비활성화

처리의 법적 근거

공개 HN 사이트와 공개 HN API를 읽는 것은 정당한 이익에 해당합니다 (귀하가 확장 프로그램을 설치함으로써 선택한 읽기 레이어를 제공). 개인 식별 가능 데이터는 처리되지 않습니다.
