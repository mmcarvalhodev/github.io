시작하기

6 개 질문

NODUS는 클릭 한 번으로 AI 응답을 저장, 정리, 재사용할 수 있는 브라우저 확장 프로그램입니다. ChatGPT, Claude, Gemini, Perplexity, Grok, Copilot, DeepSeek에서 작동합니다. 모든 데이터는 기기의 로컬 저장소에 보관됩니다 — 계정 불필요, 서버 불필요, 의무 구독 없음.

설치는 30초도 걸리지 않습니다:

  • Chrome / Edge / Brave: Chrome 웹 스토어를 방문하여 "Chrome에 추가" 클릭
  • Firefox: Mozilla 부가 기능을 방문하여 "Firefox에 추가" 클릭

설치 후 지원되는 AI 플랫폼을 열면 NODUS 버튼이 자동으로 나타납니다.

아니요. NODUS는 회원가입 없이 작동합니다. 이메일도, 비밀번호도 필요 없습니다. 설치 즉시 사용을 시작하세요. 데이터는 브라우저의 로컬 저장소에 보관됩니다.

NODUS는 다음 브라우저에서 작동합니다:

  • Chrome (88 버전 이상)
  • Firefox (109 버전 이상)
  • Edge (Chromium 기반)
  • Brave 및 기타 Chromium 브라우저

지원되는 플랫폼을 열면 NODUS가 AI 응답 옆에 플로팅 버튼을 삽입합니다. 저장을 클릭하면 질문과 응답을 즉시 캡처합니다. 빠른 저장을 클릭하면 설정 패널을 열지 않고 저장합니다. 대시보드를 클릭하면 캡처 대시보드가 열립니다.

NODUS는 현재 7개 플랫폼을 지원합니다:

  • ChatGPT (chat.openai.com)
  • Claude (claude.ai)
  • Gemini (gemini.google.com)
  • Perplexity (perplexity.ai)
  • Grok (grok.com / x.com)
  • Microsoft Copilot (copilot.microsoft.com)
  • DeepSeek (chat.deepseek.com)

대화 저장

9 개 질문

NODUS를 설치한 상태에서 평소처럼 ChatGPT를 엽니다. 각 응답 옆에 NODUS 버튼이 나타납니다. 저장을 클릭하면 캡처 패널이 열리고 태그를 추가하거나 대상 큐를 선택할 수 있습니다 — 또는 빠른 저장을 클릭하면 별도의 설정 없이 클릭 한 번으로 저장됩니다.

완전 가이드: ChatGPT 대화 저장하기 →

NODUS는 Claude.ai에서 기본으로 작동합니다. 캡처 버튼이 응답 옆에 자동으로 나타납니다. 저장을 클릭하면 질문과 응답이 로컬 대시보드에 저장됩니다. Claude 프로젝트와 일반 대화 모두에서 동일하게 작동합니다.

완전 가이드: Claude 대화 저장하기 →

NODUS를 설치하고 gemini.google.com을 방문하세요. Gemini 응답 옆에 캡처 버튼이 나타납니다. 저장을 클릭하면 다른 플랫폼과 동일한 태그 및 정리 방식으로 대화가 로컬에 저장됩니다.

완전 가이드: Gemini 대화 저장하기 →

NODUS는 Perplexity.ai의 응답을 자동으로 감지하고 캡처 버튼을 삽입합니다. 저장을 클릭하면 인용된 출처와 함께 응답이 기록됩니다. 나중에 참고하고 싶은 리서치에 이상적입니다.

NODUS는 grok.com과 x.com/grok 모두에서 작동합니다. Grok과의 대화를 열면 응답 옆에 캡처 버튼이 나타납니다. 저장을 클릭하면 NODUS 대시보드에 로컬로 보관됩니다.

NODUS는 DeepSeek (chat.deepseek.com)을 기본으로 지원합니다. 응답 옆에 캡처 버튼이 나타납니다. 저장을 클릭하면 질문과 응답이 로컬 대시보드에 기록됩니다.

각 캡처는 한 번에 하나의 질문과 응답을 저장합니다. 대화에서 여러 응답을 저장하려면 원하는 각 응답에서 저장을 클릭하세요. 그런 다음 체인을 사용하여 해당 캡처들을 논리적인 순서로 연결할 수 있습니다.

빠른 캡처(빠른 저장 버튼)는 설정 패널을 열지 않고 응답을 기본 큐에 바로 저장합니다. 대화 흐름을 방해하지 않고 빠르게 기록하고 싶을 때 이상적입니다. 캡처는 나중에 정리할 수 있도록 대시보드에서 확인할 수 있습니다.

NODUS를 설치하고 아직 어디에 쓸지 모르더라도 유용해 보이는 응답이 있을 때마다 빠른 저장 버튼을 사용하세요. 탭을 닫기 전에 캡처하는 습관이 정보 손실을 없애줍니다. 대시보드에 모든 것이 쌓이고, 전체 텍스트 검색으로 나중에 어떤 캡처든 찾을 수 있습니다.

내보내기 & 다운로드

7 개 질문

NODUS 대시보드를 열고 원하는 캡처를 선택한 후 내보내기 → DOCX를 클릭합니다. Word 파일이 브라우저에서 직접 생성되어 컴퓨터에 저장됩니다. 체인으로 여러 캡처를 연결하고 구조화된 문서로 한 번에 내보낼 수도 있습니다.

NODUS는 HTML로 내보내며, 브라우저에서 직접 PDF로 인쇄할 수 있습니다 (Ctrl+P → PDF로 저장). 직접 PDF 내보내기의 경우 HTML로 내보낸 후 브라우저의 인쇄 기능을 사용하는 것을 권장합니다 — 결과물의 형식이 잘 정리되어 있습니다.

NODUS는 다음 형식으로 내보내기를 지원합니다:

  • TXT — 일반 텍스트, 모든 편집기와 호환
  • HTML — 형식 지정됨, PDF로 인쇄 가능
  • DOCX — Word, Google Docs, LibreOffice와 호환

체인으로 연결된 캡처(체인)는 단일 문서로 함께 내보낼 수 있습니다.

NODUS 대시보드에서 설정 → 전체 내보내기로 이동합니다. 모든 캡처를 JSON 형식으로 담은 파일이 생성됩니다 (NODUS에 다시 가져오기 가능). 또는 각 큐를 DOCX 또는 HTML로 개별 내보낼 수 있습니다.

대시보드의 카드 보기에서 복사를 클릭합니다. 내용이 Markdown 형식(제목, 목록, 코드)을 유지한 채로 복사되어 Markdown을 지원하는 모든 편집기에 붙여넣을 수 있습니다.

네. 설정 → 데이터 내보내기에서 모든 캡처가 담긴 JSON 파일을 다운로드합니다. 이 파일은 다른 컴퓨터나 확장 프로그램을 재설치한 후 NODUS에 다시 가져올 수 있습니다.

체인을 사용하여 다양한 세션(심지어 다양한 플랫폼)의 관련 캡처를 연결하세요. 그런 다음 전체 체인을 DOCX로 내보내면 — 결과물은 모든 질문과 응답이 논리적인 순서로 연결된 구조화된 문서가 됩니다.

정리하기

7 개 질문

캡처를 저장할 때 내용을 분류하기 위해 최대 4개의 태그를 추가할 수 있습니다. 태그는 대시보드 카드에 표시되고 필터 역할을 합니다 — 태그를 클릭하면 해당 카테고리의 캡처만 표시됩니다. "백엔드", "학습", "아이디어", "업무" 또는 자신에게 맞는 어떤 카테고리든 태그를 만들 수 있습니다.

큐는 컨텍스트나 우선순위별로 캡처를 정리하기 위한 별도의 컬렉션입니다. 빠른 저장 큐는 분류 없이 빠른 캡처용입니다. 기본은 일반 큐입니다. Q1~Q4 큐(PRO 플랜)는 주제, 프로젝트 또는 클라이언트별로 맞춤 설정할 수 있습니다. 각 큐는 카드에서 다른 테두리 색상으로 구분됩니다.

NODUS 대시보드에서 상단의 검색창을 사용합니다. 검색은 실시간으로 작동하며 모든 캡처의 제목, 질문, 응답을 검색합니다. 플랫폼이나 태그 필터와 검색을 결합하면 원하는 것을 정확히 찾을 수 있습니다.

대시보드에서 검색창 아래의 플랫폼 배지를 클릭합니다. ChatGPT, Claude, Gemini 또는 다른 플랫폼을 클릭하면 해당 출처의 캡처만 표시됩니다. 다시 클릭하면 필터가 해제됩니다.

프로젝트(PRO 플랜)를 사용하면 완전히 분리된 공간을 만들 수 있습니다 — 예를 들어 "업무", "학습", "개인". 각 프로젝트에는 자체 큐와 캡처가 있습니다. 서로 다른 콘텐츠를 섞지 않고 클릭 한 번으로 프로젝트 간에 전환할 수 있습니다.

네. 대시보드에서 카드를 열고 편집을 클릭합니다. 제목을 수정하거나 태그를 추가/제거하고 캡처를 큐 간에 이동할 수 있습니다. 원본 콘텐츠(질문과 응답)는 보존됩니다.

대시보드의 텍스트 검색을 사용하세요 — 제목뿐만 아니라 모든 캡처의 전체 내용을 검색합니다. 응답에서 키워드를 기억한다면 그냥 입력하세요. 출처를 안다면 플랫폼 필터(예: Claude)와 결합하세요.

체인

6 개 질문

체인을 사용하면 다양한 대화의 캡처를 논리적인 순서로 연결할 수 있습니다. ChatGPT에서 주제를 조사하고, Claude에서 더 깊이 파고들고, Gemini에서 예시를 찾았다고 상상해보세요 — 체인은 다른 플랫폼에서 온 세 가지 캡처를 연속적인 추론 흐름으로 연결합니다.

대시보드의 체인 탭에서 "새 체인"을 클릭합니다. 체인에 이름을 지정하고 기존 캡처를 원하는 순서로 드래그하여 추가합니다. 어떤 플랫폼의 캡처든 추가하고 언제든지 순서를 재정렬할 수 있습니다.

네 — 그것이 체인의 주요 장점 중 하나입니다. ChatGPT, Claude, Gemini, Perplexity 및 다른 지원되는 플랫폼의 캡처를 하나의 순서로 연결할 수 있습니다. 각 카드는 출처 플랫폼 식별 정보를 유지합니다.

대시보드에서 체인을 열고 내보내기를 클릭합니다. 전체 순서를 DOCX 또는 HTML로 내보낼 수 있습니다 — 결과물은 모든 질문과 응답이 순서대로 담긴 구조화된 문서로, 보고서, 학습 또는 문서화에 이상적입니다.

무료 플랜에서 각 체인은 최대 5개 캡처를 가질 수 있습니다. PRO 플랜에서는 제한이 훨씬 높아서 복잡한 프로젝트를 위한 광범위한 체인을 만들 수 있습니다.

주입 기능을 사용하면 지원되는 플랫폼의 프롬프트 필드에 체인 내용을 직접 삽입할 수 있습니다. 각 응답을 수동으로 복사하여 붙여넣지 않고도 AI에게 이전 조사의 전체 맥락을 제공하는 것과 같습니다.

개인정보 & 보안

7 개 질문

아니요. NODUS에는 캡처를 수신하는 자체 서버가 없습니다. 모든 것은 브라우저의 로컬 저장소(chrome.storage.local / browser.storage.local)에 저장됩니다. 어떤 캡처, 태그, 콘텐츠도 기기를 떠나지 않습니다.

아니요. NODUS는 저장 또는 빠른 저장을 능동적으로 클릭할 때만 페이지 내용을 읽습니다. 자동 캡처, 수동적 모니터링, 또는 저장하도록 선택하지 않은 대화 읽기는 없습니다.

캡처는 운영 체제 사용자의 브라우저 프로필에 저장됩니다. 컴퓨터의 사용자 프로필이 비밀번호로 보호되어 있으면 캡처도 동일하게 보호됩니다. NODUS는 추가적인 암호화를 추가하지 않습니다 — 물리적 보안을 위해서는 운영 체제의 보호 기능을 사용하세요.

네. NODUS 핵심 코드는 MIT 라이선스 하에 GitHub에서 공개되어 있습니다. 누구든 코드를 감사하고 숨겨진 데이터 수집이 없음을 확인할 수 있습니다. 우리 말을 믿을 필요 없이 코드를 직접 확인하세요.

확장 프로그램을 제거하면 연결된 로컬 저장소가 브라우저에 의해 삭제됩니다. 먼저 백업하세요: 설정 → 데이터 내보내기로 이동하여 모든 캡처를 JSON으로 다운로드하세요. 재설치 후 다시 가져올 수 있습니다.

NODUS는 작동에 필요한 권한만 요청합니다:

  • AI 페이지 읽기 — 응답을 감지하고 버튼을 삽입하기 위해
  • 로컬 저장소 — 기기에 캡처를 저장하기 위해
  • 탭 접근 — 현재 어떤 플랫폼에 있는지 알기 위해

카메라, 마이크, 브라우징 기록 또는 비밀번호에 대한 권한은 요청하지 않습니다.

NODUS 대시보드는 완전히 오프라인으로 작동합니다 — 인터넷 연결 없이도 캡처를 접근, 검색, 내보낼 수 있습니다. 새 대화를 캡처하려면 AI 플랫폼 자체에 접근해야 하므로 인터넷 연결이 필요합니다.
