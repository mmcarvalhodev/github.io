🔍 1. Vue d'ensemble

NODUS YT Radar est une extension de navigateur axée sur le local (Chrome et Firefox). Elle vous montre, en temps réel, le classement de la vidéo YouTube que vous regardez par rapport au Top 50 des vidéos tendance de n'importe quel pays, avec un score viral et des analyses de momentum. Tous les réglages, caches et instantanés d'historique restent dans votre navigateur — il n'y a aucun compte utilisateur, aucune connexion, aucune synchronisation dans le cloud.

Il s'agit d'un produit distinct de l'extension NODUS principale (capture de conversations IA). Si vous cherchez cette politique, consultez privacy.html.

YT Radar établit des connexions externes uniquement à trois fins, chacune documentée ci-dessous :

requis YouTube Data API v3

Utilisée pour récupérer la liste publique du Top 50 des tendances pour le pays sélectionné, ainsi que les détails de la vidéo que vous regardez. Données publiques en lecture seule.

requis Community Spotlight

Récupère une promotion vidéo organisée et adaptée à la région auprès de notre worker. N'envoie que le code pays et un numéro de catégorie — aucune identité, aucune vidéo en cours de visionnage.

au clic Comptage des clics de promotion

Si vous cliquez sur un élément spotlight, un événement de clic anonyme est enregistré afin que le créateur promu sache comment son annonce a performé. Seul l'ID de la promotion est envoyé.

💾 2. Données stockées localement sur votre appareil

Tout ce qui suit est stocké dans chrome.storage.local — ce qui signifie que cela ne réside que sur votre ordinateur et n'est jamais envoyé à un serveur NODUS, sauf mention explicite à la Section 3.

settings
Vos préférences : code pays, mode de superposition (badge / étendu / bandeau / désactivé), intervalle de rafraîchissement du cache (15/30/60 min), filtre de catégorie, langue de l'UI.
ranking_<region>_<category>
La liste du Top 50 renvoyée par la YouTube Data API, mise en cache pour que nous n'ayons pas à la récupérer à chaque ouverture du popup. Expire selon votre réglage d'intervalle de rafraîchissement.
video_<videoId>
Les métadonnées publiques d'une vidéo que vous avez ouverte dans le popup (titre, chaîne, nombre de vues, nombre de mentions J'aime, date de publication). Expire après 10 minutes.
hist_<videoId>
Des instantanés chronologiques de compteurs publics (vues, mentions J'aime, commentaires) pour les vidéos que vous avez analysées, utilisés pour tracer la courbe de croissance et détecter les percées. Les instantanés sont pris au maximum une fois toutes les 5 minutes et supprimés après 48 heures. Ne contiennent aucune information d'identification — juste des chiffres.
_cacheVersion
Indicateur interne utilisé pour invalider le cache obsolète après une mise à jour de l'extension.

YT Radar ne dispose d'aucun système de compte utilisateur, aucune connexion, aucune collecte d'e-mail au sein de l'extension et aucune télémétrie. Toutes les clés ci-dessus sont supprimées automatiquement lorsque vous désinstallez l'extension ou cliquez sur "Supprimer toutes les données" dans les paramètres d'extension de votre navigateur.

🌐 3. Points d'accès externes expliqués

L'extension effectue quatre types de requêtes réseau. Chaque URL à laquelle elle se connecte est déclarée dans le champ de manifeste host_permissions de l'extension et visible par votre navigateur avant l'installation.

3a. YouTube Data API v3 (API publique de Google)

https://www.googleapis.com/youtube/v3/videos?chart=mostPopular&regionCode=... requis

Récupère la liste publique du Top 50 des tendances pour le pays que vous sélectionnez. C'est le même point d'accès public qui alimente l'onglet Tendances de YouTube.

Données envoyées : code pays (par ex. BR) · ID de catégorie facultatif · notre clé API · aucune donnée personnelle, aucune vidéo en cours de visionnage

https://www.googleapis.com/youtube/v3/videos?id=<videoId> requis (au besoin)

Récupère les détails publics de la vidéo que vous regardez, mais uniquement lorsqu'elle n'est pas déjà présente dans la liste du Top 50. C'est ce qui nous permet de calculer son score viral et ses métriques de croissance.

Données envoyées : ID de la vidéo YouTube · notre clé API · aucune donnée personnelle

Google peut journaliser ces requêtes conformément à sa propre politique de confidentialité. Nous n'envoyons aucune donnée personnelle supplémentaire avec elles.

3b. Worker NODUS YT Radar (Community Spotlight)

https://worker-yt-radar.mmcarvalho-dev.workers.dev/promotions?region=...&category=... requis

Demande à notre worker la vidéo promue active pour votre combinaison pays/catégorie, afin que nous puissions afficher la carte Community Spotlight.

Données envoyées : code pays · ID de catégorie · aucune identité, aucune vidéo en cours de visionnage, aucune IP stockée au-delà du journal de requêtes standard de Cloudflare

https://worker-yt-radar.mmcarvalho-dev.workers.dev/promotions/click au clic uniquement

Envoyé uniquement lorsque vous cliquez sur le bouton "Regarder" d'une carte Community Spotlight. Incrémente un compteur de clics agrégé afin que le créateur promu puisse voir comment son annonce a performé.

Données envoyées : ID de la promotion · rien d'autre

https://worker-yt-radar.mmcarvalho-dev.workers.dev/player?v=<videoId> iframe

Chargé sous forme d'iframe dans le carrousel Community Spotlight pour lire l'aperçu promotionnel. Le worker renvoie une petite page HTML qui intègre le lecteur YouTube.

Données envoyées : ID de la vidéo YouTube promue · chaîne et titre (utilisés uniquement comme libellés de l'iframe)

⭐ 4. Promotions Community Spotlight

Community Spotlight est la section, au sein du popup, qui affiche des vidéos YouTube organisées et soumises par des créateurs (offres gratuites ou payantes). Elle existe pour que les créateurs indépendants puissent gagner en visibilité sans réseaux publicitaires.

Ce que le worker stocke à propos d'une promotion

Lorsqu'un créateur soumet une vidéo sur nodus-ai.app/yt-radar, notre base de données Cloudflare D1 stocke : l'ID de la vidéo YouTube, le titre, la chaîne, l'URL de la miniature, l'offre (gratuite/bronze/argent/or), les régions et catégories ciblées, l'e-mail du soumissionnaire (à des fins de contact uniquement) et les compteurs agrégés de clics/vues. Ces informations sont fournies par le créateur, et non collectées auprès des utilisateurs de l'extension.

Et les utilisateurs de l'extension ?

Du côté de l'extension, nous ne stockons rien qui vous identifie. Le worker ne voit que : le pays et la catégorie que vous avez sélectionnés (afin de pouvoir associer une promotion appropriée) et — si vous cliquez — l'ID de la promotion. Nous ne journalisons pas la vidéo que vous regardiez, votre IP au-delà du traitement de requêtes standard de Cloudflare, l'empreinte de votre navigateur, ni aucun identifiant de compte.

Hébergement

Le worker s'exécute sur Cloudflare Workers. Cloudflare peut temporairement traiter des adresses IP et des métadonnées de requête dans le cadre du fonctionnement réseau standard (protection DDoS, routage). Nous n'écrivons pas d'adresses IP dans notre propre base de données.

🚫 5. Ce que nous ne faisons jamais

  • Vendre vos données à un tiers quelconque
  • Suivre quelles vidéos YouTube vous regardez — seul l'ID de la vidéo active est lu, et uniquement pour calculer son classement
  • Suivre quels sites web vous visitez en dehors de YouTube
  • Lire ou transmettre vos commentaires YouTube, votre historique de recherche, votre historique de visionnage ou les informations de votre compte
  • Utiliser des SDK publicitaires, des outils d'analyse tiers ou un suivi comportemental
  • Accéder à votre microphone, votre caméra, votre presse-papiers ou vos téléchargements
  • Injecter des publicités dans la page YouTube elle-même — la superposition n'affiche qu'un petit badge de classement que vous pouvez désactiver
  • Synchroniser l'une quelconque de vos données vers nos serveurs
  • Exiger un compte, une connexion ou un e-mail pour utiliser les fonctionnalités principales de l'extension

⚖️ 6. Vos droits (LGPD / GDPR)

YT Radar est conforme à la loi générale brésilienne sur la protection des données (LGPD) et au Règlement général sur la protection des données de l'UE (GDPR), et compatible avec la CCPA.

Vos droits

  • Accès — Toutes les données locales sont visibles via chrome://extensions → YT Radar → Inspecter les vues → Application → Stockage
  • Suppression — La désinstallation de l'extension efface automatiquement toutes les données de chrome.storage.local. Vous pouvez également les effacer manuellement dans les paramètres de votre navigateur
  • Données de promotion — Si vous avez soumis un élément Community Spotlight, vous pouvez le gérer ou le supprimer à l'aide du jeton d'accès affiché sur l'écran de succès du formulaire de soumission. Jeton perdu ? Contactez-nous avec l'e-mail utilisé lors de la soumission
  • Désactivation — Réglez la superposition sur "Désactivé" dans les Paramètres pour désactiver la superposition dans la page. Fermer le popup arrête toute activité réseau de l'extension

Base légale du traitement

Les récupérations du Top 50 et les recherches de détails de vidéo sont traitées au titre de l'intérêt légitime (fournir la fonctionnalité pour laquelle vous avez ouvert l'extension). Les soumissions de promotions Spotlight sont traitées au titre de l'exécution d'un contrat avec le créateur soumissionnaire. Aucun autre traitement n'a lieu.
