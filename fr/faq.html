Démarrer

6 questions

NODUS est une extension de navigateur qui vous permet de sauvegarder, organiser et réutiliser les réponses IA en un clic. Compatible avec ChatGPT, Claude, Gemini, Perplexity, Grok, Copilot et DeepSeek. Tout est stocké localement sur votre appareil — sans compte, sans serveur, sans abonnement obligatoire.

L'installation prend moins de 30 secondes :

  • Chrome / Edge / Brave : rendez-vous sur le Chrome Web Store et cliquez sur « Ajouter à Chrome »
  • Firefox : rendez-vous sur Mozilla Add-ons et cliquez sur « Ajouter à Firefox »

Après l'installation, ouvrez n'importe quelle plateforme IA prise en charge — les boutons NODUS apparaissent automatiquement.

Non. NODUS fonctionne sans inscription, sans e-mail, sans mot de passe. Installez et utilisez immédiatement. Vos données restent dans le stockage local de votre navigateur.

NODUS fonctionne sur :

  • Chrome (version 88+)
  • Firefox (version 109+)
  • Edge (basé sur Chromium)
  • Brave et autres navigateurs Chromium

En ouvrant une plateforme prise en charge, NODUS injecte des boutons flottants à côté des réponses IA. Cliquez sur Sauvegarder pour capturer la question et la réponse instantanément. Cliquez sur Rapide pour sauvegarder sans ouvrir le panneau de configuration. Cliquez sur Dash pour ouvrir votre tableau de bord.

NODUS prend en charge 7 plateformes actuellement :

  • ChatGPT (chat.openai.com)
  • Claude (claude.ai)
  • Gemini (gemini.google.com)
  • Perplexity (perplexity.ai)
  • Grok (grok.com / x.com)
  • Microsoft Copilot (copilot.microsoft.com)
  • DeepSeek (chat.deepseek.com)

Guide complet : sauvegarder les conversations Claude →

Installez NODUS et accédez à gemini.google.com. Les boutons de capture apparaissent à côté des réponses Gemini. Cliquez sur Sauvegarder pour enregistrer la conversation localement, avec des tags et la même organisation que pour les autres plateformes.

Guide complet : sauvegarder les conversations Gemini →

NODUS détecte automatiquement les réponses sur Perplexity.ai et injecte les boutons de capture. Cliquez sur Sauvegarder pour enregistrer la réponse avec les sources citées. Idéal pour les recherches que vous voudrez consulter plus tard.

NODUS fonctionne aussi bien sur grok.com que sur x.com/grok. En ouvrant une conversation avec Grok, les boutons de capture apparaissent à côté des réponses. Cliquez sur Sauvegarder pour archiver localement dans votre tableau de bord NODUS.

La Capture Rapide (bouton Rapide) sauvegarde la réponse directement dans la file par défaut sans ouvrir le panneau de configuration. Idéal pour enregistrer rapidement sans interrompre le fil de la conversation. La capture est disponible dans le panneau pour être organisée ultérieurement.

Installez NODUS et utilisez le bouton Rapide dès qu'une réponse vous semble utile — même si vous ne savez pas encore pourquoi. L'habitude de capturer avant de fermer l'onglet élimine la perte d'information. Votre panneau accumule tout et la recherche par texte vous permet de retrouver n'importe quelle capture ensuite.

Exporter et télécharger

7 questions

Ouvrez votre tableau de bord NODUS, sélectionnez la capture souhaitée et cliquez sur Exporter → DOCX. Le fichier Word est généré directement dans votre navigateur et enregistré sur votre ordinateur. Vous pouvez enchaîner plusieurs captures avec les Chaînes et tout exporter ensemble sous forme de document structuré.

NODUS exporte en HTML, que vous pouvez imprimer en PDF directement depuis le navigateur (Ctrl+P → Enregistrer au format PDF). Pour un export direct en PDF, nous recommandons d'exporter en HTML et d'utiliser la fonction d'impression du navigateur — le résultat est bien mis en forme.

NODUS prend en charge l'export en :

  • TXT — texte simple, compatible avec tout éditeur
  • HTML — formaté, imprimable en PDF
  • DOCX — compatible avec Word, Google Docs et LibreOffice

Les captures enchaînées (Chaînes) peuvent être exportées ensemble sous forme de document unique.

Dans le tableau de bord NODUS, accédez à Paramètres → Exporter tout. Cela génère un fichier avec toutes vos captures au format JSON (pour réimporter dans NODUS), ou vous pouvez exporter chaque file individuellement en DOCX ou HTML.

Dans la vue d'une carte du tableau de bord, cliquez sur Copier. Le contenu est copié avec la mise en forme Markdown préservée — titres, listes, code — prêt à coller dans tout éditeur compatible Markdown.

Oui. Dans Paramètres → Exporter les données, vous téléchargez un fichier JSON contenant toutes vos captures. Ce fichier peut être réimporté dans NODUS sur un autre ordinateur ou après avoir réinstallé l'extension.

Utilisez les Chaînes pour relier des captures liées provenant de sessions différentes (même de plateformes différentes). Puis exportez la chaîne entière en DOCX — le résultat est un document structuré avec toutes les questions et réponses enchaînées dans un ordre logique.

Organiser

7 questions

Lors de la sauvegarde d'une capture, vous pouvez ajouter jusqu'à 4 tags pour catégoriser le contenu. Les tags apparaissent sur les cartes du tableau de bord et fonctionnent comme des filtres — cliquez sur un tag pour voir uniquement les captures de cette catégorie. Créez des tags comme « backend », « étude », « idées », « travail » ou toute catégorie qui vous convient.

Les files sont des collections séparées pour organiser les captures par contexte ou priorité. La Quick Queue est pour les captures rapides, sans catégorisation. La Default est la file générale. Les files Q1–Q4 (plan PRO) sont personnalisables par thème, projet ou client. Chaque file a une couleur de bordure différente sur les cartes.

Dans le tableau de bord NODUS, utilisez la barre de recherche en haut. La recherche fonctionne en temps réel et couvre le titre, la question et la réponse de toutes les captures. Combinez la recherche avec les filtres par plateforme ou par tag pour trouver exactement ce que vous cherchez.

Dans le tableau de bord, cliquez sur les badges de plateforme sous la barre de recherche. Cliquez sur ChatGPT, Claude, Gemini ou toute autre plateforme pour voir uniquement les captures de cette source. Cliquez à nouveau pour retirer le filtre.

Les Projets (plan PRO) permettent de créer des espaces entièrement séparés — par exemple « Travail », « Études » et « Personnel ». Chaque projet a ses propres files et captures. Changez de projet en un clic sans mélanger les contenus.

Oui. Ouvrez la carte dans le tableau de bord et cliquez sur Modifier. Vous pouvez changer le titre, ajouter ou retirer des tags et déplacer la capture entre les files. Le contenu original (question + réponse) est préservé.

Utilisez la recherche par texte dans le tableau de bord — elle couvre le contenu complet de toutes les captures, pas seulement le titre. Si vous vous souvenez d'un mot-clé de la réponse, il suffit de le taper. Combinez avec le filtre par plateforme (ex : Claude) si vous savez d'où elle provient.

Chaînes

6 questions

Les Chaînes permettent de relier des captures de conversations différentes dans une séquence logique. Imaginez que vous avez recherché un sujet sur ChatGPT, approfondi sur Claude et trouvé des exemples sur Gemini — une Chaîne relie ces trois captures en un fil de raisonnement continu, même si elles proviennent de plateformes différentes.

Dans l'onglet Chaînes du tableau de bord, cliquez sur « Nouvelle Chaîne ». Donnez un nom à la chaîne et ajoutez des captures existantes en les faisant glisser dans l'ordre souhaité. Vous pouvez ajouter des captures de n'importe quelle plateforme et les réorganiser à tout moment.

Oui — c'est l'un des principaux avantages des Chaînes. Vous pouvez relier des captures de ChatGPT, Claude, Gemini, Perplexity et toute autre plateforme prise en charge dans une seule séquence. Chaque carte conserve l'identification de la plateforme d'origine.

Ouvrez la Chaîne dans le tableau de bord et cliquez sur Exporter. Vous pouvez exporter la séquence complète en DOCX ou HTML — le résultat est un document structuré avec toutes les questions et réponses dans l'ordre, idéal pour des rapports, des études ou de la documentation.

Dans le plan gratuit, chaque Chaîne peut contenir jusqu'à 5 captures. Dans le plan PRO, la limite est nettement plus élevée, permettant des chaînes étendues pour les projets complexes.

Grâce à la fonction d'injection, vous pouvez insérer le contenu d'une Chaîne directement dans le champ de prompt de n'importe quelle plateforme prise en charge. C'est comme donner à l'IA le contexte complet de recherches antérieures — sans copier-coller manuellement chaque réponse.

Confidentialité et sécurité

7 questions

Non. NODUS ne dispose d'aucun serveur propre qui reçoit vos captures. Tout est stocké dans le stockage local de votre navigateur (chrome.storage.local / browser.storage.local). Aucune capture, aucun tag, aucun contenu ne quitte votre appareil.

Non. NODUS ne lit le contenu de la page que lorsque vous cliquez activement sur Sauvegarder ou Rapide. Il n'y a pas de capture automatique, de surveillance passive ni de lecture des conversations que vous n'avez pas choisi de sauvegarder.

Les captures sont stockées dans le profil de navigateur de votre compte utilisateur du système d'exploitation. Si votre profil utilisateur est protégé par un mot de passe, les captures le sont également. NODUS n'ajoute pas de chiffrement supplémentaire — utilisez les protections de votre système d'exploitation pour la sécurité physique.

Oui. Le cœur de NODUS est disponible sur GitHub sous licence MIT. Chacun peut auditer le code et vérifier qu'il n'existe aucune collecte de données cachée. Vous n'avez pas à nous croire sur parole — consultez le code.

En désinstallant l'extension, le stockage local associé est effacé par le navigateur. Faites une sauvegarde avant : accédez à Paramètres → Exporter les données pour télécharger toutes vos captures en JSON. Vous pouvez les réimporter après avoir réinstallé l'extension.

NODUS ne demande que les permissions nécessaires à son fonctionnement :

  • Lecture des pages IA — pour détecter les réponses et injecter les boutons
  • Stockage local — pour sauvegarder vos captures sur l'appareil
  • Accès aux onglets — pour savoir sur quelle plateforme vous vous trouvez

Aucune permission d'accès à la caméra, au microphone, à l'historique de navigation ou aux mots de passe n'est demandée.

Le tableau de bord NODUS fonctionne entièrement hors ligne — vous pouvez accéder, rechercher et exporter des captures sans connexion Internet. La capture de nouvelles conversations nécessite une connexion car les plateformes IA elles-mêmes doivent être accessibles.
