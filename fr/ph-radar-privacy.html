🔍 1. Aperçu

NODUS PH Radar est une extension de navigateur local-first (Chrome). Elle vous offre une profondeur historique sur Product Hunt — suivi de la course quotidienne, analyses de vélocité, règles de surveillance, onglets de hunters et un calendrier de lancements — le tout dans un panneau latéral. Les réglages, les caches, les produits épinglés, les notes et les règles de surveillance restent dans votre navigateur. Il n'y a aucun compte utilisateur, aucune connexion, aucune synchronisation dans le cloud pour les fonctionnalités principales.

Il s'agit d'un produit distinct de l'extension NODUS principale (capture de conversations IA) et de NODUS YT Radar. Si vous cherchez l'une de ces politiques, consultez Confidentialité de NODUS ou Confidentialité de YT Radar.

PH Radar établit des connexions externes uniquement à trois fins, chacune documentée ci-dessous :

obligatoire Product Hunt API v2 (publique)

Utilisée pour récupérer les données publiques des produits (course quotidienne, nombre de votes, informations sur le hunter) pour les produits que vous suivez. Lecture seule, données publiques uniquement — nous n'accédons jamais aux identifiants de votre compte PH.

obligatoire Community Spotlight

Récupère une promotion de produit sélectionnée et adaptée à votre région depuis notre worker. N'envoie que votre code pays — aucune identité, aucun historique de navigation, aucune information de votre compte Product Hunt.

au clic Comptage des clics sur les promotions

Si vous cliquez sur un produit Spotlight, un événement de clic anonyme est enregistré afin que le maker sache comment son annonce a performé. Seul l'ID de la promotion est envoyé.

💾 2. Données stockées localement sur votre appareil

Tout ce qui suit est stocké dans chrome.storage.local ou dans IndexedDB local — cela ne réside que sur votre ordinateur et n'est jamais envoyé à aucun serveur NODUS, sauf description explicite dans la Section 3.

settings
Vos préférences : langue de l'interface, régions préférées, mode overlay, intervalle d'actualisation et choix de mise en page de la barre latérale.
ph_token
Votre Jeton Personnel de l'API Product Hunt (facultatif). Utilisé uniquement pour récupérer les données publiques du classement — jamais envoyé aux serveurs NODUS, seulement à l'API propre de Product Hunt. Vous pouvez l'effacer à tout moment depuis les réglages de l'extension.
ph_snapshots_<date> (IndexedDB)
Instantanés quotidiens des métriques publiques des produits (nombre de votes, hunter, tagline) pour les produits apparus dans la course du jour. Utilisés pour construire le graphique de vélocité et la chronologie quotidienne. Stockés dans IndexedDB local ; supprimés automatiquement après 30 jours.
ph_pins
Les produits que vous avez épinglés pour les surveiller. Stockés localement ; jamais envoyés à nos serveurs.
ph_notes_<productId>
Les notes que vous avez rédigées pour un produit suivi. Stockées localement ; jamais envoyées à nos serveurs.
ph_watch_rules
Les règles d'alerte que vous avez définies (p. ex. « notifier lorsque les votes > 200 »). Stockées localement ; les déclencheurs sont évalués dans le navigateur.
spotlight_token
Votre jeton d'accès Spotlight (UUID généré dans le navigateur lors de la soumission). Utilisé uniquement pour récupérer vos propres promotions depuis le tableau de bord. Stocké localement ; sur notre serveur, nous ne conservons qu'un hachage SHA-256 de ce jeton — le texte en clair n'est jamais transmis après la soumission initiale.
_cacheVersion
Indicateur interne utilisé pour invalider le cache obsolète après une mise à jour de l'extension.

PH Radar ne dispose pas de système de compte utilisateur. Votre jeton PH, vos produits épinglés, vos notes, vos règles de surveillance et vos instantanés sont tous supprimés automatiquement lorsque vous désinstallez l'extension ou effacez les données de l'extension dans les réglages de votre navigateur.

🌐 3. Points de terminaison externes expliqués

L'extension effectue les types de requêtes réseau suivants. Chaque domaine est déclaré dans le champ de manifeste host_permissions de l'extension et est visible par votre navigateur avant l'installation.

3a. API GraphQL v2 de Product Hunt (publique)

https://api.producthunt.com/v2/api/graphql obligatoire

Récupère le classement public de la course quotidienne, les détails des produits (titre, tagline, miniature, votes, hunter) et les statistiques du profil du hunter. Ce sont les mêmes données publiques visibles sur producthunt.com.

Données envoyées : requête GraphQL pour les données publiques produits/hunters · votre Jeton Personnel PH (uniquement vers les serveurs propres de Product Hunt — pas les nôtres) · aucune donnée personnelle collectée par NODUS

3b. Worker NODUS PH Radar (Community Spotlight)

https://worker-ph-radar.mmcarvalho-dev.workers.dev/spotlight?region=... obligatoire

Demande les promotions de produits Spotlight actives pour votre région afin de pouvoir remplir le bandeau du panneau latéral.

Données envoyées : code pays · aucune identité, aucune information de compte PH, aucune IP stockée au-delà du journal de requêtes standard de Cloudflare

https://worker-ph-radar.mmcarvalho-dev.workers.dev/spotlight/click au clic uniquement

Envoyé uniquement lorsque vous cliquez sur un produit Spotlight dans le panneau latéral. Incrémente un compteur de clics agrégé pour le tableau de bord de reporting du maker.

Données envoyées : ID de la promotion · rien d'autre

https://worker-ph-radar.mmcarvalho-dev.workers.dev/spotlight/impression à l'affichage

Envoyé lorsqu'une carte Spotlight devient visible dans le bandeau (comptée au plus une fois par session et par promotion). Utilisé pour le reporting agrégé des impressions.

Données envoyées : ID de la promotion · rien d'autre

3c. Soumission de promotion (makers uniquement, facultatif)

https://worker-ph-radar.mmcarvalho-dev.workers.dev/promotions/submit maker uniquement · à la soumission

Appelé uniquement lorsqu'un maker remplit le formulaire de soumission Community Spotlight sur nodus-ai.app/ph-radar. N'est pas déclenché par l'utilisation normale de l'extension.

Données envoyées : URL du produit Product Hunt · adresse e-mail · tagline, date de lancement, sujets et régions facultatifs · tier · jeton d'accès (UUID, généré côté client)

⭐ 4. Promotions Community Spotlight

Community Spotlight est le bandeau en bas du panneau latéral de PH Radar qui présente des produits Product Hunt sélectionnés et soumis par des makers (tiers gratuits ou payants). Il existe pour que les makers indépendants puissent gagner en visibilité sans réseaux publicitaires.

Ce que le worker stocke à propos d'une promotion

Lorsqu'un maker soumet un produit sur nodus-ai.app/ph-radar, notre base de données Cloudflare D1 stocke : l'URL et le slug du produit Product Hunt, le titre, la tagline, l'URL de la miniature, le nom d'utilisateur du hunter, le tier (free / bronze / silver / gold), les régions et sujets ciblés, la date de lancement facultative, l'e-mail du soumetteur (uniquement pour les notifications transactionnelles) et les compteurs agrégés d'impressions/clics. Ces informations sont fournies volontairement par le maker, elles ne sont pas collectées auprès des utilisateurs de l'extension.

Jetons d'accès

Au moment de la soumission, votre navigateur génère un jeton d'accès UUID à l'aide de crypto.randomUUID(). Ce jeton s'affiche une seule fois à l'écran — vous le copiez et le conservez. Sur notre serveur, nous ne stockons que le hachage SHA-256 de ce jeton. Nous pouvons le vérifier mais pas l'inverser pour récupérer votre jeton en clair. Le jeton vous permet de consulter et de gérer vos propres promotions via le tableau de bord.

Tiers payants — traitement des paiements par Paddle

Pour les tiers payants (Bronze 1 $, Silver 3 $, Gold 7 $), les paiements sont traités par Paddle (voir la Section 5 pour les détails du sous-traitant). Votre adresse e-mail et vos informations de paiement sont collectées par Paddle, et non par NODUS. Nous recevons uniquement un événement de confirmation de paiement depuis le webhook de Paddle, qui comprend votre e-mail et un ID de transaction afin que nous puissions activer votre formule.

Et les utilisateurs de l'extension ?

Du côté de l'extension, nous ne stockons rien qui vous identifie. Le worker ne reçoit que : le code de région pour la correspondance Spotlight et — si vous cliquez ou affichez — l'ID de la promotion. Nous n'enregistrons pas quels produits vous suivez, ni votre IP au-delà du traitement standard des requêtes de Cloudflare, ni l'empreinte de votre navigateur, ni aucun identifiant de compte.

Hébergement

Le worker s'exécute sur Cloudflare Workers avec une base de données Cloudflare D1. Cloudflare peut traiter temporairement des adresses IP et des métadonnées de requêtes dans le cadre du fonctionnement réseau standard (protection DDoS, routage). Nous n'écrivons pas d'adresses IP dans notre propre base de données.

🚫 6. Ce que nous ne faisons jamais

  • Vendre vos données à un tiers
  • Lire les identifiants de votre compte Product Hunt, vos DM, vos projets privés ou votre historique d'achats
  • Transmettre votre Jeton Personnel PH aux serveurs NODUS — il ne va qu'à l'API propre de Product Hunt
  • Suivre quels produits vous parcourez sur producthunt.com en dehors du panneau latéral de l'extension
  • Suivre quels sites web vous visitez en dehors de Product Hunt
  • Utiliser des SDK publicitaires, des analyses tierces ou des cookies de suivi comportemental
  • Accéder à votre microphone, votre caméra, votre presse-papiers ou vos téléchargements
  • Synchroniser les produits épinglés, les notes, les règles de surveillance ou les instantanés de votes vers nos serveurs — toutes ces données restent sur votre appareil
  • Exiger un compte, une connexion ou un e-mail pour utiliser les fonctionnalités principales de l'extension
  • Partager les données de soumission des makers (e-mail, URL du produit) avec des tiers autres que les sous-traitants énumérés dans la Section 5

⚖️ 7. Vos droits (LGPD / GDPR)

PH Radar est conforme à la Loi générale brésilienne sur la protection des données (LGPD) et au Règlement général sur la protection des données de l'UE (GDPR), et compatible avec la CCPA.

Droits dont vous disposez en tant qu'utilisateur de l'extension

  • Accès — Toutes les données locales sont visibles via chrome://extensions → PH Radar → Inspecter les vues → Application → Stockage / IndexedDB
  • Suppression — Retirer l'extension efface automatiquement toutes les données de chrome.storage.local et d'IndexedDB. Vous pouvez aussi les effacer manuellement dans les réglages de votre navigateur
  • Jeton PH — Vous pouvez effacer votre jeton Product Hunt à tout moment depuis la page de réglages de l'extension. Il n'est jamais envoyé aux serveurs NODUS
  • Désinscription — Vous pouvez désactiver le bandeau Spotlight dans les réglages de l'extension. Fermer le panneau latéral arrête toute activité réseau de l'extension

Droits dont vous disposez en tant que maker (soumetteur Spotlight)

  • Accès & suppression — Utilisez le jeton d'accès affiché au moment de la soumission pour consulter ou supprimer vos promotions via le tableau de bord sur nodus-ai.app/ph-radar#dashboard
  • Jeton perdu — Contactez-nous avec l'e-mail utilisé lors de la soumission et nous supprimerons vos données après vérification d'identité
  • Données de paiement — Pour les données de facturation (historique des paiements, factures), contactez directement Paddle sur paddle.com/legal/privacy ou via le lien du portail acheteur dans votre e-mail d'achat

Base légale du traitement

Les récupérations de l'API Product Hunt sont traitées au titre de l'intérêt légitime (fournir la fonctionnalité pour laquelle vous avez ouvert l'extension). Les soumissions de promotions Spotlight et les paiements sont traités au titre de l'exécution du contrat avec le maker soumetteur. Les e-mails transactionnels sont envoyés au titre de l'exécution du contrat. Aucun autre traitement n'a lieu.

Conservation des données

Les promotions actives sont conservées pendant la durée de la formule plus 90 jours à des fins de reporting. Les promotions expirées et les statistiques agrégées associées peuvent être supprimées à la demande du maker. Les adresses e-mail ne sont conservées que tant que la formule associée est active ou en attente, sauf si vous demandez une suppression anticipée.
