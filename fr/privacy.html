🔍 1. Aperçu

NODUS est une extension de navigateur local-first. Tout ce que vous capturez — idées, notes, extraits, tags, chaînes et projets — est stocké exclusivement dans le stockage local de votre navigateur (chrome.storage.local) et n'est jamais envoyé vers aucun serveur.

NODUS effectue deux types de connexions externes, toutes deux clairement décrites dans ce document :

opt-in Télémétrie anonyme

Désactivée par défaut. Si vous choisissez de l'activer, seules des statistiques d'utilisation agrégées sont envoyées — jamais votre contenu.

PRO only Validation de licence

Uniquement pour les abonnés PRO payants. Envoie une empreinte d'appareil hachée et votre adresse e-mail pour vérifier la licence. Aucun contenu de conversation n'est jamais inclus.

💾 2. Données stockées localement sur votre appareil

Tout ce qui suit est stocké dans chrome.storage.local — c'est-à-dire qu'il réside uniquement sur votre ordinateur et n'est jamais envoyé nulle part, sauf si vous l'exportez explicitement.

  • Idées, notes et extraits capturés
  • Tags et affectations de file d'attente
  • Chaînes et modèles de chaînes
  • Projets et métadonnées de projets
  • Préférences de mise en page du tableau de bord
  • Paramètres de langue et d'animation
  • File d'attente d'événements de télémétrie (si opt-in activé)
  • ID anonyme — un hash SHA-256 généré localement avec un sel aléatoire, jamais lié à votre identité

NODUS ne dispose pas de système de compte utilisateur. Il n'y a pas de synchronisation cloud, pas de profil côté serveur et aucun moyen pour nous de vous identifier à partir des données stockées localement.

🌐 3. Points de terminaison externes expliqués

NODUS se connecte à des URL externes dans trois scénarios : télémétrie (opt-in), validation de licence (PRO uniquement) et lecture de fichiers que vous avez déjà téléversés sur des plateformes d'IA. Voici chaque point de terminaison utilisé et exactement ce qui est envoyé.

3a. Infrastructure NODUS

https://nodus-worker.mmcarvalho-dev.workers.dev/telemetry/batch opt-in only

Reçoit des statistiques d'utilisation anonymes et agrégées. Appelé uniquement si vous avez activé la télémétrie dans les Paramètres. Consultez la Section 4 pour tous les détails.

Données envoyées : ID anonyme (hash SHA-256) · comptages de types d'événements · comptages de plateformes · aucun contenu de conversation · aucune URL · aucun texte

https://nodus-worker.mmcarvalho-dev.workers.dev/auth/status PRO only

Valide votre licence PRO au démarrage. Appelé uniquement si vous avez saisi un token de licence. Consultez la Section 5 pour tous les détails.

Données envoyées : adresse e-mail · empreinte d'appareil hachée · aucun contenu de conversation

3b. Accès aux fichiers sur les plateformes d'IA

Ces points de terminaison sont accédés en mode read-only lorsque vous déclenchez la Capture Complète du Chat ou les fonctionnalités de pièces jointes. NODUS lit le contenu du fichier pour l'afficher ou le sauvegarder localement. Rien n'est téléversé vers les serveurs de NODUS.

https://files.oaiusercontent.com/*  ·  https://*.oaiusercontent.com/*  ·  https://cdn.openai.com/* read-only

Fichiers et images téléversés par l'utilisateur dans les conversations ChatGPT (images, PDFs, pièces jointes). NODUS lit ces fichiers localement pour les inclure dans la Capture Complète du Chat.

https://*.anthropic.com/* read-only

Fichiers, artefacts et pièces jointes téléversés par l'utilisateur dans les conversations Claude.ai. Accédés localement pour prendre en charge la Capture Complète du Chat.

https://storage.googleapis.com/* read-only

Fichiers téléversés par l'utilisateur dans les conversations Gemini. Accédés localement pour prendre en charge la Capture Complète du Chat.

https://*.blob.core.windows.net/* read-only

Fichiers téléversés par l'utilisateur dans les conversations Microsoft Copilot. Accédés localement pour prendre en charge la Capture Complète du Chat.

📊 4. Télémétrie anonyme optionnelle

La télémétrie est désactivée par défaut. Vous devez l'activer explicitement dans Paramètres → Télémétrie. Vous pouvez la désactiver à tout moment et toutes les données en file d'attente localement sont effacées immédiatement.

Ce que la télémétrie collecte (lorsqu'elle est activée)

  • Comptages de types d'événements (ex. : « 3 sauvegardes, 1 injection ») — sans contenu, sans texte
  • Comptages de plateformes (ex. : « utilisé sur ChatGPT 2 fois ») — sans URLs
  • ID anonyme — un hash SHA-256 généré localement, non lié à votre identité
  • Comptages de sessions agrégés par jour (regroupement temporel)

Ce que la télémétrie ne collecte jamais

  • Contenu des conversations, prompts ou réponses d'IA
  • URLs visitées ou titres de pages
  • Votre nom, e-mail ou toute information d'identification
  • Adresse IP (non stockée par notre worker)
  • Spécifications de l'appareil ou empreinte du navigateur

Comment les données sont traitées avant l'envoi

Les événements sont agrégés localement avant transmission. Plutôt que d'envoyer des événements bruts, NODUS envoie des compteurs agrégés (ex. : combien de sauvegardes ont eu lieu, sur quelle plateforme) avec un bruit de préservation de la vie privée appliqué (±2 de décalage aléatoire par compteur). Les événements bruts ne quittent jamais votre appareil.

Conservation des données

Les données de télémétrie agrégées sont conservées sur nos serveurs pendant 12 mois maximum, après quoi elles sont supprimées. Les journaux d'événements locaux sont conservés 90 jours dans le stockage de votre navigateur, puis automatiquement nettoyés.

🔑 5. Validation de la licence PRO

Si vous achetez NODUS PRO, l'extension valide votre licence avec notre serveur au démarrage. C'est le minimum requis pour vérifier un abonnement payant.

Ce qui est envoyé lors de la validation de la licence

  • Votre adresse e-mail (telle que saisie lors de l'activation)
  • Une empreinte d'appareil hachée (identifiant généré par le navigateur, pas le numéro de série de votre matériel)

Ce qui n'est jamais envoyé

  • Contenu des conversations ou quoi que ce soit que vous avez capturé
  • Votre adresse IP (non stockée, utilisée uniquement pour le routage par Cloudflare)
  • Données de télémétrie (ce sont des systèmes séparés)

Les données de licence sont stockées dans une base de données Cloudflare D1 (région Brésil/Amérique du Sud). Elles sont utilisées uniquement pour vérifier si votre abonnement est actif. Elles ne sont jamais vendues ni partagées avec des tiers.

La version GRATUITE de NODUS fonctionne entièrement hors ligne et ne contacte jamais notre serveur de licences.

📎 6. Accès aux fichiers sur les plateformes d'IA

Lorsque vous utilisez la Capture Complète du Chat ou les fonctionnalités de pièces jointes, NODUS peut récupérer des fichiers que vous avez déjà téléversés sur une plateforme d'IA (ChatGPT, Claude, Gemini, Copilot) pour les inclure dans votre capture locale.

Cet accès est read-only et local. NODUS lit le contenu du fichier directement depuis le CDN de la plateforme d'IA dans la mémoire de votre navigateur et le sauvegarde dans votre stockage local (chrome.storage.local). Le fichier n'est jamais re-téléversé vers aucun serveur NODUS.

Les autorisations de navigateur requises pour cela (*.oaiusercontent.com, *.anthropic.com, storage.googleapis.com, *.blob.core.windows.net) permettent à NODUS de lire ces fichiers. Elles n'autorisent pas NODUS à écrire, modifier ou transmettre vos données sur ces plateformes.

🚫 7. Ce que nous ne faisons jamais

  • Vendre vos données à des tiers
  • Lire, stocker ou transmettre le contenu de vos conversations
  • Suivre les sites web que vous visitez en dehors des plateformes d'IA
  • Utiliser des SDK publicitaires ou des outils d'analyse tiers
  • Injecter des publicités ou des liens d'affiliation dans les plateformes d'IA
  • Accéder à votre microphone, caméra ou presse-papiers sans action de votre part
  • Synchroniser vos données capturées avec un cloud quelconque sans votre exportation explicite

⚖️ 8. Vos droits (LGPD / GDPR)

NODUS est conforme à la Lei Geral de Proteção de Dados brésilienne (LGPD) et au Règlement général sur la protection des données de l'UE (GDPR), et compatible avec la CCPA.

Droits dont vous disposez

  • Accès — Toutes les données stockées localement sont visibles et exportables depuis le tableau de bord NODUS à tout moment
  • Suppression — Vous pouvez supprimer toutes les données locales depuis Paramètres → Effacer toutes les données. Désinstaller l'extension supprime également toutes les données locales
  • Portabilité — Exportez toutes vos idées en JSON, Markdown ou DOCX à tout moment
  • Opt-out — Désactivez la télémétrie à tout moment dans Paramètres → Télémétrie
  • Suppression des données de licence — Contactez-nous pour demander la suppression de votre e-mail de notre base de données de licences

Base légale du traitement

La télémétrie est traitée sur la base du consentement (opt-in). La validation de licence est traitée sur la base de l'exécution du contrat (vérification d'un abonnement payant). Aucun autre traitement n'a lieu.
