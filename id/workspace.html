FAQ

Pertanyaan, terjawab.

Apakah file saya disimpan di cloud?

Tidak. Semua yang Anda buat atau impor — dokumen, spreadsheet, PDF, klip, catatan, dan gambar — disimpan secara lokal di perangkat Anda, di dalam browser. Tidak ada yang diunggah kepada kami atau pihak lain.

Di mana tepatnya data saya disimpan?

Di penyimpanan lokal bawaan browser, di perangkat Anda — tempat yang sama dengan data situs yang disimpan browser. Tidak ada yang dikirim ke server NODUS, menjadikan Workspace alternatif lokal untuk alat kantor berbasis cloud: file Anda selalu ada bersama Anda dan bisa digunakan offline.

Apakah saya perlu akun untuk menggunakannya?

Tidak. Workspace berfungsi tanpa pendaftaran dan tanpa login. Anda hanya perlu memasukkan email jika memilih untuk mengaktifkan NODUS PRO.

Apakah bisa digunakan secara offline?

Ya. Karena bersifat lokal, Anda bisa membuat, mengedit, dan membaca file tanpa koneksi internet.

Apa yang terjadi jika saya ganti komputer atau instal ulang browser?

Data Anda hanya ada di perangkat itu, sehingga pemindahannya ada di tangan Anda: gunakan fitur Backup & Pemulihan terenkripsi (fitur PRO) untuk mengekspor semua data ke sebuah file dan memulihkannya di perangkat lain. Tanpa backup, data lokal hanya ada di browser tersebut.

File apa saja yang bisa saya masukkan?

Seret dan lepas PDF, DOCX, XLSX, TXT, gambar, dan Markdown langsung ke panel. Aturannya sederhana: membawa konten masuk selalu gratis.

Bisakah saya mengedit file Word dan Excel?

Anda bisa membukanya — DOCX masuk sebagai teks biasa dan XLSX sebagai nilai (pemformatan dan rumus disederhanakan). Lebih baik terbuka tanpa pemformatan daripada tidak sama sekali. Mengekspor kembali ke DOCX/XLSX (dan gambar) adalah fitur PRO.

Apa yang gratis dan apa yang PRO?

Gratis: membuat dan mengedit dokumen dan spreadsheet, membaca/mencari/mencetak PDF, klip web, catatan, pengingat, impor file, dan 16 bahasa. PRO menambahkan ekspor (DOCX, XLSX, PNG), PDF ke gambar, backup terenkripsi, alarm aktif dengan notifikasi, dan aksi massal.
