Kebijakan Privasi

NODUS Workspace  ·  Terakhir diperbarui: Juni 2026
Versi singkat: NODUS Workspace mengutamakan penyimpanan lokal. Dokumen, spreadsheet, PDF, klip web, catatan, dan gambar Anda tersimpan di perangkat Anda, di dalam browser Anda. Tidak ada server NODUS untuk konten Anda, kami tidak memiliki akun untuk Anda, dan kami tidak pernah melihat file Anda. Tidak ada yang bisa bocor.

1.Apa itu NODUS Workspace

NODUS Workspace adalah ekstensi browser yang berjalan di panel samping browser Anda. Semua yang Anda buat atau impor disimpan secara lokal di penyimpanan browser Anda, di mesin Anda sendiri — bukan di server kami.

2.Apa yang kami kumpulkan

Tidak ada informasi tentang konten Anda. Tidak diperlukan pendaftaran atau akun untuk menggunakan Workspace. Kami tidak menjalankan analitik atau telemetri terhadap apa yang Anda tulis, buka, impor, atau gambar, dan tidak ada server NODUS yang menerima file, catatan, atau pengaturan Anda. Satu-satunya data yang meninggalkan perangkat Anda terkait dengan fitur opsional — validasi lisensi PRO dan promosi Spotlight — yang dijelaskan di bagian 8 dan 9, dan itu tidak pernah mencakup file Anda.

3.Apa yang tetap di perangkat Anda

Dokumen, spreadsheet, PDF, klip, catatan, gambar, folder, dan preferensi Anda hanya disimpan di profil browser Anda, di komputer Anda. Semuanya tidak pernah diunggah ke mana pun oleh Workspace.

4.Cadangan milik Anda — dan terenkripsi

Saat Anda mengekspor cadangan, file tersebut dienkripsi dengan AES-256 menggunakan kata sandi yang Anda tentukan. Kami tidak pernah menerima file tersebut, dan hanya Anda yang dapat mendekripsinya. Jika Anda kehilangan kata sandi, tidak ada seorang pun — termasuk kami — yang dapat memulihkan isinya.

5.Izin browser, dan alasannya

Ekstensi hanya meminta izin yang diperlukan untuk berjalan secara lokal:

  • Penyimpanan (Storage) — untuk menyimpan dokumen, file, dan pengaturan Anda di perangkat Anda.
  • Panel samping (Side panel) — untuk menampilkan Workspace di samping halaman yang sedang Anda buka.
  • Pembacaan tab aktif (Active-tab / page reading) — hanya saat Anda mengklip sesuatu dari sebuah halaman. Ekstensi tidak membaca atau melacak aktivitas browsing Anda di latar belakang.

6.Tanpa kode jarak jauh

Seluruh kode ekstensi dikirimkan di dalam paket yang diterbitkan. Tidak ada yang diunduh dari server dan dijalankan saat runtime. Yang Anda instal adalah persis yang berjalan.

7.Pihak ketiga

NODUS Workspace sendiri tidak menggunakan pihak ketiga. Satu-satunya pengecualian bersifat opsional: jika Anda memilih untuk membeli NODUS PRO, pembayaran diproses oleh Paddle (Merchant of Record kami), sesuai dengan kebijakan privasi Paddle. Pembelian PRO sepenuhnya terpisah dari file Anda.

8.NODUS PRO — validasi lisensi

Jika Anda mengaktifkan PRO, langganan Anda divalidasi dengan mengirimkan dua hal ke endpoint lisensi kami: email langganan Anda dan sebuah sidik jari perangkat (device fingerprint — hash satu arah yang mengidentifikasi instalasi, agar satu lisensi tidak digunakan di perangkat tanpa batas). Itulah satu-satunya yang diperiksa — dokumen, catatan, dan isi file Anda tidak pernah disertakan. Satu langganan NODUS PRO membuka akses PRO di seluruh NODUS AI, PH Radar, dan Workspace.

9.Community Spotlight (promosi opsional)

Jika Anda memilih untuk mempromosikan sesuatu melalui Spotlight, catatan promosi — yang diidentifikasi dengan sebuah promotionId — dibuat dengan detail yang Anda kirimkan (seperti judul, tautan, dan opsi penargetan) serta email untuk notifikasi. Kami menyimpan agregat jumlah tayangan dan klik untuk promosi tersebut. Ini sepenuhnya bersifat sukarela dan Anda yang memulainya; tidak ada yang diambil dari file atau catatan pribadi Workspace Anda.

10.Anak-anak

Workspace tidak ditujukan untuk anak-anak di bawah usia 13 tahun, dan kami tidak dengan sengaja mengumpulkan data pribadi dari mereka.

11.Kendali & hak Anda

Karena file Anda tersimpan di perangkat Anda, Anda memiliki kendali penuh atas file tersebut: ekspor, hapus, atau copot pemasangan ekstensi untuk menghapus semuanya. Berdasarkan undang-undang privasi seperti GDPR Uni Eropa dan LGPD Brasil, Anda memiliki hak atas data pribadi Anda — untuk data akun/promosi terbatas yang dijelaskan di atas (email langganan, sidik jari perangkat, promotionId), kirim email kepada kami untuk mengakses atau menghapusnya. Konten file Anda tidak pernah disimpan di server mana pun, sehingga tidak ada yang perlu diminta di sana.

12.Perubahan kebijakan ini

Kami dapat memperbarui kebijakan ini seiring perkembangan produk. Perubahan signifikan akan tercermin di sini dengan tanggal "Terakhir diperbarui" yang baru.
