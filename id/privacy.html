🔍 1. Ikhtisar

NODUS adalah ekstensi browser yang mengutamakan penyimpanan lokal. Semua yang Anda rekam — ide, catatan, sorotan, tag, rantai, dan proyek — disimpan secara eksklusif di penyimpanan lokal browser Anda (chrome.storage.local) dan tidak pernah diunggah ke server mana pun.

NODUS membuat dua jenis koneksi eksternal, yang keduanya dijelaskan secara jelas dalam dokumen ini:

opt-in only Telemetri anonim

Dinonaktifkan secara default. Jika Anda memilih untuk mengaktifkannya, hanya statistik penggunaan agregat yang dikirim — bukan konten Anda.

PRO only Validasi lisensi

Hanya untuk pelanggan PRO berbayar. Mengirimkan sidik jari perangkat yang di-hash dan email Anda untuk memverifikasi lisensi. Konten percakapan tidak pernah disertakan.

💾 2. Data yang tersimpan secara lokal di perangkat Anda

Semua hal berikut disimpan di chrome.storage.local — artinya hanya ada di komputer Anda dan tidak pernah dikirim ke mana pun kecuali Anda mengekspornya secara eksplisit.

  • Ide, catatan, dan sorotan yang direkam
  • Tag dan penugasan antrean
  • Rantai dan templat rantai
  • Proyek dan metadata proyek
  • Preferensi tata letak dasbor
  • Pengaturan bahasa dan animasi
  • Antrean acara telemetri (jika diaktifkan)
  • ID anonim — hash SHA-256 yang dihasilkan secara lokal dengan garam acak, tidak pernah dikaitkan dengan identitas Anda

NODUS tidak memiliki sistem akun pengguna. Tidak ada sinkronisasi cloud, tidak ada profil sisi server, dan tidak ada cara bagi kami untuk mengidentifikasi Anda dari data yang tersimpan secara lokal.

🌐 3. Penjelasan endpoint eksternal

NODUS terhubung ke URL eksternal dalam tiga skenario: telemetri (opt-in), validasi lisensi (khusus PRO), dan membaca file yang telah Anda unggah ke platform AI. Berikut setiap endpoint yang digunakan beserta data yang dikirimkan.

3a. Infrastruktur NODUS

https://nodus-worker.mmcarvalho-dev.workers.dev/telemetry/batch opt-in only

Menerima statistik penggunaan agregat anonim. Hanya dipanggil jika Anda telah mengaktifkan telemetri di Pengaturan. Lihat Bagian 4 untuk detail lengkap.

Data yang dikirim: ID anonim (hash SHA-256) · jumlah jenis acara · jumlah platform · tanpa konten percakapan · tanpa URL · tanpa teks

https://nodus-worker.mmcarvalho-dev.workers.dev/auth/status PRO only

Memvalidasi lisensi PRO Anda saat startup. Hanya dipanggil jika Anda telah memasukkan token lisensi. Lihat Bagian 5 untuk detail lengkap.

Data yang dikirim: alamat email · sidik jari perangkat yang di-hash · tanpa konten percakapan

3b. Akses file platform AI

Endpoint ini diakses secara read-only ketika Anda memicu Tangkap Chat Penuh atau fitur lampiran file. NODUS membaca konten file untuk ditampilkan atau disimpan secara lokal. Tidak ada yang diunggah ke server NODUS.

https://files.oaiusercontent.com/*  ·  https://*.oaiusercontent.com/*  ·  https://cdn.openai.com/* read-only

File dan gambar yang diunggah pengguna dalam percakapan ChatGPT (gambar, PDF, lampiran). NODUS membaca file-file ini secara lokal untuk menyertakannya dalam Tangkap Chat Penuh.

https://*.anthropic.com/* read-only

File, artefak, dan lampiran yang diunggah pengguna dalam percakapan Claude.ai. Diakses secara lokal untuk mendukung Tangkap Chat Penuh.

https://storage.googleapis.com/* read-only

File yang diunggah pengguna dalam percakapan Gemini. Diakses secara lokal untuk mendukung Tangkap Chat Penuh.

https://*.blob.core.windows.net/* read-only

File yang diunggah pengguna dalam percakapan Microsoft Copilot. Diakses secara lokal untuk mendukung Tangkap Chat Penuh.

📊 4. Telemetri anonim opsional

Telemetri dinonaktifkan secara default. Anda harus mengaktifkannya secara eksplisit di Pengaturan → Telemetri untuk mengaktifkannya. Anda dapat menonaktifkannya kapan saja dan semua data yang diantrekan secara lokal langsung dihapus.

Apa yang dikumpulkan telemetri (jika diaktifkan)

  • Jumlah jenis acara (mis. "3 simpanan, 1 injeksi") — tanpa konten, tanpa teks
  • Jumlah platform (mis. "digunakan di ChatGPT 2 kali") — tanpa URL
  • ID anonim — hash SHA-256 yang dihasilkan secara lokal, tidak dikaitkan dengan identitas Anda
  • Jumlah sesi agregat per hari (pengelompokan temporal)

Apa yang tidak pernah dikumpulkan telemetri

  • Konten percakapan, prompt, atau respons AI
  • URL yang dikunjungi atau judul halaman
  • Nama, email, atau informasi pengidentifikasi apa pun
  • Alamat IP (tidak disimpan oleh worker kami)
  • Spesifikasi perangkat atau sidik jari browser

Cara data diproses sebelum dikirim

Acara diagregasi secara lokal sebelum transmisi. Alih-alih mengirim acara mentah, NODUS mengirim penghitung agregat (mis. berapa banyak simpanan yang terjadi, oleh platform mana) dengan noise yang menjaga privasi diterapkan (offset acak ±2 per penghitung). Acara mentah tidak pernah meninggalkan perangkat Anda.

Retensi data

Data telemetri agregat disimpan di server kami maksimal 12 bulan, setelah itu dihapus. Log acara lokal disimpan selama 90 hari di penyimpanan browser Anda, kemudian dibersihkan secara otomatis.

🔑 5. Validasi lisensi PRO

Jika Anda membeli NODUS PRO, ekstensi akan memvalidasi lisensi Anda dengan server kami saat startup. Ini adalah minimum yang diperlukan untuk memverifikasi langganan berbayar.

Apa yang dikirimkan selama validasi lisensi

  • Alamat email Anda (sebagaimana dimasukkan saat aktivasi)
  • Sidik jari perangkat yang di-hash (pengidentifikasi yang dihasilkan browser, bukan nomor seri perangkat keras Anda)

Apa yang tidak pernah dikirimkan

  • Konten percakapan atau apa pun yang telah Anda rekam
  • Alamat IP Anda (tidak disimpan, hanya digunakan untuk perutean oleh Cloudflare)
  • Data telemetri apa pun (ini adalah sistem yang terpisah)

Data lisensi disimpan dalam database Cloudflare D1 (wilayah Brasil/Amerika Selatan). Data ini hanya digunakan untuk memvalidasi apakah langganan Anda aktif. Data ini tidak pernah dijual atau dibagikan kepada pihak ketiga.

Versi GRATIS NODUS bekerja sepenuhnya secara offline dan tidak pernah menghubungi server lisensi kami.

📎 6. Akses file di platform AI

Saat Anda menggunakan Tangkap Chat Penuh atau fitur lampiran file, NODUS dapat mengambil file yang telah Anda unggah ke platform AI (ChatGPT, Claude, Gemini, Copilot) untuk menyertakannya dalam rekaman lokal Anda.

Akses ini bersifat read-only dan lokal. NODUS membaca konten file langsung dari CDN platform AI ke memori browser Anda dan menyimpannya ke penyimpanan lokal Anda (chrome.storage.local). File tidak pernah diunggah ulang ke server NODUS mana pun.

Izin browser yang diperlukan untuk ini (*.oaiusercontent.com, *.anthropic.com, storage.googleapis.com, *.blob.core.windows.net) memungkinkan NODUS membaca file-file tersebut. Izin ini tidak mengizinkan NODUS untuk menulis, memodifikasi, atau mengirimkan data Anda di platform tersebut.

🚫 7. Apa yang tidak pernah kami lakukan

  • Menjual data Anda kepada pihak ketiga mana pun
  • Membaca, menyimpan, atau mengirimkan konten percakapan Anda
  • Melacak situs web yang Anda kunjungi di luar platform AI
  • Menggunakan SDK iklan atau analitik pihak ketiga
  • Menyisipkan iklan atau tautan afiliasi ke platform AI
  • Mengakses mikrofon, kamera, atau clipboard Anda tanpa tindakan
  • Menyinkronkan data yang Anda rekam ke cloud mana pun tanpa ekspor eksplisit Anda

⚖️ 8. Hak Anda (LGPD / GDPR)

NODUS mematuhi Lei Geral de Proteção de Dados Brasil (LGPD) dan Peraturan Perlindungan Data Umum UE (GDPR), serta kompatibel dengan CCPA.

Hak yang Anda miliki

  • Akses — Semua data yang tersimpan secara lokal dapat dilihat dan diekspor dari dasbor NODUS kapan saja
  • Penghapusan — Anda dapat menghapus semua data lokal dari Pengaturan → Hapus Semua Data. Menghapus instalan ekstensi juga menghapus semua data lokal
  • Portabilitas — Ekspor semua ide Anda sebagai JSON, Markdown, atau DOCX kapan saja
  • Opt-out — Nonaktifkan telemetri kapan saja di Pengaturan → Telemetri
  • Penghapusan data lisensi — Hubungi kami untuk meminta penghapusan email Anda dari database lisensi kami

Dasar hukum pemrosesan

Telemetri diproses berdasarkan persetujuan (opt-in). Validasi lisensi diproses berdasarkan pelaksanaan kontrak (memverifikasi langganan berbayar). Tidak ada pemrosesan lain yang terjadi.
