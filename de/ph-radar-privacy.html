🔍 1. Überblick

NODUS PH Radar ist eine local-first Browser-Erweiterung (Chrome). Sie verschafft Ihnen historische Tiefe auf Product Hunt — tägliche Race-Verfolgung, Velocity-Analysen, Watch-Regeln, Hunter-Tabs und einen Launch-Kalender — alles in einem Seitenpanel. Einstellungen, Caches, Pins, Notizen und Watch-Regeln bleiben in Ihrem Browser. Es gibt kein Benutzerkonto, keine Anmeldung und keine Cloud-Synchronisierung für die Kernfunktionen.

Dies ist ein separates Produkt von der Haupterweiterung NODUS (KI-Gesprächserfassung) und von NODUS YT Radar. Wenn Sie eine dieser Richtlinien suchen, lesen Sie NODUS Datenschutz oder YT Radar Datenschutz.

PH Radar stellt externe Verbindungen ausschließlich zu drei Zwecken her, die jeweils unten dokumentiert sind:

erforderlich Product Hunt API v2 (öffentlich)

Wird verwendet, um öffentliche Produktdaten (tägliches Race, Stimmenzahlen, Hunter-Informationen) für die von Ihnen verfolgten Produkte abzurufen. Nur Lesezugriff, ausschließlich öffentliche Daten — wir greifen niemals auf die Zugangsdaten Ihres PH-Kontos zu.

erforderlich Community Spotlight

Ruft eine kuratierte, regionsbezogene Produktpromotion von unserem Worker ab. Sendet nur Ihren Ländercode — keine Identität, keinen Browserverlauf, keine Informationen zu Ihrem Product-Hunt-Konto.

beim Klicken Promotion-Klickzählung

Wenn Sie auf ein Spotlight-Produkt klicken, wird ein anonymes Klick-Ereignis erfasst, damit der maker weiß, wie sein Eintrag abgeschnitten hat. Es wird nur die Promotion-ID gesendet.

💾 2. Lokal auf Ihrem Gerät gespeicherte Daten

Alles Folgende wird in chrome.storage.local oder in der lokalen IndexedDB gespeichert — es befindet sich ausschließlich auf Ihrem Computer und wird niemals an einen NODUS-Server gesendet, sofern nicht in Abschnitt 3 ausdrücklich beschrieben.

settings
Ihre Einstellungen: Oberflächensprache, bevorzugte Regionen, overlay-Modus, Aktualisierungsintervall und Layoutoptionen der Seitenleiste.
ph_token
Ihr persönliches Product-Hunt-API-Token (optional). Wird ausschließlich verwendet, um öffentliche Ranglistendaten abzurufen — niemals an NODUS-Server gesendet, nur an die eigene API von Product Hunt. Sie können es jederzeit in den Einstellungen der Erweiterung löschen.
ph_snapshots_<date> (IndexedDB)
Tägliche Momentaufnahmen öffentlicher Produktmetriken (Stimmenzahl, Hunter, Tagline) für die Produkte, die im Race des Tages erschienen sind. Wird verwendet, um das Velocity-Diagramm und die tägliche Zeitleiste zu erstellen. Gespeichert in der lokalen IndexedDB; nach 30 Tagen automatisch bereinigt.
ph_pins
Produkte, die Sie zur Beobachtung angepinnt haben. Lokal gespeichert; niemals an unsere Server gesendet.
ph_notes_<productId>
Notizen, die Sie für ein verfolgtes Produkt geschrieben haben. Lokal gespeichert; niemals an unsere Server gesendet.
ph_watch_rules
Benachrichtigungsregeln, die Sie definiert haben (z. B. "benachrichtigen, wenn Stimmen > 200"). Lokal gespeichert; Auslöser werden im Browser ausgewertet.
spotlight_token
Ihr Spotlight-Zugangstoken (UUID, beim Absenden im Browser generiert). Wird ausschließlich verwendet, um Ihre eigenen Promotions aus dem Dashboard abzurufen. Lokal gespeichert; auf unserem Server bewahren wir nur einen SHA-256-Hash dieses Tokens auf — der Klartext wird nach der ersten Übermittlung niemals übertragen.
_cacheVersion
Internes Kennzeichen, das verwendet wird, um veralteten Cache nach einem Erweiterungsupdate zu ungültig zu machen.

PH Radar verfügt über kein Benutzerkontosystem. Ihr PH-Token, Ihre Pins, Notizen, Watch-Regeln und Momentaufnahmen werden alle automatisch entfernt, wenn Sie die Erweiterung deinstallieren oder die Erweiterungsdaten in den Einstellungen Ihres Browsers löschen.

🌐 3. Externe Endpunkte erklärt

Die Erweiterung stellt die folgenden Arten von Netzwerkanfragen. Jede Domain ist im Manifestfeld host_permissions der Erweiterung deklariert und für Ihren Browser vor der Installation sichtbar.

3a. Product Hunt GraphQL API v2 (öffentlich)

https://api.producthunt.com/v2/api/graphql erforderlich

Ruft die öffentliche tägliche Race-Rangliste, Produktdetails (Titel, Tagline, Thumbnail, Stimmen, Hunter) und Statistiken des Hunter-Profils ab. Dies sind dieselben öffentlichen Daten, die auf producthunt.com sichtbar sind.

Gesendete Daten: GraphQL-Abfrage für öffentliche Produkt-/Hunter-Daten · Ihr persönliches PH-Token (nur an die eigenen Server von Product Hunt — nicht an unsere) · keine personenbezogenen Daten werden von NODUS erfasst

3b. NODUS PH Radar Worker (Community Spotlight)

https://worker-ph-radar.mmcarvalho-dev.workers.dev/spotlight?region=... erforderlich

Fragt die aktiven Spotlight-Produktpromotions für Ihre Region ab, damit der Streifen im Seitenpanel befüllt werden kann.

Gesendete Daten: Ländercode · keine Identität, keine PH-Kontoinformationen, keine über das Standard-Anfrageprotokoll von Cloudflare hinaus gespeicherte IP

https://worker-ph-radar.mmcarvalho-dev.workers.dev/spotlight/click nur beim Klicken

Wird nur gesendet, wenn Sie im Seitenpanel auf ein Spotlight-Produkt klicken. Erhöht einen aggregierten Klickzähler für das Berichts-Dashboard des makers.

Gesendete Daten: Promotion-ID · sonst nichts

https://worker-ph-radar.mmcarvalho-dev.workers.dev/spotlight/impression beim Ansehen

Wird gesendet, wenn eine Spotlight-Karte im Streifen sichtbar wird (höchstens einmal pro Sitzung und Promotion gezählt). Wird für aggregierte Impressions-Berichte verwendet.

Gesendete Daten: Promotion-ID · sonst nichts

3c. Promotion-Einreichung (nur maker, optional)

https://worker-ph-radar.mmcarvalho-dev.workers.dev/promotions/submit nur maker · beim Absenden

Wird nur aufgerufen, wenn ein maker das Community-Spotlight-Einreichungsformular unter nodus-ai.app/ph-radar ausfüllt. Wird durch die normale Nutzung der Erweiterung nicht ausgelöst.

Gesendete Daten: Product-Hunt-Produkt-URL · E-Mail-Adresse · optionale Tagline, Launch-Datum, Themen, Regionen · Tier · Zugangstoken (UUID, clientseitig generiert)

⭐ 4. Community-Spotlight-Promotions

Community Spotlight ist der Streifen am unteren Rand des PH-Radar-Seitenpanels, der kuratierte Product-Hunt-Produkte zeigt, die von makern eingereicht wurden (kostenlose oder kostenpflichtige Tiers). Es existiert, damit Indie-maker Sichtbarkeit erhalten können, ohne auf Werbenetzwerke angewiesen zu sein.

Was der Worker über eine Promotion speichert

Wenn ein maker ein Produkt unter nodus-ai.app/ph-radar einreicht, speichert unsere Cloudflare-D1-Datenbank: die Product-Hunt-Produkt-URL und den slug, Titel, Tagline, Thumbnail-URL, Hunter-Benutzernamen, Tier (free / bronze / silver / gold), Zielregionen und Themen, optionales Launch-Datum, die E-Mail des Einreichenden (nur für transaktionale Benachrichtigungen) und aggregierte Impressions-/Klickzähler. Diese Informationen werden freiwillig vom maker bereitgestellt und nicht von Erweiterungsnutzern erfasst.

Zugangstoken

Zum Zeitpunkt der Einreichung generiert Ihr Browser ein UUID-Zugangstoken mithilfe von crypto.randomUUID(). Dieses Token wird einmal auf dem Bildschirm angezeigt — Sie kopieren und speichern es. Auf unserem Server speichern wir nur den SHA-256-Hash dieses Tokens. Wir können ihn verifizieren, aber nicht umkehren, um Ihr Token im Klartext wiederherzustellen. Mit dem Token können Sie Ihre eigenen Promotions über das Dashboard anzeigen und verwalten.

Kostenpflichtige Tiers — Zahlungsabwicklung mit Paddle

Für kostenpflichtige Tiers (Bronze 1 $, Silver 3 $, Gold 7 $) werden Zahlungen von Paddle abgewickelt (siehe Abschnitt 5 für Details zum Unterauftragsverarbeiter). Ihre E-Mail-Adresse und Zahlungsinformationen werden von Paddle erfasst, nicht von NODUS. Wir erhalten nur ein Zahlungsbestätigungsereignis vom webhook von Paddle, das Ihre E-Mail und eine Transaktions-ID enthält, damit wir Ihren Plan aktivieren können.

Und was ist mit den Erweiterungsnutzern?

Auf der Seite der Erweiterung speichern wir nichts, was Sie identifiziert. Der Worker erhält nur: den Regionscode für das Spotlight-Matching und — falls Sie klicken oder ansehen — die Promotion-ID. Wir protokollieren nicht, welche Produkte Sie verfolgen, nicht Ihre IP über die Standard-Anfrageverarbeitung von Cloudflare hinaus, nicht Ihren Browser-Fingerabdruck und keinen Kontobezeichner.

Hosting

Der Worker läuft auf Cloudflare Workers mit einer Cloudflare-D1-Datenbank. Cloudflare kann IP-Adressen und Anfrage-Metadaten im Rahmen des Standardnetzwerkbetriebs (DDoS-Schutz, Routing) vorübergehend verarbeiten. Wir schreiben keine IP-Adressen in unsere eigene Datenbank.

🚫 6. Was wir niemals tun

  • Ihre Daten an Dritte verkaufen
  • Die Zugangsdaten Ihres Product-Hunt-Kontos, Ihre DMs, privaten Projekte oder Ihren Kaufverlauf lesen
  • Ihr persönliches PH-Token an NODUS-Server übertragen — es geht ausschließlich an die eigene API von Product Hunt
  • Verfolgen, welche Produkte Sie auf producthunt.com außerhalb des Erweiterungs-Seitenpanels durchstöbern
  • Verfolgen, welche Websites Sie außerhalb von Product Hunt besuchen
  • Werbe-SDKs, Drittanbieter-Analytik oder Verhaltens-Tracking-Cookies verwenden
  • Auf Ihr Mikrofon, Ihre Kamera, Zwischenablage oder Downloads zugreifen
  • Pins, Notizen, Watch-Regeln oder Stimmen-Momentaufnahmen auf unsere Server synchronisieren — all diese Daten bleiben auf Ihrem Gerät
  • Ein Konto, eine Anmeldung oder E-Mail verlangen, um die Kernfunktionen der Erweiterung zu nutzen
  • Einreichungsdaten von makern (E-Mail, Produkt-URL) mit anderen Dritten als den in Abschnitt 5 aufgeführten Unterauftragsverarbeitern teilen

⚖️ 7. Ihre Rechte (LGPD / GDPR)

PH Radar entspricht der brasilianischen Lei Geral de Proteção de Dados (LGPD) und der EU-Datenschutz-Grundverordnung (GDPR) und ist mit der CCPA kompatibel.

Rechte, die Sie als Erweiterungsnutzer haben

  • Zugang — Alle lokalen Daten sind sichtbar über chrome://extensions → PH Radar → Ansichten untersuchen → Anwendung → Speicher / IndexedDB
  • Löschung — Das Entfernen der Erweiterung löscht automatisch alle Daten aus chrome.storage.local und IndexedDB. Sie können sie auch manuell in den Einstellungen Ihres Browsers löschen
  • PH-Token — Sie können Ihr Product-Hunt-Token jederzeit auf der Einstellungsseite der Erweiterung löschen. Es wird niemals an NODUS-Server gesendet
  • Opt-out — Sie können den Spotlight-Streifen in den Einstellungen der Erweiterung deaktivieren. Das Schließen des Seitenpanels stoppt jegliche Netzwerkaktivität der Erweiterung

Rechte, die Sie als maker (Spotlight-Einreichender) haben

  • Zugang & Löschung — Verwenden Sie das beim Einreichen angezeigte Zugangstoken, um Ihre Promotions über das Dashboard unter nodus-ai.app/ph-radar#dashboard anzuzeigen oder zu löschen
  • Verlorenes Token — Kontaktieren Sie uns mit der beim Einreichen verwendeten E-Mail-Adresse, und wir löschen Ihre Daten nach Überprüfung Ihrer Identität
  • Zahlungsdaten — Für Abrechnungsdaten (Zahlungsverlauf, Rechnungen) kontaktieren Sie Paddle direkt unter paddle.com/legal/privacy oder über den Link zum Käuferportal in Ihrer Kauf-E-Mail

Rechtsgrundlage für die Verarbeitung

Abrufe der Product Hunt API werden auf Grundlage des berechtigten Interesses verarbeitet (Bereitstellung der Funktion, für die Sie die Erweiterung geöffnet haben). Spotlight-Promotion-Einreichungen und Zahlungen werden auf Grundlage der Vertragserfüllung mit dem einreichenden maker verarbeitet. Transaktionale E-Mails werden auf Grundlage der Vertragserfüllung versendet. Es findet keine weitere Verarbeitung statt.

Datenaufbewahrung

Aktive Promotions werden für die Dauer des Plans plus 90 Tage zu Berichtszwecken aufbewahrt. Abgelaufene Promotions und zugehörige aggregierte Statistiken können auf Anfrage des makers gelöscht werden. E-Mail-Adressen werden nur so lange aufbewahrt, wie der zugehörige Plan aktiv oder ausstehend ist, sofern Sie keine frühere Löschung verlangen.
