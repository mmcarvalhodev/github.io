🔍 1. Überblick

NODUS HN Radar ist eine vollständig local-first Browser-Erweiterung. Sie verbessert das Leseerlebnis auf news.ycombinator.com und hebt aufsteigende Posts über die öffentliche API von Hacker News hervor. Keine Server, keine Konten, keine Logins, keine Cloud-Synchronisierung, keine Telemetrie.

Schwesterprodukt der Haupt-NODUS-Erweiterung (Erfassung von KI-Konversationen) und von NODUS YT Radar. Jedes hat seine eigene Richtlinie:

  • NODUS Haupterweiterung — privacy.html
  • YT Radar — yt-radar-privacy.html
  • HN Radar — dieses Dokument

HN Radar verbindet sich mit zwei Endpoints, die beide zu Hacker News selbst gehören:

erforderlich news.ycombinator.com

Die Website, die Sie lesen. Das Content Script verbessert die Seiten, die Sie selbst laden — ohne proaktives Fetch.

erforderlich hacker-news.firebaseio.com

Öffentliche Firebase-API von Hacker News. Wird verwendet, um die aufsteigenden Listen (Top / Show / Ask / Best) und individuelle Item-Details für das Radar-Dashboard abzurufen.

keine NODUS-Server

HN Radar kontaktiert keine NODUS-Infrastruktur. Im Gegensatz zu YT Radar (Community Spotlight Worker) oder der Haupt-NODUS-Erweiterung (PRO-Lizenz) hat diese Erweiterung keine NODUS-Backend-Abhängigkeit.

💾 2. Lokal gespeicherte Daten

Alles Folgende wird in chrome.storage.local gespeichert und niemals woandershin gesendet, außer wie in Abschnitt 3 beschrieben.

settings
Ihre Einstellungen: Theme, Schriftgröße, Lesebreite, Hervorhebungs-Toggles, Oberflächensprache, Übersetzungseinstellungen, Zebra-Farbe/Intensität usw.
visited
Liste der IDs von HN-Posts, die Sie von der Startseite angeklickt haben, mit Zeitstempeln. Dient zum Ausgrauen besuchter Posts. TTL 30 Tage mit automatischer Bereinigung.
pinned
Über 📌 explizit angeheftete Posts: ID, Titel, URL, Domain, Snapshot des Scores, Anzahl der Kommentare, Alter, Tags, Zeitstempel der Anheftung.
collapsedCards
IDs der angehefteten Karten, die Sie in der Seitenleiste eingeklappt haben.
recentTags
Liste der 40 zuletzt verwendeten Tag-Namen für die Autovervollständigung.
mutedDomains
Liste der Domains, die Sie stummgeschaltet haben. Posts dieser Domains werden im Radar ausgeblendet.
radar
Snapshots der HN-Post-Daten (Score, Kommentare) im Zeitverlauf, verwendet zur Berechnung der Geschwindigkeit.
opActiveCache
Cache der Erkennung „Autor hat geantwortet" pro ID. TTL 10 Minuten.
comments_<postId>
Cache der Kommentare in der Hover-Vorschau. TTL 10 Minuten.

Die Deinstallation der Erweiterung löscht automatisch alles. Kein Benutzerkonto, keine E-Mail-Erfassung, keine Möglichkeit für NODUS, Sie zu identifizieren.

🌐 3. Externe Endpoints erklärt

Die Erweiterung führt Fetches nur von zwei Domains durch, die in host_permissions deklariert und für Chrome vor der Installation sichtbar sind.

3a. Hacker News Website

https://news.ycombinator.com/*nur Content Script

Das Content Script injiziert CSS und kleine DOM-Verbesserungen (Pin-Buttons, Typ-Badges, Übersetzungsbuttons) auf den Seiten, die Sie laden. Die Erweiterung führt im Hintergrund keine proaktiven Fetches von HN durch.

Von der Erweiterung gesendete Daten: keine über das hinaus, was Ihr Browser bereits sendet.

3b. Öffentliche Firebase-API von Hacker News

https://hacker-news.firebaseio.com/v0/topstories.jsonerforderlich

Gibt das Array der aufsteigenden IDs zurück. Dieselbe Quelle wie die offizielle HN-Startseite.

Gesendete Daten: nichts Identifizierendes — nur die Anfrage.

…/v0/{best,show,ask}stories.jsonwenn Tab aktiv

Dasselbe für die Tabs Best, Show HN und Ask HN.

…/v0/item/<id>.jsonpro Post

Ruft die öffentlichen Details jedes im Radar oder in der Vorschau angezeigten Posts oder Kommentars ab.

Gesendete Daten: die ID des Posts. Keine Identifikatoren von Ihnen.

Hacker News und Y Combinator können diese Anfragen gemäß ihren eigenen Richtlinien protokollieren. Die Erweiterung selbst fügt keine Header, Cookies oder Auth hinzu.

🌐 4. Übersetzung im Browser

Übersetzungen erfolgen vollständig auf Ihrem Gerät. HN Radar verwendet die integrierte Translator-API von Chrome (Chrome 138+), die bei der ersten Verwendung lokal ein kleines Sprachmodell herunterlädt und Text übersetzt, ohne ihn an einen Server zu senden.

Das bedeutet:

  • Bei der Übersetzung verlässt kein Text Ihren Browser.
  • Kein API-Schlüssel, keine Kosten, keine Nutzungserfassung.
  • Die Übersetzung funktioniert offline, sobald das Modell heruntergeladen wurde.
  • Übersetzungs-Cache nur lokal und wird mit der Erweiterung gelöscht.

Wenn Ihr Browser die Translator-API nicht unterstützt (Firefox oder älteres Chrome), tun die Übersetzungsfunktionen nichts — kein Fallback auf einen Cloud-Dienst.

🚫 5. Was wir niemals tun

  • Ihre Daten an Dritte verkaufen
  • Irgendetwas an NODUS-Server senden (kein NODUS-Backend für diese Erweiterung)
  • Verfolgen, welche Posts Sie lesen, anklicken oder anheften
  • Besuchte Websites außerhalb von news.ycombinator.com verfolgen
  • Analytics oder Werbe-SDKs von Drittanbietern verwenden
  • Ihre Kommentare, Antworten oder HN-Kontodaten lesen oder speichern
  • Auf Mikrofon, Kamera, Zwischenablage oder Downloads zugreifen
  • Werbung oder Affiliate-Links injizieren
  • Ein Konto, Login oder eine E-Mail-Adresse verlangen
  • Ihre Tags, Pins oder Einstellungen in die Cloud synchronisieren

⚖️ 6. Ihre Rechte (LGPD / RGPD / CCPA)

HN Radar entspricht der brasilianischen LGPD, der europäischen RGPD und ist mit dem CCPA kompatibel. Da alle Daten lokal sind und die Erweiterung weder Profiling noch standortübergreifendes Tracking betreibt, können die meisten Rechte direkt über Ihren Browser ausgeübt werden.

Rechte, die Sie haben

  • Zugriff — alle lokalen Daten sind in chrome://extensions → HN Radar → Inspizieren → Application → Storage sichtbar
  • Löschung — Deinstallation der Erweiterung löscht alles
  • Portabilität — lokale Daten in JSON in chrome.storage.local, exportierbar über DevTools
  • Opt-out — deaktivieren Sie den Lens-Hauptschalter jederzeit

Rechtsgrundlage der Verarbeitung

Das Lesen der öffentlichen HN-Website und der öffentlichen HN-API fällt unter berechtigtes Interesse (die Bereitstellung der Leseschicht, die Sie durch die Installation der Erweiterung gewählt haben). Es werden keine personenbezogenen Daten verarbeitet.
