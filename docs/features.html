Step 2

Your organized AI knowledge base

Every saved idea appears on the dashboard as a card. Search, filter by platform, date or tag. Switch between 1–3 column layouts.

  • 🔍 Full text search across all saved ideas
  • 🏷️ Filter by tag, platform and date — stack filters
  • 📌 Pin mode — keep dashboard open while using the AI
  • ✏️ Inline edit — title, content, tags, notes on any card
  • 📎 Attachments — add files to any card
  • 🗂️ 6 queues — Quick, Default, Q1, Q2*, Q3*, Q4*
✓ FREE ★ PRO unlocks Q2, Q3, Q4

Step 3

Build structured workflows with Chains

Link multiple captures into an ordered sequence. Use Chains to document research flows, writing drafts or multi-step AI conversations.

  • 📄 Export to TXT — available in FREE
  • 🌐 Export to HTML + DOCX — PRO only
  • 📎 File attachments per chain node
  • 💉 Inject chain content back into any AI

Privacy

Local-first. Always.

Your captured content never leaves your device. No account. No sync. No cloud. The code is open for you to verify.

💾
Local storage only
All data lives in chrome.storage.local and IndexedDB. Nothing is synced.
🔍
Open source core
The capture engines, dashboard, chains, projects and storage layer are MIT licensed and fully auditable.
📊
Anonymous telemetry
Usage stats are anonymous, aggregated counts — no content, no PII. Can be disabled anytime in Settings.
🔐
Encrypted backup
PRO backup uses AES-256-GCM with PBKDF2 key derivation. Only you hold the password.
🚫
No account required
FREE tier works completely without registration. PRO license is validated locally after purchase.
