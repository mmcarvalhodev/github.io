🔍 1. Обзор

NODUS YT Radar — это расширение для браузера, работающее в первую очередь локально (Chrome и Firefox). Оно показывает вам в реальном времени, какое место занимает просматриваемое вами видео на YouTube относительно Top 50 трендовых видео любой страны, с показателем виральности и аналитикой динамики. Все настройки, кеши и снимки истории остаются в вашем браузере — нет учётной записи пользователя, нет входа в систему, нет облачной синхронизации.

Это отдельный продукт от основного расширения NODUS (захват ИИ-переписки). Если вы ищете ту политику, см. privacy.html.

YT Radar устанавливает внешние соединения только для трёх целей, каждая из которых описана ниже:

обязательно YouTube Data API v3

Используется для получения публичного списка Top 50 трендовых видео для выбранной страны и сведений о видео, которое вы смотрите. Публичные данные только для чтения.

обязательно Community Spotlight

Получает курируемое продвижение видео с учётом региона с нашего воркера. Отправляет только код страны и номер категории — без идентичности, без просматриваемого видео.

по клику Подсчёт кликов по продвижению

Если вы кликаете по элементу spotlight, записывается анонимное событие клика, чтобы продвигаемый автор знал, насколько эффективно работает его объявление. Отправляется только ID продвижения.

💾 2. Данные, хранящиеся локально на вашем устройстве

Всё нижеперечисленное хранится в chrome.storage.local — то есть существует только на вашем компьютере и никогда не отправляется ни на какой сервер NODUS, кроме случаев, явно описанных в Разделе 3.

settings
Ваши предпочтения: код страны, режим наложения (значок / развёрнутый / бегущая строка / выкл.), интервал обновления кеша (15/30/60 мин), фильтр категорий, язык интерфейса.
ranking_<region>_<category>
Список Top 50, возвращаемый YouTube Data API, кешируется, чтобы мы не запрашивали его повторно при каждом открытии всплывающего окна. Истекает в соответствии с вашей настройкой интервала обновления.
video_<videoId>
Публичные метаданные видео, которое вы открыли во всплывающем окне (название, канал, количество просмотров, количество лайков, дата публикации). Истекает через 10 минут.
hist_<videoId>
Снимки временны́х рядов публичных счётчиков (просмотры, лайки, комментарии) для видео, которые вы проанализировали, используемые для построения мини-графика роста и обнаружения резких скачков. Снимки делаются не чаще одного раза в 5 минут и удаляются через 48 часов. Не содержат никакой идентифицирующей информации — только числа.
_cacheVersion
Внутренний флаг, используемый для сброса устаревшего кеша после обновления расширения.

В YT Radar нет системы учётных записей пользователей, нет входа в систему, нет сбора email внутри расширения и нет телеметрии. Все указанные выше ключи удаляются автоматически, когда вы удаляете расширение или нажимаете "Удалить все данные" в настройках расширений вашего браузера.

🌐 3. Описание внешних эндпоинтов

Расширение выполняет четыре вида сетевых запросов. Каждый URL, к которому оно подключается, объявлен в поле манифеста host_permissions расширения и виден вашему браузеру до установки.

3a. YouTube Data API v3 (публичный API Google)

https://www.googleapis.com/youtube/v3/videos?chart=mostPopular&regionCode=... обязательно

Получает публичный список Top 50 трендовых видео для выбранной вами страны. Это тот же публичный эндпоинт, который обеспечивает работу вкладки «В тренде» на YouTube.

Отправляемые данные: код страны (например, BR) · необязательный ID категории · наш ключ API · никаких персональных данных, никакого просматриваемого видео

https://www.googleapis.com/youtube/v3/videos?id=<videoId> обязательно (при необходимости)

Получает публичные сведения о видео, которое вы смотрите, но только тогда, когда его ещё нет в списке Top 50. Именно это позволяет нам вычислить его показатель виральности и метрики роста.

Отправляемые данные: ID видео YouTube · наш ключ API · никаких персональных данных

Google может регистрировать эти запросы в соответствии со своей собственной политикой конфиденциальности. Мы не отправляем вместе с ними никаких дополнительных персональных данных.

3b. Воркер NODUS YT Radar (Community Spotlight)

https://worker-yt-radar.mmcarvalho-dev.workers.dev/promotions?region=...&category=... обязательно

Запрашивает у нашего воркера активное продвигаемое видео для вашей комбинации страны/категории, чтобы мы могли отобразить карточку Community Spotlight.

Отправляемые данные: код страны · ID категории · без идентичности, без просматриваемого видео, без хранения IP сверх стандартного журнала запросов Cloudflare

https://worker-yt-radar.mmcarvalho-dev.workers.dev/promotions/click только по клику

Отправляется только когда вы нажимаете кнопку "Смотреть" на карточке Community Spotlight. Увеличивает агрегированный счётчик кликов, чтобы продвигаемый автор мог видеть, насколько эффективно работает его объявление.

Отправляемые данные: ID продвижения · больше ничего

https://worker-yt-radar.mmcarvalho-dev.workers.dev/player?v=<videoId> iframe

Загружается как iframe внутри карусели Community Spotlight для воспроизведения промо-превью. Воркер возвращает небольшую HTML-страницу, которая встраивает плеер YouTube.

Отправляемые данные: ID продвигаемого видео YouTube · канал и название (используются только как подписи iframe)

⭐ 4. Продвижения Community Spotlight

Community Spotlight — это раздел внутри всплывающего окна, который отображает курируемые видео YouTube, отправленные авторами (бесплатные или платные уровни). Он существует, чтобы независимые авторы могли получить видимость без рекламных сетей.

Что воркер хранит о продвижении

Когда автор отправляет видео на nodus-ai.app/yt-radar, наша база данных Cloudflare D1 хранит: ID видео YouTube, название, канал, URL миниатюры, уровень (free/bronze/silver/gold), целевые регионы и категории, email отправителя (только для связи) и агрегированные счётчики кликов/просмотров. Эта информация предоставляется самим автором, а не собирается у пользователей расширения.

А что насчёт пользователей расширения?

Со стороны расширения мы не храним ничего, что вас идентифицирует. Воркер видит только: выбранные вами страну и категорию (чтобы подобрать подходящее промо) и — если вы кликаете — ID продвижения. Мы не регистрируем, какое видео вы смотрели, ваш IP сверх стандартной обработки запросов Cloudflare, отпечаток вашего браузера или какой-либо идентификатор учётной записи.

Хостинг

Воркер работает на Cloudflare Workers. Cloudflare может временно обрабатывать IP-адреса и метаданные запросов в рамках стандартной работы сети (защита от DDoS, маршрутизация). Мы не записываем IP-адреса в нашу собственную базу данных.

🚫 5. Чего мы никогда не делаем

  • Продавать ваши данные каким-либо третьим лицам
  • Отслеживать, какие видео YouTube вы смотрите — считывается только ID активного видео и только для вычисления его места в рейтинге
  • Отслеживать, какие сайты вы посещаете за пределами YouTube
  • Читать или передавать ваши комментарии на YouTube, историю поиска, историю просмотров или информацию об учётной записи
  • Использовать рекламные SDK, сторонние аналитические инструменты или поведенческое отслеживание
  • Получать доступ к вашему микрофону, камере, буферу обмена или загрузкам
  • Внедрять рекламу на саму страницу YouTube — наложение показывает лишь небольшой значок рейтинга, который вы можете отключить
  • Синхронизировать какие-либо ваши данные с нашими серверами
  • Требовать учётную запись, вход в систему или email для использования основных функций расширения

⚖️ 6. Ваши права (LGPD / GDPR)

YT Radar соответствует бразильскому Общему закону о защите данных (LGPD) и Общему регламенту ЕС по защите данных (GDPR), а также совместим с CCPA.

Ваши права

  • Доступ — все локальные данные видны через chrome://extensions → YT Radar → Просмотр представлений → Application → Storage
  • Удаление — удаление расширения автоматически очищает все данные chrome.storage.local. Вы также можете очистить их вручную в настройках браузера
  • Данные о продвижении — если вы отправили элемент Community Spotlight, вы можете управлять им или удалить его с помощью токена доступа, отображённого на экране успешной отправки формы. Потеряли токен? Свяжитесь с нами, указав email, использованный при отправке
  • Отказ — установите Наложение в значение "Выкл." в Настройках, чтобы отключить наложение на странице. Закрытие всплывающего окна останавливает всю сетевую активность расширения

Правовое основание для обработки

Запросы Top 50 и получение сведений о видео обрабатываются на основании законного интереса (предоставление функции, ради которой вы открыли расширение). Отправки продвижений Spotlight обрабатываются на основании исполнения договора с отправляющим автором. Никакой другой обработки не происходит.
