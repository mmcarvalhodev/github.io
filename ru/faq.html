Начало работы

6 вопросов

NODUS — это браузерное расширение, которое позволяет сохранять, организовывать и повторно использовать ответы ИИ одним кликом. Оно работает с ChatGPT, Claude, Gemini, Perplexity, Grok, Copilot и DeepSeek. Всё хранится локально на вашем устройстве — без аккаунта, без сервера, без обязательной подписки.

Установка занимает менее 30 секунд:

  • Chrome / Edge / Brave: перейдите в Chrome Web Store и нажмите «Добавить в Chrome»
  • Firefox: перейдите на страницу Mozilla Add-ons и нажмите «Добавить в Firefox»

После установки откройте любую поддерживаемую платформу ИИ — кнопки NODUS появятся автоматически.

NODUS работает в:

  • Chrome (версия 88+)
  • Firefox (версия 109+)

  • Brave и других браузерах на Chromium

Нажмите Быстро, чтобы сохранить одним кликом без настройки. Нажмите Панель, чтобы открыть дашборд с захваченными записями.

Экспорт и скачивание

7 вопросов

Откройте дашборд NODUS, выберите нужный захват и нажмите Экспорт → DOCX. Файл Word генерируется прямо в браузере и сохраняется на компьютер. Вы можете объединить несколько захватов с помощью Цепочек и экспортировать всё вместе как структурированный документ.

NODUS экспортирует в формат HTML, который можно распечатать как PDF прямо из браузера (Ctrl+P → Сохранить как PDF). Для прямого экспорта в PDF рекомендуем экспортировать в HTML и использовать функцию печати браузера — результат хорошо отформатирован.

NODUS поддерживает экспорт в:

  • TXT — простой текст, совместим с любым редактором
  • HTML — форматированный, можно распечатать как PDF
  • DOCX — совместим с Word, Google Docs и LibreOffice

Связанные захваты (Цепочки) можно экспортировать вместе как единый документ.

В дашборде NODUS перейдите в Настройки → Экспортировать всё. Это создаёт файл со всеми захватами в формате JSON (для повторного импорта в NODUS), или вы можете экспортировать каждую очередь отдельно в формате DOCX или HTML.

В виде карточек в дашборде нажмите Копировать. Содержимое копируется с сохранением форматирования Markdown — заголовки, списки, код — готово к вставке в любой редактор с поддержкой Markdown.

Да. В разделе Настройки → Экспорт данных вы скачиваете JSON-файл со всеми захватами. Этот файл можно повторно импортировать в NODUS на другом компьютере или после переустановки расширения.

Используйте Цепочки, чтобы связать связанные захваты из разных сессий (даже с разных платформ). Затем экспортируйте всю цепочку в DOCX — результат представляет собой структурированный документ со всеми вопросами и ответами, выстроенными в логическом порядке.

Организация

7 вопросов

При сохранении захвата вы можете добавить до 4 тегов для категоризации содержимого. Теги отображаются на карточках дашборда и служат фильтрами — нажмите на тег, чтобы увидеть только захваты с этой категорией. Создавайте теги вроде «бэкенд», «учёба», «идеи», «работа» или любые другие, удобные вам.

Очереди — это отдельные коллекции для организации захватов по контексту или приоритету. Быстрая очередь предназначена для быстрых захватов без категоризации. Основная — общая очередь. Очереди Q1–Q4 (план PRO) настраиваются по теме, проекту или клиенту. Каждая очередь имеет разный цвет рамки на карточках.

В дашборде NODUS используйте строку поиска вверху. Поиск работает в реальном времени и охватывает заголовок, вопрос и ответ всех захватов. Сочетайте поиск с фильтрами по платформе или тегам, чтобы найти именно то, что нужно.

В дашборде нажмите значки платформ под строкой поиска. Нажмите ChatGPT, Claude, Gemini или любую другую платформу, чтобы увидеть только захваты из этого источника. Нажмите снова, чтобы снять фильтр.

Проекты (план PRO) позволяют создавать полностью отдельные пространства — например, «Работа», «Учёба» и «Личное». У каждого проекта свои очереди и захваты. Переключайтесь между проектами одним кликом, не смешивая разный контент.

Да. Откройте карточку в дашборде и нажмите Редактировать. Вы можете изменить заголовок, добавить или удалить теги и переместить захват между очередями. Исходное содержимое (вопрос и ответ) сохраняется.

Используйте текстовый поиск в дашборде — он охватывает полное содержимое всех захватов, а не только заголовок. Если вы помните любое ключевое слово из ответа, просто введите его. Сочетайте с фильтром по платформе (например, Claude), если знаете, откуда он взят.

Цепочки

6 вопросов

Цепочки позволяют связывать захваты из разных разговоров в логическую последовательность. Представьте: вы исследовали тему в ChatGPT, затем углубились в Claude и нашли примеры в Gemini — Цепочка объединяет эти три захвата в непрерывную нить рассуждений, даже если они с разных платформ.

На вкладке Цепочки дашборда нажмите «Новая цепочка». Дайте цепочке название и добавьте существующие захваты, перетаскивая их в нужном порядке. Вы можете добавлять захваты с любой платформы и перестраивать их в любое время.

Да — это одно из главных преимуществ Цепочек. Вы можете объединить захваты из ChatGPT, Claude, Gemini, Perplexity и любой другой поддерживаемой платформы в единую последовательность. Каждая карточка сохраняет идентификацию исходной платформы.

Откройте Цепочку в дашборде и нажмите Экспорт. Вы можете экспортировать полную последовательность в DOCX или HTML — результат представляет собой структурированный документ со всеми вопросами и ответами по порядку, идеальный для отчётов, учёбы или документации.

В бесплатном плане каждая Цепочка может содержать до 5 захватов. В плане PRO лимит значительно выше, позволяя создавать обширные цепочки для сложных проектов.

Функция внедрения позволяет вставить содержимое Цепочки прямо в поле ввода любой поддерживаемой платформы. Это как передать ИИ полный контекст предыдущих исследований — без ручного копирования и вставки каждого ответа.

Конфиденциальность и безопасность

7 вопросов

Нет. У NODUS нет собственного сервера, который получал бы ваши захваты. Всё хранится в локальном хранилище браузера (chrome.storage.local / browser.storage.local). Ни один захват, тег или фрагмент контента никогда не покидает ваше устройство.

Нет. NODUS считывает содержимое страницы только тогда, когда вы активно нажимаете «Сохранить» или «Быстро». Автоматического захвата, пассивного мониторинга или чтения разговоров, которые вы не выбрали для сохранения, не происходит.

Да. Ядро NODUS доступно на GitHub под лицензией MIT. Каждый может проверить код и убедиться, что скрытого сбора данных нет. Вам не нужно верить нам на слово — посмотрите код.

При удалении расширения браузер удаляет связанное локальное хранилище. Сначала сделайте резервную копию: перейдите в Настройки → Экспорт данных, чтобы скачать все захваты в формате JSON. После переустановки вы сможете их импортировать.

NODUS запрашивает только разрешения, необходимые для работы:

  • Чтение страниц ИИ — для обнаружения ответов и добавления кнопок
  • Локальное хранилище — для сохранения захватов на устройстве
  • Доступ к вкладкам — чтобы знать, на какой платформе вы находитесь

Разрешения на доступ к камере, микрофону, истории браузера или паролям не запрашиваются.

Дашборд NODUS работает полностью офлайн — вы можете получать доступ, искать и экспортировать захваты без подключения к интернету. Для захвата новых разговоров требуется соединение, так как сами платформы ИИ должны быть доступны.
