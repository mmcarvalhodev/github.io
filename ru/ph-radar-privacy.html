🔍 1. Обзор

NODUS PH Radar — это браузерное расширение по принципу local-first (Chrome). Оно даёт вам историческую глубину по Product Hunt — отслеживание ежедневной гонки, аналитику скорости, правила наблюдения, вкладки hunter и календарь запусков — всё в боковой панели. Настройки, кэши, закреплённые элементы, заметки и правила наблюдения остаются в вашем браузере. Нет учётной записи пользователя, нет входа в систему, нет облачной синхронизации для основных функций.

Это отдельный продукт от основного расширения NODUS (захват разговоров с ИИ) и от NODUS YT Radar. Если вы ищете одну из тех политик, см. Конфиденциальность NODUS или Конфиденциальность YT Radar.

PH Radar устанавливает внешние соединения только в трёх целях, каждая из которых описана ниже:

обязательно Product Hunt API v2 (публичный)

Используется для получения публичных данных о продуктах (ежедневная гонка, количество голосов, информация о hunter) по продуктам, которые вы отслеживаете. Только чтение, только публичные данные — мы никогда не получаем доступ к учётным данным вашего аккаунта PH.

обязательно Community Spotlight

Получает подобранную, привязанную к региону промоакцию продукта от нашего worker. Отправляет только код вашей страны — без идентификации, без истории просмотров, без информации об аккаунте Product Hunt.

при клике Счётчик кликов по промоакции

Если вы кликаете по продукту Spotlight, регистрируется анонимное событие клика, чтобы maker знал, как сработало его размещение. Отправляется только ID промоакции.

💾 2. Данные, хранящиеся локально на вашем устройстве

Всё перечисленное ниже хранится в chrome.storage.local или в локальной IndexedDB — оно существует только на вашем компьютере и никогда не отправляется ни на один сервер NODUS, кроме случаев, явно описанных в Разделе 3.

settings
Ваши предпочтения: язык интерфейса, предпочитаемые регионы, режим overlay, интервал обновления и настройки компоновки боковой панели.
ph_token
Ваш Персональный API-токен Product Hunt (необязательно). Используется только для получения публичных данных рейтинга — никогда не отправляется на серверы NODUS, только в собственный API Product Hunt. Вы можете удалить его в любой момент в настройках расширения.
ph_snapshots_<date> (IndexedDB)
Ежедневные снимки публичных метрик продуктов (количество голосов, hunter, tagline) по продуктам, появившимся в гонке дня. Используются для построения графика скорости и ежедневной хронологии. Хранятся в локальной IndexedDB; автоматически удаляются через 30 дней.
ph_pins
Продукты, которые вы закрепили для наблюдения. Хранятся локально; никогда не отправляются на наши серверы.
ph_notes_<productId>
Заметки, которые вы написали для отслеживаемого продукта. Хранятся локально; никогда не отправляются на наши серверы.
ph_watch_rules
Правила оповещений, которые вы задали (например, «уведомить, когда голосов > 200»). Хранятся локально; срабатывания вычисляются в браузере.
spotlight_token
Ваш токен доступа Spotlight (UUID, сгенерированный в браузере при отправке). Используется только для получения ваших собственных промоакций из панели управления. Хранится локально; на нашем сервере мы храним лишь SHA-256-хеш этого токена — открытый текст никогда не передаётся после первоначальной отправки.
_cacheVersion
Внутренний флаг, используемый для аннулирования устаревшего кэша после обновления расширения.

У PH Radar нет системы учётных записей пользователей. Ваш токен PH, закреплённые элементы, заметки, правила наблюдения и снимки автоматически удаляются, когда вы удаляете расширение или очищаете данные расширения в настройках браузера.

🌐 3. Внешние эндпоинты — пояснения

Расширение выполняет следующие виды сетевых запросов. Каждый домен объявлен в поле манифеста расширения host_permissions и виден вашему браузеру до установки.

3a. Product Hunt GraphQL API v2 (публичный)

https://api.producthunt.com/v2/api/graphql обязательно

Получает публичный рейтинг ежедневной гонки, детали продуктов (название, tagline, миниатюра, голоса, hunter) и статистику профиля hunter. Это те же публичные данные, что видны на producthunt.com.

Отправляемые данные: GraphQL-запрос публичных данных о продуктах/hunter · ваш Персональный токен PH (только на собственные серверы Product Hunt — не на наши) · никаких персональных данных NODUS не собирает

3b. Worker NODUS PH Radar (Community Spotlight)

https://worker-ph-radar.mmcarvalho-dev.workers.dev/spotlight?region=... обязательно

Запрашивает активные промоакции продуктов Spotlight для вашего региона, чтобы заполнить полосу в боковой панели.

Отправляемые данные: код страны · без идентификации, без информации об аккаунте PH, без хранения IP за пределами стандартного журнала запросов Cloudflare

https://worker-ph-radar.mmcarvalho-dev.workers.dev/spotlight/click только при клике

Отправляется только когда вы кликаете по продукту Spotlight в боковой панели. Увеличивает агрегированный счётчик кликов для панели отчётов maker.

Отправляемые данные: ID промоакции · ничего больше

https://worker-ph-radar.mmcarvalho-dev.workers.dev/spotlight/impression при просмотре

Отправляется, когда карточка Spotlight становится видимой в полосе (учитывается не более одного раза за сессию на каждую промоакцию). Используется для агрегированных отчётов о показах.

Отправляемые данные: ID промоакции · ничего больше

3c. Отправка промоакции (только maker, необязательно)

https://worker-ph-radar.mmcarvalho-dev.workers.dev/promotions/submit только maker · при отправке

Вызывается только когда maker заполняет форму отправки Community Spotlight по адресу nodus-ai.app/ph-radar. Не запускается при обычном использовании расширения.

Отправляемые данные: URL продукта на Product Hunt · адрес электронной почты · необязательные tagline, дата запуска, темы, регионы · уровень · токен доступа (UUID, генерируется на стороне клиента)

⭐ 4. Промоакции Community Spotlight

Community Spotlight — это полоса в нижней части боковой панели PH Radar, которая показывает подобранные продукты Product Hunt, отправленные makers (бесплатный или платные уровни). Она существует, чтобы инди-makers могли получить охват и узнаваемость без рекламных сетей.

Что worker хранит о промоакции

Когда maker отправляет продукт по адресу nodus-ai.app/ph-radar, наша база данных Cloudflare D1 хранит: URL и slug продукта на Product Hunt, название, tagline, URL миниатюры, имя пользователя hunter, уровень (free / bronze / silver / gold), целевые регионы и темы, необязательную дату запуска, электронную почту отправителя (только для транзакционных уведомлений) и агрегированные счётчики показов/кликов. Эта информация предоставляется добровольно самим maker, а не собирается у пользователей расширения.

Токены доступа

В момент отправки ваш браузер генерирует UUID-токен доступа с помощью crypto.randomUUID(). Этот токен отображается на экране один раз — вы копируете и сохраняете его. На нашем сервере мы храним только SHA-256-хеш этого токена. Мы можем его проверить, но не можем обратить, чтобы восстановить ваш токен в открытом виде. Токен позволяет вам просматривать и управлять собственными промоакциями через панель управления.

Платные уровни — обработка платежей Paddle

Для платных уровней (Bronze 1 $, Silver 3 $, Gold 7 $) платежи обрабатывает Paddle (подробности о субобработчике см. в Разделе 5). Ваш адрес электронной почты и платёжная информация собираются Paddle, а не NODUS. Мы получаем лишь событие подтверждения платежа из webhook Paddle, которое включает вашу электронную почту и ID транзакции, чтобы мы могли активировать ваш план.

А как насчёт пользователей расширения?

Со стороны расширения мы не храним ничего, что вас идентифицирует. Worker получает только: код региона для подбора Spotlight и — если вы кликаете или просматриваете — ID промоакции. Мы не записываем, какие продукты вы отслеживаете, ваш IP за пределами стандартной обработки запросов Cloudflare, отпечаток вашего браузера или какой-либо идентификатор учётной записи.

Хостинг

Worker работает на Cloudflare Workers с базой данных Cloudflare D1. Cloudflare может временно обрабатывать IP-адреса и метаданные запросов в рамках стандартной работы сети (защита от DDoS, маршрутизация). Мы не записываем IP-адреса в нашу собственную базу данных.

🚫 6. Чего мы никогда не делаем

  • Продавать ваши данные какой-либо третьей стороне
  • Читать учётные данные вашего аккаунта Product Hunt, личные сообщения, приватные проекты или историю покупок
  • Передавать ваш Персональный токен PH на серверы NODUS — он идёт только в собственный API Product Hunt
  • Отслеживать, какие продукты вы просматриваете на producthunt.com вне боковой панели расширения
  • Отслеживать, какие сайты вы посещаете вне Product Hunt
  • Использовать рекламные SDK, стороннюю аналитику или отслеживающие поведение cookie
  • Получать доступ к вашему микрофону, камере, буферу обмена или загрузкам
  • Синхронизировать закреплённые элементы, заметки, правила наблюдения или снимки голосов на наши серверы — все эти данные остаются на вашем устройстве
  • Требовать учётную запись, вход в систему или электронную почту для использования основных функций расширения
  • Передавать данные отправок maker (электронная почта, URL продукта) третьим сторонам, отличным от субобработчиков, перечисленных в Разделе 5

⚖️ 7. Ваши права (LGPD / GDPR)

PH Radar соответствует бразильскому Общему закону о защите данных (LGPD) и Общему регламенту ЕС по защите данных (GDPR), а также совместим с CCPA.

Права, которые у вас есть как у пользователя расширения

  • Доступ — все локальные данные видны через chrome://extensions → PH Radar → Просмотр представлений (Inspect views) → Application → Storage / IndexedDB
  • Удаление — удаление расширения автоматически очищает все данные chrome.storage.local и IndexedDB. Вы также можете очистить их вручную в настройках браузера
  • Токен PH — вы можете удалить свой токен Product Hunt в любой момент на странице настроек расширения. Он никогда не отправляется на серверы NODUS
  • Отказ — вы можете отключить полосу Spotlight в настройках расширения. Закрытие боковой панели останавливает всю сетевую активность расширения

Права, которые у вас есть как у maker (отправителя Spotlight)

  • Доступ и удаление — используйте токен доступа, показанный в момент отправки, чтобы просмотреть или удалить ваши промоакции через панель управления по адресу nodus-ai.app/ph-radar#dashboard
  • Утерянный токен — свяжитесь с нами, указав электронную почту, использованную при отправке, и мы удалим ваши данные после проверки личности
  • Платёжные данные — по поводу данных биллинга (история платежей, счета) обращайтесь напрямую в Paddle по адресу paddle.com/legal/privacy или по ссылке на портал покупателя в письме о покупке

Правовое основание обработки

Запросы к API Product Hunt обрабатываются на основании законного интереса (предоставление функции, ради которой вы открыли расширение). Отправки промоакций Spotlight и платежи обрабатываются на основании исполнения договора с отправляющим maker. Транзакционные письма отправляются на основании исполнения договора. Никакой другой обработки не происходит.

Срок хранения данных

Активные промоакции хранятся в течение срока действия плана плюс 90 дней для целей отчётности. Истёкшие промоакции и связанная агрегированная статистика могут быть удалены по запросу maker. Адреса электронной почты хранятся только до тех пор, пока связанный план активен или находится в ожидании, если вы не запросите более раннее удаление.
