🔍 1. Обзор

NODUS HN Radar — полностью local-first расширение браузера. Оно улучшает опыт чтения на news.ycombinator.com и выводит набирающие популярность посты через публичный API Hacker News. Никаких серверов, никаких аккаунтов, никакого логина, никакой облачной синхронизации, никакой телеметрии.

Продукт-сосед основного расширения NODUS (захват ИИ-диалогов) и NODUS YT Radar. У каждого своя политика:

  • NODUS основной — privacy.html
  • YT Radar — yt-radar-privacy.html
  • HN Radar — этот документ

HN Radar подключается к двум endpoint'ам, оба из которых принадлежат самому Hacker News:

требуется news.ycombinator.com

Сайт, который вы читаете. Content script улучшает страницы, которые вы загружаете сами — без проактивного fetch.

требуется hacker-news.firebaseio.com

Публичный API Firebase от Hacker News. Используется для получения списков набирающих популярность (Top / Show / Ask / Best) и индивидуальных деталей элементов для дашборда Radar.

никакого Серверы NODUS

HN Radar не обращается ни к какой инфраструктуре NODUS. В отличие от YT Radar (worker Community Spotlight) или основного NODUS (лицензия PRO), это расширение не имеет никаких backend-зависимостей от NODUS.

💾 2. Данные, хранящиеся локально

Всё нижеперечисленное хранится в chrome.storage.local и никогда не отправляется куда-либо, кроме случаев, описанных в Разделе 3.

settings
Ваши настройки: тема, размер шрифта, ширина чтения, переключатели подсветки, язык интерфейса, параметры перевода, цвет/интенсивность zebra и т. д.
visited
Список ID постов HN, по которым вы кликнули с главной страницы, с метками времени. Используется, чтобы делать посещённые посты серыми. TTL 30 дней с авто-очисткой.
pinned
Посты, явно закреплённые через 📌: id, заголовок, url, домен, снимок счёта, число комментариев, возраст, теги, метка времени закрепления.
collapsedCards
ID закреплённых карточек, которые вы свернули в боковой панели.
recentTags
Список последних 40 использованных названий тегов для автодополнения.
mutedDomains
Список доменов, которые вы поставили в mute. Посты с этих доменов скрыты в Radar.
radar
Снимки данных постов HN (счёт, комментарии) во времени, используемые для расчёта скорости.
opActiveCache
Кэш определения «автор ответил» по ID. TTL 10 минут.
comments_<postId>
Кэш комментариев для превью при наведении. TTL 10 минут.

Удаление расширения автоматически стирает всё. Никаких пользовательских аккаунтов, никакого сбора email, никаких способов для NODUS вас идентифицировать.

🌐 3. Внешние endpoint'ы — объяснение

Расширение делает fetch только с двух доменов, объявленных в host_permissions и видимых для Chrome до установки.

3a. Сайт Hacker News

https://news.ycombinator.com/*только content script

Content script внедряет CSS и небольшие улучшения DOM (кнопки pin, бейджи типов, кнопки перевода) на страницы, которые вы загружаете. Расширение не делает fetch к HN проактивно в фоне.

Данные, отправляемые расширением: никаких сверх того, что ваш браузер и так отправляет.

3b. Публичный API Firebase от Hacker News

https://hacker-news.firebaseio.com/v0/topstories.jsonтребуется

Возвращает массив ID, набирающих популярность. Тот же источник, что и официальная главная страница HN.

Отправляемые данные: ничего идентифицирующего — просто запрос.

…/v0/{best,show,ask}stories.jsonесли вкладка активна

То же самое для вкладок Best, Show HN и Ask HN.

…/v0/item/<id>.jsonпо посту

Получает публичные детали каждого поста или комментария, отображаемого в Radar или превью.

Отправляемые данные: ID поста. Никаких ваших идентификаторов.

Hacker News и Y Combinator могут логировать эти запросы согласно собственным политикам. Само расширение не добавляет заголовков, cookies или авторизации.

🌐 4. Перевод в браузере

Переводы выполняются полностью на вашем устройстве. HN Radar использует встроенный API Translator в Chrome (Chrome 138+), который при первом использовании скачивает локально небольшую языковую модель и переводит текст без отправки на какой-либо сервер.

Это означает:

  • Никакой текст не покидает ваш браузер во время перевода.
  • Никакого API-ключа, никаких затрат, никакого отслеживания использования.
  • Перевод работает оффлайн после загрузки модели.
  • Кэш переводов только локальный и стирается вместе с расширением.

Если ваш браузер не поддерживает API Translator (Firefox или более старый Chrome), функции перевода ничего не делают — никакого fallback к облачному сервису.

🚫 5. Чего мы никогда не делаем

  • Продавать ваши данные третьим лицам
  • Отправлять что-либо на серверы NODUS (для этого расширения нет backend'а NODUS)
  • Отслеживать, какие посты вы читаете, кликаете или закрепляете
  • Отслеживать посещённые сайты вне news.ycombinator.com
  • Использовать сторонние аналитики или рекламные SDK
  • Читать или хранить ваши комментарии, ответы или данные аккаунта HN
  • Получать доступ к микрофону, камере, буферу обмена или загрузкам
  • Внедрять рекламу или партнёрские ссылки
  • Требовать аккаунт, логин или email
  • Синхронизировать ваши теги, закрепления или настройки в облаке

⚖️ 6. Ваши права (LGPD / GDPR / CCPA)

HN Radar соответствует бразильскому LGPD, европейскому GDPR и совместим с CCPA. Так как все данные локальные, а расширение не занимается ни профилированием, ни межсайтовым трекингом, большинство прав реализуется напрямую через ваш браузер.

Права, которыми вы располагаете

  • Доступ — все локальные данные видны в chrome://extensions → HN Radar → Inspect → Application → Storage
  • Удаление — удаление расширения стирает всё
  • Переносимость — локальные данные в JSON в chrome.storage.local, экспортируются из DevTools
  • Opt-out — отключите главный переключатель Lens в любой момент

Правовая основа обработки

Чтение публичного сайта HN и публичного API HN относится к законному интересу (доставка слоя чтения, который вы выбрали, установив расширение). Никакие персональные идентифицирующие данные не обрабатываются.
