Como baixar seu histórico de conversas de IA

Faça backup completo de todas as suas capturas do ChatGPT, Claude, Gemini e outras plataformas — exporte tudo em JSON para reimportar depois, ou em HTML/DOC para leitura.

Resposta rápida

No painel NODUS, acesse Configurações → Exportar dados para baixar todas as capturas em JSON (backup completo, reimportável). Para leitura, exporte capturas individuais ou Cadeias em HTML, Markdown ou DOC.

Passo a passo

Abra o painel NODUS clicando em Dash

O botão Dash ao lado de qualquer resposta de IA abre o painel centralizado com todas as suas capturas.

Vá em Configurações (ícone ⚙)

No painel, localize o ícone de engrenagem ou o menu de Configurações para acessar as opções avançadas.

Clique em Exportar dados

A opção Exportar dados gera um arquivo JSON com todas as suas capturas, tags, filas e metadados — um backup completo do seu histórico.

Guarde o arquivo em segurança

Salve o arquivo JSON num local seguro (pasta na nuvem, pen drive, disco externo). Você pode reimportá-lo no NODUS em qualquer computador para restaurar todo o seu histórico.

Por que fazer backup?

Os dados ficam no armazenamento local do navegador. Se você reinstalar o navegador, trocar de computador ou desinstalar a extensão sem fazer backup, as capturas são perdidas. O backup em JSON preserva tudo e pode ser reimportado depois.

Recomendamos fazer backup regularmente — especialmente antes de atualizar o navegador, formatar o computador ou mudar de dispositivo.

Diferença entre backup completo e exportação

  • Backup JSON: reimportável, inclui tags, filas, metadados e todo o histórico. Use para migrar entre dispositivos ou fazer backup de segurança.
  • Exportação individual (HTML / MD / DOC): para leitura e compartilhamento. Não é reimportável no NODUS, mas abre em qualquer editor ou navegador.

Plataformas suportadas

O NODUS faz backup de capturas de todas as plataformas no mesmo arquivo JSON:
