Como fazer backup de conversas de IA

Se você salva respostas importantes, o passo seguinte é garantir que elas sobrevivam a troca de dispositivo, reinstalação do navegador ou limpeza de dados. Backup serve exatamente para isso.

Resposta rápida

No NODUS, o backup principal é feito por exportação de dados em JSON. Esse arquivo serve para restauração. Já HTML e DOC funcionam melhor como arquivo de leitura e compartilhamento, não como backup completo do acervo.

Por que backup é diferente de simplesmente salvar

Salvar uma captura protege a resposta contra perda imediata dentro da plataforma. Backup protege seu acervo contra perda do ambiente local. São duas camadas diferentes.

Como o NODUS é local-first, suas capturas ficam no seu dispositivo. Isso é ótimo para privacidade, mas significa que você precisa exportar periodicamente se quiser proteção contra formatação, troca de navegador ou falha da máquina.

Como fazer backup completo

Abra o painel NODUS

Use o botão Dash para entrar no painel e acessar a área de configurações.

Exporte os dados em JSON

Esse arquivo leva capturas, organização, tags e outros dados necessários para reimportar depois.

Guarde o arquivo fora do navegador

Salve em pasta sincronizada, HD externo ou nuvem pessoal. Backup no mesmo lugar do dado original não resolve o risco.

Reimporte quando precisar restaurar

Depois de reinstalar ou migrar de dispositivo, use a opção de importação no painel para recuperar o acervo.

Qual formato serve para qual objetivo

JSON

Melhor para backup e restauração. É o formato certo para migrar seu acervo.

HTML

Melhor para leitura, arquivo visual e impressão em PDF.

DOC

Melhor para Word, Google Docs, revisão e compartilhamento editorial.

Com que frequência fazer backup

  • Uso leve: uma vez por mês pode ser suficiente.
  • Uso profissional frequente: semanalmente é mais seguro.
  • Projeto crítico ou pesquisa importante: exporte logo após blocos relevantes de captura.

Uma regra simples para não perder nada

Se a resposta é importante o suficiente para você sentir falta depois, ela merece duas coisas: estar salva no NODUS e ter backup em JSON fora do navegador.
