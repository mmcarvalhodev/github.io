Como exportar conversas do Perplexity

O NODUS captura respostas do Perplexity e permite exportá-las em HTML, Markdown ou DOC — com formatação preservada, sem copiar e colar.

Resposta rápida

Com o NODUS instalado, salve a conversa do Perplexity clicando em Salvar. No painel, abra o card e clique em Exportar para baixar em HTML, Markdown ou DOC. Toda a formatação — listas, código, títulos — é preservada.

Por que exportar conversas do Perplexity?

O Perplexity não tem exportação nativa. Respostas com fontes e referências precisam ser copiadas manualmente, perdendo a formatação das citações. O NODUS exporta a captura completa — incluindo as referências formatadas — em HTML, Markdown ou DOC, ideal para relatórios de pesquisa.

Passo a passo

Instale o NODUS e salve a conversa desejada

Abra o Perplexity normalmente. Ao encontrar uma resposta útil, clique em Salvar (abre o painel com opções) ou Rápido (salva instantaneamente na fila padrão).

Abra o painel NODUS clicando em Dash

O botão Dash ao lado de qualquer resposta abre o painel completo onde todas as suas capturas ficam organizadas.

Encontre o card e clique em Exportar

Localize a captura desejada no painel. Abra o card e clique no botão Exportar para ver as opções de formato disponíveis.

Escolha o formato de exportação

Selecione HTML para visualizar no navegador, Markdown para editores como Notion e Obsidian, ou DOC para abrir no Word e Google Docs. O arquivo é baixado automaticamente.

Formatos disponíveis

HTML

Abre no navegador, imprimível, formatação completa com estilos preservados.

Markdown

Compatível com Notion, Obsidian, VS Code e qualquer editor que suporte .md.

DOC

Abre no Microsoft Word, Google Docs e LibreOffice sem perder a estrutura.

Exportar várias capturas de uma vez

Com a funcionalidade de Cadeias, você conecta múltiplas capturas do Perplexity (ou de outras plataformas) numa sequência e exporta tudo junto como um documento estruturado — ideal para relatórios e documentação.

Basta criar uma cadeia no painel, adicionar os cards desejados em ordem, e exportar a cadeia inteira em um único clique. O resultado é um arquivo coeso com todas as capturas encadeadas logicamente.
