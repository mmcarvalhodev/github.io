🔍 1. Visão geral

O NODUS HN Radar é uma extensão de navegador totalmente local-first. Ela melhora a experiência de leitura em news.ycombinator.com e revela posts em alta via API pública do Hacker News. Sem servidor, sem conta, sem login, sem sincronização em nuvem e sem telemetria.

Este é um produto irmão da extensão principal NODUS (captura de conversas de IA) e do NODUS YT Radar. Cada um tem sua própria política de privacidade:

  • NODUS principal — privacy.html
  • YT Radar — yt-radar-privacy.html
  • HN Radar — este documento

O HN Radar se conecta a dois endpoints, ambos pertencentes ao próprio Hacker News:

obrigatório news.ycombinator.com

O site que você está lendo. O content script melhora as páginas que você mesmo carrega — sem busca proativa.

obrigatório hacker-news.firebaseio.com

API pública Firebase do Hacker News. Usada para buscar listas em alta (Top / Show / Ask / Best) e detalhes individuais de itens para o dashboard Radar.

nenhum Servidores NODUS

O HN Radar não contata nenhuma infraestrutura NODUS. Diferente do YT Radar (worker do Community Spotlight) ou do NODUS principal (licença PRO), esta extensão tem zero dependência de backend NODUS.

💾 2. Dados armazenados localmente no seu dispositivo

Tudo abaixo é armazenado em chrome.storage.local e nunca enviado a lugar algum exceto onde descrito na Seção 3.

settings
Suas preferências: tema, tamanho da fonte, largura de leitura, toggles de destaque, idioma da interface, configurações de tradução, cor/intensidade do zebra etc.
visited
Mapa de IDs de posts do HN que você clicou na frontpage, com timestamps. Usado para acinzentar posts visitados. TTL de 30 dias com poda automática.
pinned
Posts que você fixou explicitamente via o ícone 📌: id, título, url, domínio, snapshot do score, contagem de comentários, idade, tags e timestamp do pin.
collapsedCards
Mapa de IDs de cards fixados que você recolheu no painel lateral, para o estado persistir entre sessões.
recentTags
Lista das últimas 40 tags usadas, para sugestões de autocomplete ao adicionar uma nova tag.
mutedDomains
Lista de domínios que você escolheu silenciar. Posts desses domínios são ocultados no Radar.
radar
Snapshots de dados de posts HN (score, contagem de comentários) ao longo do tempo, usados para calcular velocidade. Poda automática: apenas posts em listas em alta atuais são mantidos.
opActiveCache
Cache do resultado da detecção "autor do post respondeu" por ID. TTL de 10 minutos.
comments_<postId>
Cache dos comentários principais de posts que você passou o mouse para pré-visualizar. TTL de 10 minutos.

Desinstalar a extensão limpa automaticamente tudo acima. Não há conta de usuário, não há coleta de email e não há forma do NODUS identificar você a partir desses dados.

🌐 3. Endpoints externos explicados

A extensão só busca dados de dois domínios, ambos declarados em host_permissions e visíveis para o Chrome antes da instalação.

3a. Site do Hacker News

https://news.ycombinator.com/*apenas content script

O content script injeta CSS e pequenas melhorias DOM (botões de pin, badges de tipo, botões de tradução) em páginas que você carrega. A extensão não busca páginas do HN proativamente em background.

Dados enviados ao HN pela extensão: nenhum além do que seu navegador já envia quando você carrega o site.

3b. API pública Firebase do Hacker News

https://hacker-news.firebaseio.com/v0/topstories.jsonobrigatório

Retorna o array de IDs de posts em alta. Mesma fonte que a frontpage oficial do HN usa.

Dados enviados: nada identificável — apenas a requisição.

…/v0/{best,show,ask}stories.jsonquando aba ativa

Igual ao acima para as abas Best, Show HN e Ask HN do dashboard Radar.

…/v0/item/<id>.jsonpor post

Busca detalhes públicos de cada post ou comentário mostrado no Radar ou em pré-visualização ao passar o mouse.

Dados enviados: o ID do post. Nenhum identificador seu.

O Hacker News e a Y Combinator podem registrar essas requisições conforme suas próprias políticas. A extensão em si não adiciona headers, cookies ou auth.

🌐 4. Tradução no navegador

As traduções acontecem inteiramente no seu dispositivo. O HN Radar usa a API Translator embutida do Chrome (138+), que baixa um pequeno modelo de idioma localmente no primeiro uso e traduz o texto sem enviar a nenhum servidor.

Isso significa:

  • Nenhum texto sai do seu navegador ao traduzir.
  • Sem chave de API, sem custo, sem rastreamento de uso.
  • Tradução funciona offline depois do modelo do par de idiomas ser baixado.
  • Cache de traduções é apenas local e é limpo com a extensão.

Se seu navegador não suportar a Translator API (Firefox ou Chrome mais antigo), as funcionalidades de tradução simplesmente não fazem nada — não há fallback para nenhum serviço de tradução em nuvem.

🚫 5. O que nunca fazemos

  • Vender seus dados para qualquer terceiro
  • Enviar qualquer coisa para servidores NODUS (não existe backend NODUS para esta extensão)
  • Rastrear quais posts você lê, clica ou fixa
  • Rastrear sites que você visita fora de news.ycombinator.com
  • Usar analytics ou SDKs de publicidade de terceiros
  • Ler ou armazenar seus comentários, respostas ou dados de conta no HN
  • Acessar microfone, câmera, área de transferência ou downloads
  • Injetar anúncios ou links de afiliados
  • Exigir conta, login ou email
  • Sincronizar suas tags, pins ou preferências em qualquer nuvem

⚖️ 6. Seus direitos (LGPD / GDPR / CCPA)

O HN Radar está em conformidade com a LGPD brasileira, o GDPR europeu e é compatível com CCPA. Como todos os dados são locais e a extensão não faz profiling ou rastreamento entre sites, a maioria dos direitos é exercida diretamente pelo seu navegador.

Direitos que você tem

  • Acesso — Todos os dados locais ficam visíveis em chrome://extensions → HN Radar → Inspecionar visualizações → Application → Storage
  • Exclusão — Desinstalar a extensão limpa tudo. Você também pode limpar apenas os dados da extensão nas configurações do navegador
  • Portabilidade — Dados locais são JSON puro em chrome.storage.local; você pode exportar do DevTools
  • Opt-out — Desabilite o toggle mestre do Lens a qualquer momento para parar todas as modificações no DOM. Feche o painel lateral para parar fetches do Radar

Base legal para processamento

Ler o site público HN e a API pública Firebase do HN é processado sob interesse legítimo (entregar a camada de leitura que você optou ao instalar a extensão). Nenhum dado pessoalmente identificável é processado.
