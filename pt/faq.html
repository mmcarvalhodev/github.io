Começar

6 perguntas

O NODUS é uma extensão de navegador que permite salvar, organizar e reutilizar respostas de IA com um clique. Funciona com ChatGPT, Claude, Gemini, Perplexity, Grok, Copilot e DeepSeek. Tudo fica armazenado localmente no seu dispositivo — sem conta, sem servidor, sem assinatura obrigatória.

A instalação leva menos de 30 segundos:

  • Chrome / Edge / Brave: acesse a Chrome Web Store e clique em "Adicionar ao Chrome"
  • Firefox: acesse a Mozilla Add-ons e clique em "Adicionar ao Firefox"

Após instalar, abra qualquer plataforma de IA suportada — os botões do NODUS aparecem automaticamente.

Não. O NODUS funciona sem cadastro, sem e-mail, sem senha. Instale e use imediatamente. Seus dados ficam no armazenamento local do próprio navegador.

O NODUS funciona em:

  • Chrome (versão 88+)
  • Firefox (versão 109+)
  • Edge (baseado em Chromium)
  • Brave e outros navegadores Chromium

Ao abrir qualquer plataforma suportada, o NODUS injeta botões flutuantes ao lado das respostas da IA. Clique em Salvar para capturar a pergunta e a resposta instantaneamente. Clique em Rápido para salvar sem abrir o painel de configuração. Clique em Dash para abrir seu painel de capturas.

O NODUS suporta 7 plataformas atualmente:

  • ChatGPT (chat.openai.com)
  • Claude (claude.ai)
  • Gemini (gemini.google.com)
  • Perplexity (perplexity.ai)
  • Grok (grok.com / x.com)
  • Microsoft Copilot (copilot.microsoft.com)
  • DeepSeek (chat.deepseek.com)

Salvar conversas

9 perguntas

Com o NODUS instalado, abra o ChatGPT normalmente. Ao lado de cada resposta aparecem os botões do NODUS. Clique em Salvar para abrir o painel de captura, adicionar tags e escolher a fila de destino — ou clique em Rápido para salvar com um único clique sem configuração.

O NODUS funciona nativamente no Claude.ai. Os botões de captura aparecem ao lado das respostas automaticamente. Clique em Salvar para capturar pergunta + resposta no seu painel local. Funciona igualmente para projetos e conversas normais do Claude.

Guia completo: salvar conversas do Claude →

Instale o NODUS e acesse gemini.google.com. Os botões de captura aparecem ao lado das respostas do Gemini. Clique em Salvar para guardar a conversa localmente, com tags e organização igual às outras plataformas.

Guia completo: salvar conversas do Gemini →

O NODUS detecta automaticamente as respostas no Perplexity.ai e injeta os botões de captura. Clique em Salvar para registrar a resposta junto com as fontes citadas. Ideal para pesquisas que você vai querer consultar depois.

O NODUS funciona tanto em grok.com quanto em x.com/grok. Ao abrir uma conversa com o Grok, os botões de captura aparecem ao lado das respostas. Clique em Salvar para arquivar localmente no seu painel NODUS.

O NODUS suporta o DeepSeek (chat.deepseek.com) nativamente. Os botões de captura aparecem ao lado das respostas. Clique em Salvar para registrar a pergunta e a resposta no seu painel local.

Cada captura salva uma pergunta + resposta por vez. Para salvar múltiplas respostas de uma conversa, clique em Salvar em cada resposta que desejar. Depois, use Cadeias para conectar essas capturas numa sequência lógica.

A Captura Rápida (botão Rápido) salva a resposta diretamente na fila padrão sem abrir o painel de configuração. É ideal quando você quer registrar algo rapidamente sem interromper o fluxo da conversa. A captura fica disponível no painel para organizar depois.

Instale o NODUS e use o botão Rápido sempre que uma resposta parecer útil — mesmo que não saiba ainda para quê. O hábito de capturar antes de fechar a aba elimina a perda de informação. Seu painel acumula tudo e a busca por texto permite encontrar qualquer captura depois.

Exportar e baixar

7 perguntas

Abra seu painel NODUS, selecione a captura desejada e clique em Exportar → DOCX. O arquivo Word é gerado diretamente no seu navegador e salvo no seu computador. Você pode encadear várias capturas com Cadeias e exportar tudo junto como um documento estruturado.

O NODUS exporta em HTML, que você pode imprimir como PDF direto do navegador (Ctrl+P → Salvar como PDF). Para exportação direta em PDF, recomendamos exportar como HTML e usar a impressão do navegador — o resultado fica bem formatado.

O NODUS suporta exportação em:

  • TXT — texto simples, compatível com qualquer editor
  • HTML — formatado, imprimível como PDF
  • DOCX — compatível com Word, Google Docs e LibreOffice

Capturas encadeadas (Cadeias) podem ser exportadas juntas como um documento único.

No painel NODUS, acesse Configurações → Exportar tudo. Isso gera um arquivo com todas as suas capturas em formato JSON (para reimportar no NODUS) ou você pode exportar cada fila individualmente em DOCX ou HTML.

Na visualização de um card no painel, clique em Copiar. O conteúdo é copiado com formatação Markdown preservada — títulos, listas, código — pronto para colar em qualquer editor que suporte Markdown.

Sim. Em Configurações → Exportar dados, você baixa um arquivo JSON com todas as capturas. Esse arquivo pode ser reimportado no NODUS em outro computador ou após reinstalar a extensão.

Use Cadeias para conectar capturas relacionadas de sessões diferentes (mesmo de plataformas diferentes). Depois exporte a cadeia inteira como DOCX — o resultado é um documento estruturado com todas as perguntas e respostas encadeadas em ordem lógica.

Organizar

7 perguntas

Ao salvar uma captura, você pode adicionar até 4 tags para categorizar o conteúdo. As tags aparecem nos cards do painel e funcionam como filtros — clique numa tag para ver apenas as capturas com aquela categoria. Crie tags como "backend", "estudo", "ideias", "trabalho" ou qualquer categoria que faça sentido para você.

As filas são coleções separadas para organizar capturas por contexto ou prioridade. A Quick Queue é para capturas rápidas, sem categorização. A Default é a fila geral. As filas Q1–Q4 (plano PRO) são personalizáveis por tema, projeto ou cliente. Cada fila tem uma cor de borda diferente nos cards.

No painel NODUS, use a barra de busca no topo. A busca funciona em tempo real e cobre o título, a pergunta e a resposta de todas as capturas. Combine a busca com filtros de plataforma ou tag para encontrar exatamente o que procura.

No painel, clique nos badges de plataforma abaixo da barra de busca. Clique em ChatGPT, Claude, Gemini ou qualquer outra plataforma para ver apenas as capturas daquela origem. Clique novamente para remover o filtro.

Projetos (plano PRO) permitem criar espaços completamente separados — por exemplo, "Trabalho", "Estudos" e "Pessoal". Cada projeto tem suas próprias filas e capturas. Troque de projeto com um clique sem misturar conteúdos diferentes.

Sim. Abra o card no painel e clique em Editar. Você pode modificar o título, adicionar ou remover tags e mover a captura entre filas. O conteúdo original (pergunta + resposta) é preservado.

Use a busca por texto no painel — ela cobre o conteúdo completo de todas as capturas, não só o título. Se lembrar de alguma palavra-chave da resposta, basta digitar. Combine com o filtro de plataforma (ex: Claude) se souber de onde veio.

Cadeias

6 perguntas

Cadeias permitem conectar capturas de conversas diferentes numa sequência lógica. Imagine que você pesquisou sobre um tema no ChatGPT, depois aprofundou no Claude e encontrou exemplos no Gemini — uma Cadeia une essas três capturas num fio de raciocínio contínuo, mesmo vindo de plataformas diferentes.

Na aba Cadeias do painel, clique em "Nova Cadeia". Dê um nome à cadeia e adicione capturas existentes arrastando-as para a ordem desejada. Você pode adicionar capturas de qualquer plataforma e reorganizá-las a qualquer momento.

Sim — essa é uma das principais vantagens das Cadeias. Você pode conectar capturas do ChatGPT, Claude, Gemini, Perplexity e qualquer outra plataforma suportada numa única sequência. Cada card mantém a identificação da plataforma de origem.

Abra a Cadeia no painel e clique em Exportar. Você pode exportar a sequência completa como DOCX ou HTML — o resultado é um documento estruturado com todas as perguntas e respostas em ordem, ideal para relatórios, estudos ou documentação.

No plano gratuito, cada Cadeia pode ter até 5 capturas. No plano PRO, o limite é significativamente maior, permitindo cadeias extensas para projetos complexos.

Com a função de injeção, você pode inserir o conteúdo de uma Cadeia diretamente no campo de prompt de qualquer plataforma suportada. É como dar à IA o contexto completo de pesquisas anteriores — sem copiar e colar manualmente cada resposta.

Privacidade e segurança

7 perguntas

Não. O NODUS não tem servidor próprio que receba suas capturas. Tudo é armazenado no armazenamento local do seu navegador (chrome.storage.local / browser.storage.local). Nenhuma captura, tag ou conteúdo sai do seu dispositivo.

Não. O NODUS apenas lê o conteúdo da página quando você clica ativamente em Salvar ou Rápido. Não existe captura automática, monitoramento passivo ou leitura de conversas que você não escolheu salvar.

As capturas ficam no perfil do navegador do seu usuário do sistema operacional. Se o seu perfil de usuário no computador for protegido por senha, as capturas ficam igualmente protegidas. O NODUS não adiciona criptografia extra — use as proteções do sistema operacional para segurança física.

Sim. O core do NODUS está disponível no GitHub sob licença MIT. Qualquer pessoa pode auditar o código e verificar que não existe coleta de dados oculta. Não precisa acreditar na nossa palavra — veja o código.

Ao desinstalar a extensão, o armazenamento local associado é apagado pelo navegador. Faça backup antes: acesse Configurações → Exportar dados para baixar todas as suas capturas em JSON. Você pode reimportar depois de reinstalar.

O NODUS solicita apenas as permissões necessárias para funcionar:

  • Leitura das páginas de IA — para detectar respostas e injetar os botões
  • Armazenamento local — para salvar suas capturas no dispositivo
  • Acesso a abas — para saber em qual plataforma você está

Nenhuma permissão de acesso à câmera, microfone, histórico de navegação ou senhas é solicitada.

O painel NODUS funciona completamente offline — você pode acessar, buscar e exportar capturas sem conexão com a internet. A captura de novas conversas requer conexão porque as próprias plataformas de IA precisam estar acessíveis.
