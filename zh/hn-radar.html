工作原理

安装一次。永远阅读得更好。

无需配置，无需账户。打开 Hacker News，扩展会自动柔化粗糙的边缘。

1

安装扩展

将 NODUS HN Radar 添加到 Chrome 或 Firefox。280KB。仅本地运行。除 Hacker News 之外不要求任何权限。

2

打开 Hacker News

Lens 层自动启用。深色模式、易读字体、按帖子类型显示徽章、已访问帖子变灰 — 静默生效。

3

打开侧边面板

点击扩展图标。置顶帖子、添加标签，观察 Radar 实时呈现带速度评分的上升帖。

功能

由每天阅读 HN 的人打造。

不是"现代主题" — 而是一个尊重 HN 美学同时消除其痛点的阅读与信号层。

🌓

Lens 阅读层

深色、浅色或自动主题。可调字号。可控阅读宽度。已访问帖子变灰。紧凑模式。

🏷️

类型徽章

标题上的 SHOW / ASK / LAUNCH / TELL / POLL 内联标签。按类型着色的行。点击即可打开面板。

📌

置顶与标签

置顶任意帖子。添加多色标签（颜色由名称派生）。标签会在 HN 页面上传播显示在标题旁。

📡

Radar 仪表板

Top / Show HN / Ask HN / Best — 每个帖子都附有速度评分（每小时积分 + 评论数）。在内容爆发前发现上升趋势。

⚡

速度与变化量

每个帖子显示当前速度以及上一个时间段的变化。了解什么在加速 vs. 失去动力。

👤

活跃 OP 徽章

当作者在帖子中回复时显示金色徽章。HN 用户喜爱的"创始人在场"信号。

🔥

热门讨论提示

评论超过 150+ 时显示微妙的标签。超过 400+ 时显示 🔥。值得一看的讨论。

💬

内联预览

悬停置顶卡片上的 "X comments" — 内联显示前 5 条最佳评论。无需切换标签页即可浏览讨论。

🌐

内置翻译

使用 Chrome (138+) 本地 Translator API 翻译标题和评论预览。无需 API 密钥，无云端，无成本。

🔕

域名静音

厌倦了 medium.com 帖子？x.com？将域名加入静音列表，它们就会从 Radar 中消失。

📐

斑马纹行

可选的交替背景，颜色和强度可自定义。首页的 Excel 风格扫描。

🌍

17 种语言

界面完整翻译为 English、Português、Español、Français、Deutsch、Italiano、日本語、한국어、中文、Русский 等。
