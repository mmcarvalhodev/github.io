🔍 1. 概述

NODUS PH Radar 是一款本地优先的浏览器扩展（Chrome）。它为你提供 Product Hunt 的历史深度——每日榜单追踪、增速分析、关注规则、hunter 标签页以及发布日历——全部都在侧边栏中完成。设置、缓存、置顶项、笔记和关注规则都保留在你的浏览器内。核心功能没有用户账户、没有登录、没有云端同步。

这是一款独立于 NODUS 主扩展（AI 对话捕获）和 NODUS YT Radar 的产品。如果你要查找上述其中一份政策，请参阅 NODUS 隐私政策 或 YT Radar 隐私政策。

PH Radar 仅出于以下三种目的建立外部连接，每一项都在下文中作了说明：

必需 Product Hunt API v2（公开）

用于获取你所追踪产品的公开产品数据（每日榜单、投票数、hunter 信息）。仅为只读、仅为公开数据——我们绝不会访问你的 PH 账户凭据。

必需 Community Spotlight

从我们的 worker 获取经过精选、按地区适配的产品推广。仅发送你的国家代码——不含身份信息、不含浏览历史、不含 Product Hunt 账户信息。

点击时 推广点击计数

如果你点击某个 Spotlight 产品，会记录一次匿名点击事件，让 maker 了解其展示效果。仅发送推广 ID。

💾 2. 存储在你设备本地的数据

以下所有内容都存储在 chrome.storage.local 或本地 IndexedDB 中——它们只存在于你的电脑上，除第 3 节明确说明的情形外，绝不会发送到任何 NODUS 服务器。

settings
你的偏好设置：界面语言、首选地区、overlay 模式、刷新间隔以及侧栏布局选项。
ph_token
你的 Product Hunt 个人 API 令牌（可选）。仅用于获取公开的排行榜数据——绝不会发送到 NODUS 服务器，只发送到 Product Hunt 自己的 API。你可以随时在扩展设置中将其清除。
ph_snapshots_<date> (IndexedDB)
当日榜单中出现的产品的公开指标的每日快照（投票数、hunter、tagline）。用于构建增速图表和每日时间线。存储在本地 IndexedDB 中；30 天后自动清理。
ph_pins
你已置顶关注的产品。本地存储；绝不会发送到我们的服务器。
ph_notes_<productId>
你为某个所追踪产品撰写的笔记。本地存储；绝不会发送到我们的服务器。
ph_watch_rules
你定义的提醒规则（例如“当投票数 > 200 时通知”）。本地存储；触发条件在浏览器内进行评估。
spotlight_token
你的 Spotlight 访问令牌（提交时在浏览器内生成的 UUID）。仅用于从仪表板检索你自己的推广。本地存储；在我们的服务器上，我们只保留该令牌的 SHA-256 哈希——明文在初次提交后绝不会再被传输。
_cacheVersion
用于在扩展更新后使过期缓存失效的内部标记。

PH Radar 没有用户账户系统。当你卸载扩展，或在浏览器设置中清除扩展数据时，你的 PH 令牌、置顶项、笔记、关注规则和快照都会被自动删除。

🌐 3. 外部端点说明

扩展会发起以下几类网络请求。每个域名都在扩展的 host_permissions 清单字段中声明，并在安装前对你的浏览器可见。

3a. Product Hunt GraphQL API v2（公开）

https://api.producthunt.com/v2/api/graphql 必需

获取公开的每日榜单、产品详情（标题、tagline、缩略图、投票数、hunter）以及 hunter 个人资料统计。这与 producthunt.com 上可见的公开数据相同。

发送的数据：用于获取公开产品/hunter 数据的 GraphQL 查询 · 你的 PH 个人令牌（仅发送至 Product Hunt 自己的服务器——不发送到我们的服务器）· NODUS 不收集任何个人数据

3b. NODUS PH Radar worker（Community Spotlight）

https://worker-ph-radar.mmcarvalho-dev.workers.dev/spotlight?region=... 必需

请求你所在地区当前有效的 Spotlight 产品推广，以便填充侧边栏的推广条。

发送的数据：国家代码 · 不含身份信息、不含 PH 账户信息、除 Cloudflare 标准请求日志外不存储任何 IP

https://worker-ph-radar.mmcarvalho-dev.workers.dev/spotlight/click 仅点击时

仅在你点击侧边栏中的某个 Spotlight 产品时发送。为 maker 的报表仪表板递增一个汇总点击计数器。

发送的数据：推广 ID · 别无其他

https://worker-ph-radar.mmcarvalho-dev.workers.dev/spotlight/impression 查看时

当某张 Spotlight 卡片在推广条中变为可见时发送（每次会话、每个推广最多计数一次）。用于汇总的曝光报表。

发送的数据：推广 ID · 别无其他

3c. 推广提交（仅 maker，可选）

https://worker-ph-radar.mmcarvalho-dev.workers.dev/promotions/submit 仅 maker · 提交时

仅在 maker 于 nodus-ai.app/ph-radar 填写 Community Spotlight 提交表单时调用。正常使用扩展不会触发。

发送的数据：Product Hunt 产品 URL · 电子邮件地址 · 可选的 tagline、发布日期、主题、地区 · 套餐等级 · 访问令牌（UUID，客户端生成）

⭐ 4. Community Spotlight 推广

Community Spotlight 是 PH Radar 侧边栏底部的推广条，展示由 maker 提交的、经过精选的 Product Hunt 产品（free 或付费等级）。它的存在是为了让独立 maker 无需依赖广告网络即可获得曝光发现。

worker 关于推广所存储的内容

当 maker 在 nodus-ai.app/ph-radar 提交产品时，我们的 Cloudflare D1 数据库会存储：Product Hunt 产品 URL 和 slug、标题、tagline、缩略图 URL、hunter 用户名、套餐等级（free / bronze / silver / gold）、目标地区和主题、可选的发布日期、提交者的电子邮件（仅用于事务性通知）以及汇总的曝光/点击计数器。这些信息由 maker 自愿提供，并非从扩展用户处收集。

访问令牌

在提交时，你的浏览器会使用 crypto.randomUUID() 生成一个 UUID 访问令牌。该令牌在屏幕上仅显示一次——你需要将其复制并保存。在我们的服务器上，我们只存储该令牌的 SHA-256 哈希。我们可以对其进行验证，但无法逆向还原出你的明文令牌。该令牌让你能够通过仪表板查看和管理自己的推广。

付费等级——Paddle 支付处理

对于付费等级（Bronze 1 美元、Silver 3 美元、Gold 7 美元），支付由 Paddle 处理（子处理方详情见第 5 节）。你的电子邮件地址和支付信息由 Paddle 收集，而非 NODUS。我们仅从 Paddle 的 webhook 接收一个支付确认事件，其中包含你的电子邮件和一个交易 ID，以便我们激活你的套餐。

那么扩展用户呢？

在扩展这一侧，我们不存储任何能识别你身份的内容。worker 仅接收：用于 Spotlight 匹配的地区代码，以及——如果你点击或查看——推广 ID。我们不记录你正在追踪哪些产品、不记录超出 Cloudflare 标准请求处理范围的你的 IP、不记录你的浏览器指纹，也不记录任何账户标识符。

托管

worker 运行在 Cloudflare Workers 上，并配有一个 Cloudflare D1 数据库。作为标准网络运行的一部分（DDoS 防护、路由），Cloudflare 可能临时处理 IP 地址和请求元数据。我们不会将 IP 地址写入我们自己的数据库。

🔗 5. 子处理方

我们使用以下可能代表我们处理个人数据的第三方服务。在适用的情况下，我们已与每一方签订数据处理协议。

服务 用途 处理的数据 隐私政策
Cloudflare Workers + D1 用于 Spotlight 推广存储与分发的无服务器运行时和数据库 推广元数据、电子邮件（哈希后的令牌）、汇总统计。IP 地址由 Cloudflare 网络临时处理——不写入 D1。 cloudflare.com/privacypolicy

🚫 6. 我们绝不会做的事

  • 将你的数据出售给任何第三方
  • 读取你的 Product Hunt 账户凭据、私信、私有项目或购买历史
  • 将你的 PH 个人令牌传输到 NODUS 服务器——它只发送至 Product Hunt 自己的 API
  • 追踪你在扩展侧边栏之外于 producthunt.com 浏览了哪些产品
  • 追踪你在 Product Hunt 之外访问了哪些网站
  • 使用广告 SDK、第三方分析或行为跟踪 cookie
  • 访问你的麦克风、摄像头、剪贴板或下载内容
  • 将置顶项、笔记、关注规则或投票快照同步到我们的服务器——所有这些数据都保留在你的设备上
  • 要求账户、登录或电子邮件才能使用扩展的核心功能
  • 将 maker 的提交数据（电子邮件、产品 URL）分享给第 5 节所列子处理方以外的任何第三方

⚖️ 7. 你的权利（LGPD / GDPR）

PH Radar 符合巴西《通用数据保护法》（LGPD）和欧盟《通用数据保护条例》（GDPR），并与 CCPA 兼容。

你作为扩展用户所享有的权利

  • 访问——所有本地数据均可通过 chrome://extensions → PH Radar → 检查视图 → Application → Storage / IndexedDB 查看
  • 删除——移除扩展会自动清除所有 chrome.storage.local 和 IndexedDB 数据。你也可以在浏览器设置中手动清除
  • PH 令牌——你可以随时在扩展设置页中清除你的 Product Hunt 令牌。它绝不会发送到 NODUS 服务器
  • 退出——你可以在扩展设置中关闭 Spotlight 推广条。关闭侧边栏会停止扩展的所有网络活动

你作为 maker（Spotlight 提交者）所享有的权利

  • 访问与删除——使用提交时显示的访问令牌，通过位于 nodus-ai.app/ph-radar#dashboard 的仪表板查看或删除你的推广
  • 令牌丢失——用提交时所用的电子邮件联系我们，我们将在验证身份后删除你的数据
  • 支付数据——关于账单数据（支付历史、发票），请直接通过 paddle.com/legal/privacy 联系 Paddle，或通过购买邮件中的买家门户链接联系

处理的法律依据

Product Hunt API 的获取操作基于正当利益进行处理（交付你打开扩展所要使用的功能）。Spotlight 推广提交和支付基于与提交方 maker 的合同履行进行处理。事务性电子邮件基于合同履行发送。不会发生任何其他处理。

数据保留

有效推广在套餐有效期内加上 90 天的时间内予以保留，以用于报表目的。已过期的推广及其关联的汇总统计可应 maker 请求删除。电子邮件地址仅在关联套餐处于有效或待处理状态期间予以保留，除非你提前请求删除。
