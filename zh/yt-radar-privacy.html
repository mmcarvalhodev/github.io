🔍 1. 概述

NODUS YT Radar 是一款本地优先的浏览器扩展（Chrome 和 Firefox）。它实时向您显示，您正在观看的 YouTube 视频相对于任意国家/地区 Top 50 热门视频的排名情况，并附带病毒式传播评分和增长势头分析。所有设置、缓存和历史快照都保留在您的浏览器中——没有用户账户，无需登录，也没有云同步。

这是一款独立于主 NODUS 扩展（AI 对话捕获）的产品。如果您要查找那份政策，请参阅 privacy.html。

YT Radar 仅出于以下三个目的建立外部连接，每一项都在下文有详细说明：

必需 YouTube Data API v3

用于获取所选国家/地区的公开 Top 50 热门列表，以及您正在观看的视频的详情。仅限只读的公开数据。

必需 Community Spotlight

从我们的 worker 获取一条经过精选、感知地区的视频推广。仅发送国家/地区代码和一个类别编号——不含身份信息，也不含正在观看的视频。

点击时 推广点击计数

如果您点击某个 spotlight 项目，会记录一次匿名点击事件，以便被推广的创作者了解其展示效果。仅发送推广 ID。

💾 2. 存储在您设备本地的数据

以下所有内容均存储在 chrome.storage.local 中——也就是说，它仅存在于您的计算机上，除非第 3 节中明确说明，否则绝不会发送到任何 NODUS 服务器。

settings
您的偏好设置：国家/地区代码、覆盖层模式（徽章 / 展开 / 滚动条 / 关闭）、缓存刷新间隔（15/30/60 分钟）、类别筛选、UI 语言。
ranking_<region>_<category>
由 YouTube Data API 返回的 Top 50 列表，经过缓存，以免我们在每次打开弹窗时重新获取。根据您的刷新间隔设置过期。
video_<videoId>
您在弹窗中打开过的某个视频的公开元数据（标题、频道、观看次数、点赞数、发布日期）。10 分钟后过期。
hist_<videoId>
您分析过的视频的公开计数器（观看、点赞、评论）的时间序列快照，用于绘制增长迷你图并检测爆发式增长。快照最多每 5 分钟采集一次，并在 48 小时后清除。不含任何可识别身份的信息——只有数字。
_cacheVersion
用于在扩展更新后使陈旧缓存失效的内部标志。

YT Radar 没有用户账户系统，无需登录，扩展内不收集任何电子邮件，也没有遥测。当您卸载扩展或在浏览器的扩展设置中点击 "Remove all data"（删除所有数据）时，上述所有键都会被自动移除。

🌐 3. 外部端点说明

该扩展会发起四种网络请求。它连接的每一个 URL 都在扩展的 host_permissions manifest 字段中声明，并在安装前对您的浏览器可见。

3a. YouTube Data API v3（公开的 Google API）

https://www.googleapis.com/youtube/v3/videos?chart=mostPopular&regionCode=... 必需

获取您所选国家/地区的公开 Top 50 热门列表。这与驱动 YouTube "Trending"（热门）标签页的公开端点是同一个。

发送的数据：国家/地区代码（例如 BR）· 可选的类别 ID · 我们的 API 密钥 · 无个人数据，无正在观看的视频

https://www.googleapis.com/youtube/v3/videos?id=<videoId> 必需（按需）

获取您正在观看的视频的公开详情，但仅当它尚未出现在 Top 50 列表中时。正是这一点让我们能够计算其病毒式传播评分和增长指标。

发送的数据：YouTube 视频 ID · 我们的 API 密钥 · 无个人数据

Google 可能会根据其自身的隐私政策记录这些请求。我们不会随之发送任何额外的个人数据。

3b. NODUS YT Radar worker（Community Spotlight）

https://worker-yt-radar.mmcarvalho-dev.workers.dev/promotions?region=...&category=... 必需

向我们的 worker 请求适用于您的国家/地区与类别组合的有效推广视频，以便我们显示 Community Spotlight 卡片。

发送的数据：国家/地区代码 · 类别 ID · 无身份信息，无正在观看的视频，除 Cloudflare 标准请求日志外不存储任何 IP

https://worker-yt-radar.mmcarvalho-dev.workers.dev/promotions/click 仅点击时

仅当您点击 Community Spotlight 卡片上的 "Watch"（观看）按钮时发送。递增聚合点击计数器，以便被推广的创作者了解其展示效果。

发送的数据：推广 ID · 别无其他

https://worker-yt-radar.mmcarvalho-dev.workers.dev/player?v=<videoId> iframe

作为 iframe 加载到 Community Spotlight 轮播中，以播放推广预览。worker 会返回一个嵌入 YouTube 播放器的小型 HTML 页面。

发送的数据：被推广的 YouTube 视频 ID · 频道和标题（仅用作 iframe 标签）

⭐ 4. Community Spotlight 推广

Community Spotlight 是弹窗内的一个版块，用于展示由创作者（免费或付费等级）提交的精选 YouTube 视频。它的存在是为了让独立创作者无需借助广告网络即可获得曝光。

worker 关于一条推广所存储的内容

当创作者在 nodus-ai.app/yt-radar 提交视频时，我们的 Cloudflare D1 数据库会存储：YouTube 视频 ID、标题、频道、缩略图 URL、等级（free/bronze/silver/gold）、目标地区和类别、提交者的电子邮件（仅用于联系），以及聚合的点击/观看计数器。这些信息是由创作者提供的，并非从扩展用户处收集。

那么扩展用户呢？

在扩展端，我们不存储任何可识别您身份的内容。worker 仅能看到：您所选的国家/地区和类别（以便匹配合适的推广），以及——如果您点击——推广 ID。我们不会记录您正在观看哪个视频、除 Cloudflare 标准请求处理之外的您的 IP、您的浏览器指纹，或任何账户标识符。

托管

该 worker 运行于 Cloudflare Workers 之上。作为标准网络运行（DDoS 防护、路由）的一部分，Cloudflare 可能会临时处理 IP 地址和请求元数据。我们不会将 IP 地址写入我们自己的数据库。

🚫 5. 我们绝不会做的事

  • 将您的数据出售给任何第三方
  • 追踪您观看了哪些 YouTube 视频——只读取当前活动的视频 ID，且仅用于计算其排名
  • 追踪您在 YouTube 之外访问了哪些网站
  • 读取或传输您的 YouTube 评论、搜索历史、观看历史或账户信息
  • 使用广告 SDK、第三方分析或行为追踪
  • 访问您的麦克风、摄像头、剪贴板或下载内容
  • 向 YouTube 页面本身注入广告——覆盖层仅显示一个您可以禁用的小排名徽章
  • 将您的任何数据同步到我们的服务器
  • 要求账户、登录或电子邮件才能使用扩展的核心功能

⚖️ 6. 您的权利（LGPD / GDPR）

YT Radar 符合巴西《通用数据保护法》（LGPD）和欧盟《通用数据保护条例》（GDPR），并与 CCPA 兼容。

您拥有的权利

  • 访问 — 所有本地数据均可通过 chrome://extensions → YT Radar → Inspect views（检查视图）→ Application（应用）→ Storage（存储）查看
  • 删除 — 移除扩展会自动清除所有 chrome.storage.local 数据。您也可以在浏览器设置中手动清除
  • 推广数据 — 如果您提交了 Community Spotlight 项目，可以使用提交表单成功页面上显示的访问令牌来管理或删除它。丢失了令牌？请使用提交时所用的电子邮件与我们联系
  • 选择退出 — 在设置中将覆盖层设为 "Off"（关闭）即可禁用页面内覆盖层。关闭弹窗会停止所有扩展的网络活动

处理的法律依据

Top 50 获取和视频详情查询基于正当利益进行处理（提供您打开扩展所需的功能）。Spotlight 推广提交基于与提交创作者的合同履行进行处理。不存在其他任何处理。
