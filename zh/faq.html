快速开始

6 个问题

NODUS 是一款浏览器扩展，让你能够一键保存、整理和重用 AI 回复。支持 ChatGPT、Claude、Gemini、Perplexity、Grok、Copilot 和 DeepSeek。所有内容均存储在你的设备本地——无需账号、无需服务器、无强制订阅。

导出与下载

7 个问题

打开你的 NODUS 仪表板，选择所需的捕获记录，点击导出 → DOCX。Word 文件直接在浏览器中生成并保存到你的电脑。你可以通过链条将多条捕获连接起来，将所有内容一起导出为结构化文档。

NODUS 支持导出为 HTML 格式，你可以直接从浏览器打印为 PDF（Ctrl+P → 保存为 PDF）。如需直接导出 PDF，建议先导出为 HTML，再使用浏览器的打印功能——效果排版精良。

NODUS 支持以下格式导出：

  • TXT — 纯文本，兼容任意编辑器
  • HTML — 格式化，可打印为 PDF
  • DOCX — 兼容 Word、Google Docs 和 LibreOffice

通过链条连接的捕获记录可作为单个文档一起导出。

在 NODUS 仪表板中，前往设置 → 导出全部。这将生成包含所有捕获记录的 JSON 格式文件（可重新导入 NODUS），或者你也可以将每个队列分别导出为 DOCX 或 HTML。

在仪表板的卡片视图中，点击复制。内容将以保留 Markdown 格式复制——包括标题、列表、代码——可直接粘贴到任何支持 Markdown 的编辑器中。

可以。在设置 → 导出数据中，下载包含所有捕获记录的 JSON 文件。该文件可在另一台电脑上重新导入 NODUS，或在重新安装扩展后使用。

使用链条将不同会话（甚至不同平台）中的相关捕获记录连接起来。然后将整条链条导出为 DOCX——结果是一个结构化文档，所有问题和回复按逻辑顺序排列。

整理

7 个问题

保存捕获记录时，你可以添加最多4个标签对内容分类。标签会显示在仪表板卡片上，并作为筛选器——点击标签可只查看该类别的捕获记录。创建"后端"、"学习"、"想法"、"工作"等标签，或任何对你有意义的类别。

队列是按上下文或优先级整理捕获记录的独立集合。快速队列用于快速捕获，无需分类。默认是通用队列。Q1–Q4 队列（PRO 套餐）可按主题、项目或客户自定义。每个队列在卡片上有不同的边框颜色。

在 NODUS 仪表板中，使用顶部的搜索栏。搜索实时生效，涵盖所有捕获记录的标题、问题和回复内容。结合平台或标签筛选器，可精准找到你想要的内容。

在仪表板中，点击搜索栏下方的平台徽章。点击 ChatGPT、Claude、Gemini 或任意其他平台，可只查看来自该来源的捕获记录。再次点击可取消筛选。

项目（PRO 套餐）让你创建完全独立的空间——例如"工作"、"学习"和"个人"。每个项目有自己的队列和捕获记录。一键切换项目，内容互不混淆。

可以。在仪表板中打开卡片并点击编辑。你可以修改标题、添加或删除标签，以及在队列之间移动捕获记录。原始内容（问题和回复）将被保留。

使用仪表板中的文字搜索——它涵盖所有捕获记录的完整内容，不只是标题。如果你记得回复中的任意关键词，直接输入即可。若知道来源平台（如 Claude），可结合平台筛选器一起使用。

链条

6 个问题

链条让你能够将来自不同对话的捕获记录连接成逻辑序列。试想你在 ChatGPT 上研究了一个主题，在 Claude 上深入探讨，又在 Gemini 上找到了示例——链条将这三条捕获记录串联成一个连续的推理线索，即使来自不同平台也没有问题。

在仪表板的链条标签页中，点击"新建链条"。为链条命名，然后将现有捕获记录拖入所需顺序。你可以添加来自任意平台的捕获记录，并随时重新排列。

可以——这正是链条的主要优势之一。你可以在单个序列中连接来自 ChatGPT、Claude、Gemini、Perplexity 及任意其他支持平台的捕获记录。每张卡片都保留其来源平台的标识。

在仪表板中打开链条，点击导出。你可以将完整序列导出为 DOCX 或 HTML——结果是一个包含所有按顺序排列的问题和回复的结构化文档，非常适合报告、学习或文档编写。

免费套餐中，每条链条最多包含 5 条捕获记录。PRO 套餐的限制大幅提升，支持为复杂项目创建大型链条。

通过注入功能，你可以将链条的内容直接插入任意支持平台的提示框中。就像是将之前研究的完整上下文交给 AI——无需手动复制粘贴每条回复。
