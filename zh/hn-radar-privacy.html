🔍 1. 概述

NODUS HN Radar 是一个完全本地优先的浏览器扩展。它优化了 news.ycombinator.com 上的阅读体验，并通过 Hacker News 的公共 API 突显上升帖子。无服务器、无账户、无登录、无云同步、无遥测。

这是主 NODUS 扩展（AI 对话捕获）和 NODUS YT Radar 的姊妹产品。每个产品都有自己的隐私政策：

  • NODUS 主扩展 — privacy.html
  • YT Radar — yt-radar-privacy.html
  • HN Radar — 本文档

HN Radar 连接到两个端点，二者都属于 Hacker News 自身：

必需 news.ycombinator.com

您正在阅读的网站。内容脚本会对您自行加载的页面进行优化 — 不主动 fetch。

必需 hacker-news.firebaseio.com

Hacker News 的公共 Firebase API。用于获取上升帖列表（Top / Show / Ask / Best）以及 Radar 仪表板的单项详情。

无 NODUS 服务器

HN Radar 不联系任何 NODUS 基础设施。与 YT Radar（Community Spotlight worker）或主 NODUS（PRO 许可证）不同，本扩展没有任何 NODUS 后端依赖。

💾 2. 本地存储的数据

以下所有内容都存储在 chrome.storage.local 中，除第 3 节中描述的情况外，永远不会发送到其他位置。

settings
您的偏好：主题、字号、阅读宽度、高亮开关、界面语言、翻译设置、斑马纹颜色/强度等。
visited
您从首页点击过的 HN 帖子 ID 列表，附带时间戳。用于将已访问帖子变灰。TTL 30 天，自动清理。
pinned
通过 📌 显式置顶的帖子：ID、标题、URL、域名、评分快照、评论数、时长、标签、置顶时间戳。
collapsedCards
您在侧边面板中折叠的置顶卡片 ID。
recentTags
最近使用的 40 个标签名称列表，用于自动补全。
mutedDomains
您已静音的域名列表。这些域名的帖子在 Radar 中被隐藏。
radar
HN 帖子数据（评分、评论数）随时间的快照，用于计算速度。
opActiveCache
按 ID 缓存的"作者已回复"检测结果。TTL 10 分钟。
comments_<postId>
悬停预览中评论的缓存。TTL 10 分钟。

卸载扩展会自动清除所有内容。无用户账户，无邮箱收集，NODUS 无法识别您的身份。

🌐 3. 外部端点说明

本扩展仅从两个域名 fetch，已在 host_permissions 中声明，安装前对 Chrome 可见。

3a. Hacker News 网站

https://news.ycombinator.com/*仅内容脚本

内容脚本向您加载的页面注入 CSS 和小型 DOM 增强功能（置顶按钮、类型徽章、翻译按钮）。扩展不会在后台主动 fetch HN。

扩展发送的数据：不超过您的浏览器本来发送的内容。

3b. Hacker News 的公共 Firebase API

https://hacker-news.firebaseio.com/v0/topstories.json必需

返回上升 ID 数组。与官方 HN 首页相同的数据源。

发送的数据：无可识别信息 — 仅是请求本身。

…/v0/{best,show,ask}stories.json如果标签页激活

Best、Show HN 和 Ask HN 标签页同理。

…/v0/item/<id>.json按帖子

获取 Radar 或预览中显示的每个帖子或评论的公共详情。

发送的数据：帖子的 ID。不包含您的任何标识符。

Hacker News 和 Y Combinator 可能会按其自身政策记录这些请求。扩展本身不添加 header、cookie 或 auth。

🌐 4. 浏览器内翻译

翻译完全在您的设备上完成。HN Radar 使用 Chrome 内置的 Translator API（Chrome 138+），首次使用时本地下载一个小型语言模型，无需向任何服务器发送文本即可翻译。

这意味着：

  • 翻译时没有任何文本离开您的浏览器。
  • 无 API 密钥，无成本，无使用追踪。
  • 模型下载完成后翻译可离线工作。
  • 翻译缓存仅本地存储，随扩展一起删除。

如果您的浏览器不支持 Translator API（Firefox 或较旧的 Chrome），翻译功能将不执行任何操作 — 不会回退到云服务。

🚫 5. 我们绝不做的事

  • 将您的数据出售给第三方
  • 向 NODUS 服务器发送任何内容（本扩展无 NODUS 后端）
  • 跟踪您阅读、点击或置顶哪些帖子
  • 跟踪 news.ycombinator.com 之外访问的网站
  • 使用第三方分析或广告 SDK
  • 读取或存储您的 HN 评论、回复或账户数据
  • 访问麦克风、摄像头、剪贴板或下载
  • 注入广告或联盟链接
  • 要求账户、登录或邮箱
  • 将您的标签、置顶或偏好同步到云端

⚖️ 6. 您的权利（LGPD / GDPR / CCPA）

HN Radar 符合巴西 LGPD、欧盟 GDPR，并与 CCPA 兼容。由于所有数据都是本地的，且扩展不进行画像或跨站跟踪，大多数权利可直接通过您的浏览器行使。

您拥有的权利

  • 访问 — 所有本地数据在 chrome://extensions → HN Radar → 检查 → Application → Storage 中可见
  • 删除 — 卸载扩展即清除所有内容
  • 可携带性 — 本地数据以 JSON 格式存储在 chrome.storage.local 中，可从 DevTools 导出
  • 退出 — 随时停用 Lens 主开关

处理的法律依据

读取公共 HN 网站和公共 HN API 属于正当利益（提供您通过安装扩展所选择的阅读层）。不处理任何个人可识别数据。
