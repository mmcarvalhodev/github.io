🔍 1. 概要

NODUS YT Radar はローカルファースト型のブラウザ拡張機能です（Chrome および Firefox）。視聴中の YouTube 動画が、任意の国の Top 50 トレンド動画に対してどの位置にランクしているかを、バイラルスコアと勢いの分析とともにリアルタイムで表示します。すべての設定、キャッシュ、履歴スナップショットはお使いのブラウザ内に保存され、ユーザーアカウントも、ログインも、クラウド同期もありません。

これはメインの NODUS 拡張機能（AI 会話のキャプチャ）とは別の製品です。そちらのポリシーをお探しの場合は privacy.html をご覧ください。

YT Radar は次の3つの目的のためにのみ外部接続を行います。それぞれ以下に記載しています:

必須 YouTube Data API v3

選択した国の公開された Top 50 トレンドリストと、視聴中の動画の詳細を取得するために使用します。読み取り専用の公開データです。

必須 Community Spotlight

当社のワーカーから、地域に応じた厳選された動画プロモーションを取得します。送信するのは国コードとカテゴリ番号のみで、個人を特定する情報も、視聴中の動画も送信しません。

クリック時 プロモーションのクリック数

スポットライト項目をクリックすると、匿名のクリックイベントが記録され、プロモーションを行ったクリエイターは自分の掲載がどう機能したかを把握できます。送信されるのはプロモーション ID のみです。

💾 2. お使いのデバイスにローカル保存されるデータ

以下のすべては chrome.storage.local に保存されます。つまり、お使いのコンピューター上にのみ存在し、第3条で明示的に説明されている場合を除き、いかなる NODUS サーバーにも送信されることはありません。

settings
あなたの設定: 国コード、オーバーレイモード（バッジ / 拡張表示 / ティッカー / オフ）、キャッシュ更新間隔（15/30/60 分）、カテゴリフィルター、UI 言語。
ranking_<region>_<category>
YouTube Data API が返した Top 50 リスト。ポップアップを開くたびに再取得しないようにキャッシュされます。更新間隔の設定に従って期限切れになります。
video_<videoId>
ポップアップで開いた動画の公開メタデータ（タイトル、チャンネル、再生回数、高評価数、公開日）。10分後に期限切れになります。
hist_<videoId>
分析した動画の公開カウンター（再生回数、高評価数、コメント数）の時系列スナップショット。成長スパークラインの描画やブレイクアウトの検出に使用します。スナップショットは最大でも5分に1回取得され、48時間後に削除されます。個人を特定する情報は含まれず、単なる数値のみです。
_cacheVersion
拡張機能の更新後に古いキャッシュを無効化するために使用する内部フラグ。

YT Radar にはユーザーアカウントシステムがなく、ログインも、拡張機能内でのメール収集も、テレメトリもありません。上記のすべてのキーは、拡張機能をアンインストールするか、ブラウザの拡張機能設定で「すべてのデータを削除」をクリックすると自動的に削除されます。

🌐 3. 外部エンドポイントの説明

この拡張機能は4種類のネットワークリクエストを行います。接続するすべての URL は、拡張機能の host_permissions マニフェストフィールドに宣言されており、インストール前にお使いのブラウザで確認できます。

3a. YouTube Data API v3（Google の公開 API）

https://www.googleapis.com/youtube/v3/videos?chart=mostPopular&regionCode=... 必須

選択した国の公開された Top 50 トレンドリストを取得します。これは YouTube の急上昇タブを支えているのと同じ公開エンドポイントです。

送信されるデータ: 国コード（例: BR）· 任意のカテゴリ ID · 当社の API キー · 個人データなし、視聴中の動画なし

https://www.googleapis.com/youtube/v3/videos?id=<videoId> 必須（必要時）

視聴中の動画の公開された詳細を取得しますが、その動画が Top 50 リストにまだ存在しない場合のみ取得します。これにより、その動画のバイラルスコアと成長指標を計算できます。

送信されるデータ: YouTube 動画 ID · 当社の API キー · 個人データなし

Google は自社のプライバシーポリシーに従ってこれらのリクエストを記録する場合があります。当社はそれらに追加の個人データを一切送信しません。

3b. NODUS YT Radar ワーカー（Community Spotlight）

https://worker-yt-radar.mmcarvalho-dev.workers.dev/promotions?region=...&category=... 必須

あなたの国／カテゴリの組み合わせに対してアクティブなプロモーション動画を当社のワーカーに問い合わせ、Community Spotlight カードを表示できるようにします。

送信されるデータ: 国コード · カテゴリ ID · 個人を特定する情報なし、視聴中の動画なし、Cloudflare の標準的なリクエストログを超えて保存される IP なし

https://worker-yt-radar.mmcarvalho-dev.workers.dev/promotions/click クリック時のみ

Community Spotlight カードの「視聴」ボタンをクリックしたときにのみ送信されます。集計クリックカウンターを増分し、プロモーションを行ったクリエイターが自分の掲載がどう機能したかを確認できるようにします。

送信されるデータ: プロモーション ID · その他は一切なし

https://worker-yt-radar.mmcarvalho-dev.workers.dev/player?v=<videoId> iframe

Community Spotlight カルーセル内に iframe として読み込まれ、プロモーションのプレビューを再生します。ワーカーは YouTube プレーヤーを埋め込んだ小さな HTML ページを返します。

送信されるデータ: プロモーション対象の YouTube 動画 ID · チャンネルとタイトル（iframe のラベルとしてのみ使用）

⭐ 4. Community Spotlight のプロモーション

Community Spotlight は、クリエイターが投稿した（無料または有料プランの）厳選された YouTube 動画を表示する、ポップアップ内のセクションです。独立系クリエイターが広告ネットワークを使わずに露出を得られるように存在しています。

ワーカーがプロモーションについて保存する内容

クリエイターが nodus-ai.app/yt-radar で動画を投稿すると、当社の Cloudflare D1 データベースには次の情報が保存されます: YouTube 動画 ID、タイトル、チャンネル、サムネイル URL、プラン（無料 / ブロンズ / シルバー / ゴールド）、対象地域とカテゴリ、投稿者のメールアドレス（連絡のみに使用）、および集計クリック／視聴カウンター。この情報はクリエイターによって提供されるものであり、拡張機能のユーザーから収集されるものではありません。

拡張機能のユーザーについては?

拡張機能側では、あなたを特定するものは一切保存しません。ワーカーが認識するのは、あなたが選択した国とカテゴリ（適切なプロモーションを照合するため）と、あなたがクリックした場合はそのプロモーション ID のみです。当社は、あなたが視聴していた動画、Cloudflare の標準的なリクエスト処理を超えたあなたの IP、ブラウザのフィンガープリント、いかなるアカウント識別子も記録しません。

ホスティング

ワーカーは Cloudflare Workers 上で動作します。Cloudflare は、標準的なネットワーク運用（DDoS 保護、ルーティング）の一環として IP アドレスとリクエストメタデータを一時的に処理する場合があります。当社は IP アドレスを自社のデータベースに書き込みません。

🚫 5. 当社が決して行わないこと

  • あなたのデータを第三者に販売すること
  • あなたが視聴する YouTube 動画を追跡すること — 読み取られるのはアクティブな動画 ID のみで、それもそのランクを計算するためだけです
  • YouTube 以外であなたが訪問するウェブサイトを追跡すること
  • あなたの YouTube のコメント、検索履歴、視聴履歴、アカウント情報を読み取ったり送信したりすること
  • 広告 SDK、サードパーティの分析、行動追跡を使用すること
  • あなたのマイク、カメラ、クリップボード、ダウンロードにアクセスすること
  • YouTube ページ自体に広告を挿入すること — オーバーレイは無効化できる小さなランクバッジを表示するだけです
  • あなたのデータを当社のサーバーに同期すること
  • 拡張機能の中核機能を使用するためにアカウント、ログイン、メールを必須とすること

⚖️ 6. あなたの権利（LGPD / GDPR）

YT Radar はブラジルの一般データ保護法（LGPD）および EU 一般データ保護規則（GDPR）に準拠しており、CCPA とも互換性があります。

あなたが有する権利

  • アクセス — すべてのローカルデータは chrome://extensions → YT Radar → ビューを検証 → Application → Storage から確認できます
  • 削除 — 拡張機能を削除すると、すべての chrome.storage.local データが自動的に消去されます。ブラウザの設定から手動で消去することもできます
  • プロモーションデータ — Community Spotlight 項目を投稿した場合、投稿フォームの完了画面に表示されるアクセストークンを使って管理または削除できます。トークンを紛失した場合は、投稿時に使用したメールアドレスでお問い合わせください
  • オプトアウト — 設定でオーバーレイを「オフ」にすると、ページ内オーバーレイを無効にできます。ポップアップを閉じると、拡張機能のすべてのネットワーク活動が停止します

処理の法的根拠

Top 50 の取得と動画詳細の検索は、正当な利益（あなたが拡張機能を開いた目的の機能を提供すること）に基づいて処理されます。スポットライトのプロモーション投稿は、投稿クリエイターとの契約の履行に基づいて処理されます。それ以外の処理は行われません。
