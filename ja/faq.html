はじめに

6 件の質問

NODUSは、AIの回答をワンクリックで保存・整理・再利用できるブラウザ拡張機能です。ChatGPT、Claude、Gemini、Perplexity、Grok、Copilot、DeepSeekに対応しています。すべてのデータはお使いのデバイスにローカル保存されます — アカウント不要、サーバー不要、サブスクリプション不要。

インストールは30秒以内で完了します：

  • Chrome / Edge / Brave： Chrome ウェブストアにアクセスして「Chromeに追加」をクリック
  • Firefox： Mozilla アドオンにアクセスして「Firefoxに追加」をクリック

インストール後、対応しているAIプラットフォームを開くと、NODUSのボタンが自動的に表示されます。

不要です。 NODUSは登録なし、メールアドレスなし、パスワードなしで動作します。インストールしてすぐに使い始められます。データはブラウザのローカルストレージに保存されます。

NODUSは以下のブラウザで動作します：

  • Chrome（バージョン88以降）
  • Firefox（バージョン109以降）
  • Edge（Chromiumベース）
  • Braveおよびその他のChromiumブラウザ

対応プラットフォームを開くと、NODUSがAIの回答の横にフローティングボタンを挿入します。保存をクリックすると、質問と回答を即座にキャプチャするパネルが開き、タグ追加やキューの選択ができます。クイックをクリックすると、設定パネルを開かずにワンクリックで保存できます。ダッシュをクリックすると、キャプチャのダッシュボードが開きます。

NODUSは現在7つのプラットフォームに対応しています：

  • ChatGPT (chat.openai.com)
  • Claude (claude.ai)
  • Gemini (gemini.google.com)
  • Perplexity (perplexity.ai)
  • Grok (grok.com / x.com)
  • Microsoft Copilot (copilot.microsoft.com)
  • DeepSeek (chat.deepseek.com)

NODUSをインストールしてgemini.google.comにアクセスすると、Geminiの回答の横にキャプチャボタンが表示されます。保存をクリックすると、タグ付きで会話をローカルに保存でき、他のプラットフォームと同じように整理できます。

NODUSはPerplexity.aiの回答を自動的に検出し、キャプチャボタンを挿入します。保存をクリックすると、引用ソースとともに回答が記録されます。後で参照したいリサーチに最適です。

NODUSはgrok.comとx.com/grokの両方で動作します。Grokとの会話を開くと、回答の横にキャプチャボタンが表示されます。保存をクリックすると、NODUSダッシュボードにローカル保存されます。

各キャプチャは質問と回答を1セットずつ保存します。会話から複数の回答を保存するには、保存したい各回答の保存をクリックしてください。その後、チェーンを使ってそれらのキャプチャを論理的な順序でつなげることができます。

クイックキャプチャ（クイックボタン）は、設定パネルを開かずに回答をデフォルトキューに直接保存します。会話の流れを中断せずに素早く記録したいときに最適です。キャプチャはダッシュボードで後から整理できます。

NODUSをインストールし、役に立ちそうな回答を見つけたらすぐクイックボタンを使いましょう — まだ何に使うか分からなくても構いません。タブを閉じる前にキャプチャするという習慣が、情報の紛失をなくします。ダッシュボードにすべてが蓄積され、全文検索でいつでも目的のキャプチャを見つけられます。

エクスポート＆ダウンロード

7 件の質問

NODUSダッシュボードを開き、目的のキャプチャを選択してエクスポート → DOCXをクリックします。Wordファイルはブラウザ上で直接生成され、コンピューターに保存されます。チェーンで複数のキャプチャをつなげて、構造化されたドキュメントとしてまとめてエクスポートすることもできます。

NODUSはHTML形式でエクスポートでき、ブラウザから直接PDFとして印刷できます（Ctrl+P → PDFとして保存）。直接PDF出力の場合は、HTMLでエクスポートしてブラウザの印刷機能を使うことをお勧めします — 見やすくフォーマットされた結果が得られます。

NODUSは以下の形式でのエクスポートに対応しています：

  • TXT — プレーンテキスト、あらゆるエディターと互換
  • HTML — フォーマット済み、PDFとして印刷可能
  • DOCX — Word、Google Docs、LibreOfficeと互換

チェーンでつなげたキャプチャは、1つのドキュメントとしてまとめてエクスポートできます。

NODUSダッシュボードで設定 → すべてエクスポートに進みます。すべてのキャプチャをJSON形式でファイル生成できます（NODUSへの再インポート用）。また、各キューを個別にDOCXまたはHTMLとしてエクスポートすることも可能です。

ダッシュボードのカードビューでコピーをクリックします。コンテンツはMarkdownの書式（見出し、リスト、コードなど）を保持した状態でコピーされ、Markdownに対応したエディターにそのままペーストできます。

できます。設定 → データをエクスポートから、すべてのキャプチャを含むJSONファイルをダウンロードできます。このファイルは別のコンピューターや拡張機能の再インストール後にNODUSへ再インポートできます。

チェーンを使って、異なるセッション（異なるプラットフォームからでも可）の関連キャプチャをつなげます。次にチェーン全体をDOCXとしてエクスポートすると、質問と回答が論理的な順序でつながった構造化ドキュメントが完成します。

整理

7 件の質問

キャプチャを保存する際、コンテンツを分類するためのタグを最大4つ追加できます。タグはダッシュボードのカードに表示され、フィルターとして機能します — タグをクリックするとそのカテゴリのキャプチャだけが表示されます。「バックエンド」「学習」「アイデア」「仕事」など、自分に合ったカテゴリでタグを作成できます。

キューは、コンテキストや優先度別にキャプチャを整理するための独立したコレクションです。クイックキューは、分類なしで素早くキャプチャするためのものです。デフォルトは汎用キューです。Q1〜Q4（PROプラン）はテーマ、プロジェクト、クライアント別にカスタマイズ可能です。各キューはカードの枠線の色で区別されます。

NODUSダッシュボードの上部にある検索バーを使います。検索はリアルタイムで動作し、すべてのキャプチャのタイトル、質問、回答を対象に検索します。プラットフォームやタグのフィルターと組み合わせて、目的のものをピンポイントで見つけられます。

ダッシュボードの検索バー下にあるプラットフォームバッジをクリックします。ChatGPT、Claude、Geminiなどをクリックすると、そのソースからのキャプチャだけが表示されます。再度クリックするとフィルターが解除されます。

プロジェクト（PROプラン）を使うと、「仕事」「学習」「プライベート」など完全に独立したスペースを作れます。各プロジェクトには独自のキューとキャプチャがあります。ワンクリックでプロジェクトを切り替えられ、コンテンツが混在しません。

できます。ダッシュボードのカードを開いて編集をクリックします。タイトルの変更、タグの追加・削除、キュー間のキャプチャ移動が可能です。元のコンテンツ（質問と回答）は保持されます。

ダッシュボードのテキスト検索を使います — タイトルだけでなく、すべてのキャプチャの全内容を対象に検索します。回答内のキーワードを覚えていれば、入力するだけで見つかります。どのプラットフォームか分かっている場合は、プラットフォームフィルター（例：Claude）と組み合わせてください。

チェーン

6 件の質問

チェーンを使うと、異なる会話のキャプチャを論理的な順序でつなげることができます。たとえば、ChatGPTであるトピックを調査し、Claudeでさらに深掘りし、Geminiで事例を見つけた場合、チェーンはその3つのキャプチャを — 異なるプラットフォームからでも — 連続した思考の流れとして結びつけます。

ダッシュボードのチェーンタブで「新しいチェーン」をクリックします。チェーンに名前を付け、既存のキャプチャを希望の順序にドラッグして追加します。どのプラットフォームのキャプチャも追加でき、いつでも並べ替えができます。

できます — それがチェーンの主な利点の一つです。ChatGPT、Claude、Gemini、Perplexityなど対応しているあらゆるプラットフォームのキャプチャを1つのシーケンスにつなげられます。各カードにはソースプラットフォームの識別情報が保持されます。

ダッシュボードでチェーンを開き、エクスポートをクリックします。完全なシーケンスをDOCXまたはHTMLとしてエクスポートできます — 結果は質問と回答が順序通りに並んだ構造化ドキュメントになり、レポート、学習、ドキュメント作成に最適です。

無料プランでは、各チェーンに最大5件のキャプチャを含められます。PROプランでは上限が大幅に拡張され、複雑なプロジェクトにも対応できる大規模なチェーンが作成できます。

注入機能を使うと、対応プラットフォームのプロンプト入力欄にチェーンのコンテンツを直接挿入できます。AIに過去のリサーチの全コンテキストを渡すようなもの — 各回答を手動でコピー＆ペーストする手間がなくなります。
