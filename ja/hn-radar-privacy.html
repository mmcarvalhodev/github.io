🔍 1. 概要

NODUS HN Radar は完全にローカルファーストのブラウザ拡張機能です。 news.ycombinator.com の閲覧体験を改善し、Hacker News の公開 API を介して上昇中の投稿を浮上させます。サーバーなし、アカウントなし、ログインなし、クラウド同期なし、テレメトリーなし。

NODUS メイン拡張機能(AI 会話キャプチャ)と NODUS YT Radar の姉妹プロダクトです。それぞれが独自のポリシーを持ちます:

  • NODUS メイン — privacy.html
  • YT Radar — yt-radar-privacy.html
  • HN Radar — このドキュメント

HN Radar は2つのエンドポイントに接続し、両方とも Hacker News 自身 に属します:

必須 news.ycombinator.com

あなたが読んでいるサイトそのもの。content script はあなた自身が読み込んだページを改善します — プロアクティブな fetch はありません。

必須 hacker-news.firebaseio.com

Hacker News の公開 Firebase API。上昇中リスト(Top / Show / Ask / Best)と Radar ダッシュボード用の個別アイテム詳細を取得するために使用します。

なし NODUS サーバー

HN Radar は NODUS インフラに一切接続しません。YT Radar(Community Spotlight worker)や NODUS メイン(PRO ライセンス)とは異なり、この拡張機能には NODUS バックエンドへの依存はありません。

💾 2. ローカルに保存されるデータ

以下のすべてが chrome.storage.local に保存され、セクション 3 で説明される場合を除いて他のどこにも送信されません。

settings
あなたの設定:テーマ、フォントサイズ、読書幅、ハイライトのトグル、インターフェース言語、翻訳設定、ゼブラの色/濃度など。
visited
フロントページからクリックした HN 投稿の ID リスト、タイムスタンプ付き。訪問済み投稿のグレーアウトに使用。30日 TTL、自動プルーニング。
pinned
📌 で明示的にピン留めされた投稿:ID、タイトル、URL、ドメイン、スコアのスナップショット、コメント数、経過時間、タグ、ピン留めタイムスタンプ。
collapsedCards
サイドパネルで折りたたんだピン留めカードの ID。
recentTags
直近 40 件のタグ名リスト、オートコンプリート用。
mutedDomains
ミュートしたドメインのリスト。これらのドメインの投稿は Radar から非表示になります。
radar
時間経過に伴う HN 投稿データのスナップショット(スコア、コメント)、速度計算に使用。
opActiveCache
ID ごとの「投稿者が返信した」検出キャッシュ。10分 TTL。
comments_<postId>
ホバープレビューコメントのキャッシュ。10分 TTL。

拡張機能をアンインストールするとすべてが自動的に消去されます。ユーザーアカウントなし、メール収集なし、NODUS があなたを特定する手段はありません。

🌐 3. 外部エンドポイントの説明

拡張機能は host_permissions に宣言された2つのドメインからのみ fetch を行い、これはインストール前に Chrome で確認できます。

3a. Hacker News サイト

https://news.ycombinator.com/*content script のみ

content script はあなたが読み込むページに CSS と小さな DOM 改善(ピンボタン、タイプバッジ、翻訳ボタン)を注入します。拡張機能はバックグラウンドで HN にプロアクティブな fetch を行いません。

拡張機能から送信されるデータ: ブラウザが既に送信しているもの以外はなし。

3b. Hacker News の公開 Firebase API

https://hacker-news.firebaseio.com/v0/topstories.json必須

上昇中の ID 配列を返します。公式 HN フロントページと同じソース。

送信されるデータ: 識別情報はなし — リクエストのみ。

…/v0/{best,show,ask}stories.jsonアクティブなタブの場合

Best、Show HN、Ask HN タブにも同様。

…/v0/item/<id>.json投稿ごと

Radar またはプレビューで表示される各投稿またはコメントの公開詳細を取得します。

送信されるデータ: 投稿の ID のみ。あなたを示す識別子はなし。

Hacker News と Y Combinator は独自のポリシーに従ってこれらのリクエストをログに記録する可能性があります。拡張機能自体はヘッダー、Cookie、認証情報を追加しません。

🌐 4. ブラウザ内翻訳

翻訳は完全にあなたのデバイス上で行われます。 HN Radar は Chrome 内蔵の Translator API (Chrome 138+) を使用し、初回使用時に小さな言語モデルをローカルにダウンロードして、サーバーに送信せずにテキストを翻訳します。

これは以下を意味します:

  • 翻訳時にテキストがブラウザから出ることはありません。
  • API キーなし、コストなし、使用状況追跡なし。
  • モデルがダウンロードされれば翻訳はオフラインで動作します。
  • 翻訳キャッシュはローカルのみで、拡張機能と共に消去されます。

ブラウザが Translator API をサポートしない場合(Firefox や古い Chrome)、翻訳機能は何も動作しません — クラウドサービスへのフォールバックはありません。

🚫 5. 決して行わないこと

  • あなたのデータを第三者に販売すること
  • NODUS サーバーに何かを送信すること(この拡張機能には NODUS バックエンドはありません)
  • あなたが読んだ、クリックした、ピン留めした投稿を追跡すること
  • news.ycombinator.com 以外で訪問したサイトを追跡すること
  • サードパーティのアナリティクスや広告 SDK を使用すること
  • あなたのコメント、返信、HN アカウントデータを読み取りまたは保存すること
  • マイク、カメラ、クリップボード、ダウンロードへのアクセス
  • 広告やアフィリエイトリンクの注入
  • アカウント、ログイン、メールの要求
  • タグ、ピン、設定のクラウド同期

⚖️ 6. あなたの権利 (LGPD / GDPR / CCPA)

HN Radar はブラジルの LGPD、欧州の GDPR に準拠し、CCPA と互換性があります。すべてのデータはローカルにあり、拡張機能はプロファイリングやサイト横断トラッキングを行わないため、ほとんどの権利はブラウザを通じて直接行使できます。

あなたが持つ権利

  • アクセス — すべてのローカルデータは chrome://extensions → HN Radar → Inspect → Application → Storage で確認できます
  • 削除 — 拡張機能をアンインストールするとすべてが消去されます
  • ポータビリティ — ローカルデータは chrome.storage.local 内に JSON 形式で保存され、DevTools からエクスポート可能です
  • オプトアウト — Lens マスタートグルをいつでも無効化できます

処理の法的根拠

公開 HN サイトと公開 HN API の読み取りは 正当な利益 に該当します(拡張機能をインストールして選択した閲覧レイヤーを提供するため)。個人を特定できるデータは一切処理されません。
