🔍 1. 概要

NODUS PH Radar はローカルファーストのブラウザ拡張機能です（Chrome）。Product Hunt の履歴的な深掘り — デイリーレースの追跡、勢いの分析、ウォッチルール、hunter タブ、ローンチカレンダー — をすべてサイドパネルで提供します。設定、キャッシュ、ピン留め、メモ、ウォッチルールはお使いのブラウザ内にとどまります。ユーザーアカウントもログインも、コア機能のためのクラウド同期もありません。

本製品はメインの NODUS 拡張機能（AI 会話キャプチャ）および NODUS YT Radar とは別の製品です。これらのポリシーをお探しの場合は、NODUS プライバシーまたはYT Radar プライバシーをご覧ください。

PH Radar は以下の3つの目的のみで外部接続を行い、それぞれを以下に記載しています。

必須 Product Hunt API v2（公開）

あなたが追跡している製品の公開製品データ（デイリーレース、投票数、hunter 情報）を取得するために使用します。読み取り専用、公開データのみで、あなたの PH アカウントの認証情報には決してアクセスしません。

必須 Community Spotlight

当社の worker から、地域に応じてキュレーションされた製品プロモーションを取得します。送信されるのはあなたの国コードのみで、身元情報、閲覧履歴、Product Hunt アカウント情報は一切送信しません。

クリック時 プロモーションのクリック数

Spotlight の製品をクリックすると、maker が掲載のパフォーマンスを把握できるよう、匿名のクリックイベントが記録されます。送信されるのはプロモーション ID のみです。

💾 2. お使いのデバイスにローカル保存されるデータ

以下のすべては chrome.storage.local またはローカルの IndexedDB に保存されます。これらはお使いのコンピューター上にのみ存在し、第3章で明示的に説明されている場合を除き、いかなる NODUS サーバーにも送信されません。

settings
あなたの設定: UI 言語、優先地域、overlay モード、更新間隔、サイドバーのレイアウト選択。
ph_token
あなたの Product Hunt 個人 API トークン（任意）。公開リーダーボードのデータを取得するためにのみ使用され、NODUS サーバーには決して送信されず、Product Hunt 自身の API にのみ送信されます。拡張機能の設定からいつでも消去できます。
ph_snapshots_<date> (IndexedDB)
その日のレースに登場した製品の公開メトリクス（投票数、hunter、tagline）の日次スナップショット。勢いのチャートと日次タイムラインの作成に使用されます。ローカルの IndexedDB に保存され、30日後に自動的に削除されます。
ph_pins
あなたがウォッチのためにピン留めした製品。ローカルに保存され、当社のサーバーには決して送信されません。
ph_notes_<productId>
あなたが追跡している製品について書いたメモ。ローカルに保存され、当社のサーバーには決して送信されません。
ph_watch_rules
あなたが定義したアラートルール（例:「投票数が > 200 になったら通知」）。ローカルに保存され、トリガーはブラウザ内で評価されます。
spotlight_token
あなたの Spotlight アクセストークン（送信時にブラウザ内で生成される UUID）。ダッシュボードからあなた自身のプロモーションを取得するためにのみ使用されます。ローカルに保存され、当社のサーバー上ではこのトークンの SHA-256 ハッシュのみを保持します。平文は最初の送信後に送信されることは決してありません。
_cacheVersion
拡張機能の更新後に古いキャッシュを無効化するために使用される内部フラグ。

PH Radar にはユーザーアカウントシステムがありません。あなたの PH トークン、ピン留め、メモ、ウォッチルール、スナップショットは、拡張機能をアンインストールするか、ブラウザ設定で拡張機能のデータを消去すると、すべて自動的に削除されます。

🌐 3. 外部エンドポイントの説明

拡張機能は以下の種類のネットワークリクエストを行います。すべてのドメインは拡張機能の host_permissions マニフェストフィールドに宣言されており、インストール前にお使いのブラウザで確認できます。

3a. Product Hunt GraphQL API v2（公開）

https://api.producthunt.com/v2/api/graphql 必須

公開のデイリーレース リーダーボード、製品の詳細（タイトル、tagline、サムネイル、投票数、hunter）、hunter のプロフィール統計を取得します。これは producthunt.com で表示されるのと同じ公開データです。

送信されるデータ: 公開の製品/hunter データの GraphQL クエリ · あなたの PH 個人トークン（Product Hunt 自身のサーバーのみへ — 当社へではありません）· NODUS が収集する個人データはありません

3b. NODUS PH Radar worker（Community Spotlight）

https://worker-ph-radar.mmcarvalho-dev.workers.dev/spotlight?region=... 必須

サイドパネルのストリップを埋められるよう、あなたの地域向けにアクティブな Spotlight 製品プロモーションをリクエストします。

送信されるデータ: 国コード · 身元情報なし、PH アカウント情報なし、Cloudflare の標準リクエストログを超えて保存される IP はありません

https://worker-ph-radar.mmcarvalho-dev.workers.dev/spotlight/click クリック時のみ

サイドパネルで Spotlight の製品をクリックしたときのみ送信されます。maker のレポートダッシュボード向けに集計クリックカウンターを増分します。

送信されるデータ: プロモーション ID · それ以外は何もありません

https://worker-ph-radar.mmcarvalho-dev.workers.dev/spotlight/impression 表示時

Spotlight カードがストリップ内で表示されたときに送信されます（プロモーションごとにセッション中最大1回カウント）。集計インプレッションのレポートに使用されます。

送信されるデータ: プロモーション ID · それ以外は何もありません

3c. プロモーションの送信（maker のみ、任意）

https://worker-ph-radar.mmcarvalho-dev.workers.dev/promotions/submit maker のみ · 送信時

maker が nodus-ai.app/ph-radar で Community Spotlight の送信フォームに入力したときのみ呼び出されます。通常の拡張機能の使用ではトリガーされません。

送信されるデータ: Product Hunt の製品 URL · メールアドレス · 任意の tagline、ローンチ日、トピック、地域 · tier · アクセストークン（UUID、クライアント側で生成）

⭐ 4. Community Spotlight プロモーション

Community Spotlight は、maker が送信した（無料または有料の tier の）キュレーション済み Product Hunt 製品を表示する、PH Radar サイドパネル下部のストリップです。インディー maker が広告ネットワークを使わずに発見の露出を得られるよう存在しています。

worker がプロモーションについて保存する内容

maker が nodus-ai.app/ph-radar で製品を送信すると、当社の Cloudflare D1 データベースには次が保存されます: Product Hunt の製品 URL と slug、タイトル、tagline、サムネイル URL、hunter のユーザー名、tier（free / bronze / silver / gold）、対象地域とトピック、任意のローンチ日、送信者のメールアドレス（取引通知のみのため）、集計インプレッション/クリックカウンター。この情報はmaker によって任意に提供されるものであり、拡張機能のユーザーから収集されるものではありません。

アクセストークン

送信時に、あなたのブラウザは crypto.randomUUID() を使用して UUID アクセストークンを生成します。このトークンは画面に一度だけ表示されるので、あなたがコピーして保管します。当社のサーバー上では、このトークンの SHA-256 ハッシュのみを保存します。当社はこれを検証できますが、平文のトークンを取得するために逆変換することはできません。このトークンにより、ダッシュボードを通じてあなた自身のプロモーションを閲覧・管理できます。

有料 tier — Paddle による決済処理

有料 tier（Bronze 1ドル、Silver 3ドル、Gold 7ドル）の決済は Paddle によって処理されます（サブプロセッサーの詳細は第5章をご覧ください）。あなたのメールアドレスと決済情報は NODUS ではなく Paddle によって収集されます。当社は Paddle の webhook から決済確認イベントのみを受け取り、これにはあなたのプランを有効化できるよう、あなたのメールアドレスとトランザクション ID が含まれます。

拡張機能のユーザーについては?

拡張機能側からは、あなたを特定するものは一切保存しません。worker が受け取るのは次のみです: Spotlight マッチング用の地域コード、そして — あなたがクリックまたは表示した場合 — プロモーション ID。あなたが追跡している製品、Cloudflare の標準リクエスト処理を超えたあなたの IP、あなたのブラウザフィンガープリント、いかなるアカウント識別子も記録しません。

ホスティング

worker は Cloudflare D1 データベースを備えた Cloudflare Workers 上で動作します。Cloudflare は標準的なネットワーク運用（DDoS 保護、ルーティング）の一環として、IP アドレスとリクエストのメタデータを一時的に処理する場合があります。当社は IP アドレスを自社のデータベースに書き込みません。

🔗 5. サブプロセッサー

当社は、当社に代わって個人データを処理する可能性のある以下のサードパーティサービスを利用しています。該当する場合は、各社とデータ処理契約を締結しています。

サービス 目的 処理されるデータ プライバシーポリシー
Cloudflare Workers + D1 Spotlight プロモーションの保存と配信のためのサーバーレス ランタイムとデータベース プロモーションのメタデータ、メール（ハッシュ化されたトークン）、集計統計。IP アドレスは Cloudflare のネットワークによって一時的に処理され、D1 には書き込まれません。 cloudflare.com/privacypolicy
Paddle 有料 Spotlight tier（Bronze、Silver、Gold）の決済処理 メールアドレス、請求先氏名、決済カードの詳細（すべて Paddle によって処理され、NODUS はカード番号を一切見ません）。Paddle は記録上の販売者です。 paddle.com/legal/privacy
Resend 取引メール: 送信確認と管理者レビュー通知 送信する maker のメールアドレスとメール内容（送信の詳細）。メールは送信イベントによってのみトリガーされます。 resend.com/legal/privacy-policy
Product Hunt API v2 公開の製品および hunter データの取得 公開の製品メタデータ（投票数、タイトル、tagline、hunter）。あなたの PH 個人トークンは Product Hunt に直接送信され、NODUS へは送信されません。 producthunt.com/legal/privacy

サードパーティ分析なし、トラッキング Cookie なし。 PH Radar は Google Analytics、Mixpanel、Segment、Facebook Pixel、その他いかなる行動トラッキングや広告 SDK も — 拡張機能内でも、PH Radar に関連する nodus-ai.app の Web サイトページ上でも — 使用しません。

🚫 6. 当社が決して行わないこと

  • あなたのデータを第三者に販売すること
  • あなたの Product Hunt アカウントの認証情報、DM、非公開プロジェクト、購入履歴を読み取ること
  • あなたの PH 個人トークンを NODUS サーバーに送信すること — それは Product Hunt 自身の API にのみ送られます
  • 拡張機能のサイドパネル外で producthunt.com 上であなたが閲覧する製品を追跡すること
  • Product Hunt 以外であなたが訪問する Web サイトを追跡すること
  • 広告 SDK、サードパーティ分析、行動トラッキング Cookie を使用すること
  • あなたのマイク、カメラ、クリップボード、ダウンロードにアクセスすること
  • ピン留め、メモ、ウォッチルール、投票スナップショットを当社のサーバーに同期すること — それらのデータはすべてお使いのデバイスにとどまります
  • 拡張機能のコア機能を使用するためにアカウント、ログイン、メールを要求すること
  • maker の送信データ（メール、製品 URL）を第5章に記載されたサブプロセッサー以外の第三者と共有すること

⚖️ 7. お客様の権利（LGPD / GDPR）

PH Radar はブラジルの一般データ保護法（LGPD）および EU 一般データ保護規則（GDPR）に準拠し、CCPA とも互換性があります。

拡張機能ユーザーとしてのあなたの権利

  • アクセス — すべてのローカルデータは chrome://extensions → PH Radar → ビューを検証 → アプリケーション → ストレージ / IndexedDB から確認できます
  • 削除 — 拡張機能を削除すると、すべての chrome.storage.local および IndexedDB データが自動的に消去されます。ブラウザ設定から手動で消去することもできます
  • PH トークン — 拡張機能の設定ページからいつでも Product Hunt トークンを消去できます。これは NODUS サーバーには決して送信されません
  • オプトアウト — 拡張機能の設定で Spotlight ストリップを無効にできます。サイドパネルを閉じると、拡張機能のすべてのネットワーク活動が停止します

maker（Spotlight 送信者）としてのあなたの権利

  • アクセスと削除 — 送信時に表示されたアクセストークンを使用して、nodus-ai.app/ph-radar#dashboard のダッシュボードからあなたのプロモーションを閲覧または削除できます
  • トークンの紛失 — 送信時に使用したメールアドレスでご連絡いただければ、本人確認の後にあなたのデータを削除します
  • 決済データ — 請求データ（支払い履歴、請求書）については、paddle.com/legal/privacy で Paddle に直接お問い合わせいただくか、購入メール内の購入者ポータルリンクをご利用ください

処理の法的根拠

Product Hunt API の取得は正当な利益（あなたが拡張機能を開いた目的の機能を提供すること）に基づいて処理されます。Spotlight プロモーションの送信と決済は、送信する maker との契約の履行に基づいて処理されます。取引メールは契約の履行に基づいて送信されます。それ以外の処理は行われません。

データの保持

アクティブなプロモーションは、プランの期間に加えてレポート目的で90日間保持されます。期限切れのプロモーションと関連する集計統計は、maker の要求に応じて削除される場合があります。メールアドレスは、関連するプランがアクティブまたは保留中である限りにおいてのみ保持されますが、あなたが早期の削除を要求した場合はこの限りではありません。
